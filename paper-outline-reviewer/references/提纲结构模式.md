# 提纲结构模式

> **结构模式的权威源在环节5**：`paper-writing-engine/references/论文结构模式.md`（6种模式，含写作要点和实务轨推荐模式）。
>
> 本文件不重复定义结构模式，只保留提纲审查阶段特有的注意事项。

---

## 六种结构模式速查

| 模式 | 适用场景 | 核心特征 |
|------|----------|----------|
| 模式一：制度分析型 | 分析某一制度的规范构造、实施效果和完善路径 | 规范分析为主体，案例支撑，制度建议为落脚点 |
| 模式二：规范解释型 | 对某一法律条文或概念进行解释论研究 | 以解释方法为论证主线（文义→体系→目的），案例为验证 |
| 模式三：实证研究型 | 通过实证数据揭示法律制度的运行状况 | 实证发现为主体，规范含义为落脚点 |
| 模式四：比较法研究型 | 通过比较法分析为国内制度提供借鉴 | 比较分析为核心，强调功能比较，落脚于本土化 |
| 模式五：问题对策型（实务轨推荐） | 以实务问题为起点，分析规范困境，给出可操作对策 | 以"问题"为中心，对策须可操作（谁来做+怎么做+前提条件） |
| 模式六：案例评析型（实务轨推荐） | 以真实案例切入，从个案提炼规则适用路径 | 以个案/类案的法律分析为核心，适用指引是核心增量 |

> 详细结构模板和写作要点请查阅环节5的论文结构模式.md。

## 提纲审查特有注意事项

以下注意事项是提纲审查阶段（环节3）独有的，环节5不涉及：

### 1. 提纲与结构模式的匹配检查

- 提纲的一级标题框架是否与所选结构模式基本对应？
- 不要求完全照搬模板，但偏离模式时须有论证理由
- 混合模式（如"制度分析+实证验证"）须标明主模式和辅模式

### 2. 篇幅分配预检

- 规范分析部分是否占全文30%左右？（制度分析型、规范解释型）
- 问题识别与对策建议的篇幅比例是否合理？（问题对策型）
- 实证数据呈现与分析的篇幅是否占主体？（实证研究型）
- 比较法考察与本土化启示的篇幅比例是否合理？（比较法研究型）

### 3. 论证线索完整性检查

- 提纲中每个一级标题是否有论证功能？（不能只是"介绍"或"概述"）
- 一级标题之间的逻辑关系是否清晰？（递进/并列/对比）
- 提纲是否覆盖了从"问题提出"到"结论"的完整链条？
- 是否有"孤立章节"——与其他章节没有逻辑关联的章节？

### 4. 实务轨专项检查

- 【实务轨】提纲中是否有专门的"问题对策"或"案例评析"章节？
- 【实务轨】提纲中是否有标题直接对应线索卡的"痛点描述"？
- 【实务轨】如选题为实务轨且提纲未包含实操建议章节 → 标记"结构缺陷：缺少实操建议章节"
- 推荐结构模式参见环节5论文结构模式五、六

### 5. 通用注意

1. 结构模式是参考框架，不是模板。具体提纲应根据选题特点调整。
2. 一篇论文可以混合多种模式。如"制度分析+实证验证""规范解释+比较法参照"。
3. 无论哪种模式，应用法学论文必须包含规范分析（法律条文分析）。
4. 纯理论分析（不涉及具体条文的）不属于应用法学论文，应调整选题方向。
5. 篇幅分配仅供参考，实际应根据论文内容的重要性灵活调整。
