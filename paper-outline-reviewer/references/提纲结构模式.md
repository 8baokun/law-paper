# 提纲结构模式

> 参考用。应用法学论文的典型提纲结构模式，供审查时参照。

---

## 模式一：制度分析型

适用于：分析某一具体制度的设计、实施和改进

```
一、问题的提出
  1.1 实践困惑/制度争议的呈现
  1.2 文献回顾与研究缺口
  1.3 研究方法与论文结构

二、制度的规范基础
  2.1 法律条文梳理
  2.2 构成要件分析
  2.3 解释争议辨析

三、制度的实施现状
  3.1 典型案例分析
  3.2 实施中的问题识别
  3.3 问题成因分析

四、制度的比较法参照
  4.1 [国家A]的制度安排
  4.2 [国家B]的制度安排
  4.3 比较启示

五、制度的完善路径
  5.1 规范层面的完善
  5.2 实施层面的改进
  5.3 配套制度安排

六、结论
  6.1 核心发现总结
  6.2 研究局限与展望
```

**结构特点**：规范分析为主体（第二章），案例支撑（第三章），比较法为参照（第四章），制度建议为落脚点（第五章）。

---

## 模式二：规范解释型

适用于：对某一法律条文或法律概念的解释论研究

```
一、问题的提出
  1.1 条文/概念的争议焦点
  1.2 文献回顾
  1.3 研究路径

二、文义解释
  2.1 条文的文义射程
  2.2 核心概念的语义分析
  2.3 文义解释的局限

三、体系解释
  3.1 在法律体系中的位置
  3.2 与相关条文的协调
  3.3 体系解释的发现

四、目的解释
  4.1 立法目的的探寻
  4.2 目的限缩/扩张的必要性
  4.3 目的解释的结论

五、案例分析验证
  5.1 支持性案例
  5.2 反面案例的回应
  5.3 解释结论的适用效果

六、结论
  6.1 解释结论
  6.2 解释方法的贡献
  6.3 待解决的问题
```

**结构特点**：以解释方法为论证主线（文义→体系→目的），案例为验证，结论为解释结论。

---

## 模式三：实证研究型

适用于：通过实证数据揭示法律制度的运行状况

```
一、问题的提出
  1.1 实践困惑
  1.2 文献回顾
  1.3 研究假设

二、研究设计
  2.1 数据来源与样本
  2.2 变量与测量
  2.3 分析方法

三、描述性发现
  3.1 基本特征
  3.2 总体趋势
  3.3 分组比较

四、解释性分析
  4.1 影响因素识别
  4.2 机制分析
  4.3 假设检验结果

五、规范含义
  5.1 实证发现对规范解释的启示
  5.2 实证发现对制度改进的启示
  5.3 实证发现与理论预期的张力

六、结论
  6.1 核心发现
  6.2 政策建议
  6.3 研究局限
```

**结构特点**：以实证发现为主体（第三、四章），规范含义为落脚点（第五章），不喧宾夺主。

---

## 模式四：比较法研究型

适用于：通过比较法分析为国内制度提供借鉴

```
一、问题的提出
  1.1 国内制度的困境
  1.2 比较法研究的必要性
  1.3 比较对象的选取理由

二、比较对象A的制度安排
  2.1 制度框架
  2.2 实施机制
  2.3 实施效果

三、比较对象B的制度安排
  3.1 制度框架
  3.2 实施机制
  3.3 实施效果

四、比较分析
  4.1 功能比较（非概念比较）
  4.2 差异成因分析
  4.3 可比性与不可比性

五、对国内制度的启示
  5.1 可借鉴之处
  5.2 不可移植之处及原因
  5.3 本土化路径

六、结论
  6.1 比较法发现
  6.2 对国内制度的具体建议
  6.3 研究局限
```

**结构特点**：比较分析为核心（第四章），强调功能比较而非概念比较，落脚于本土化（第五章）。

---

## 通用注意事项

1. 上述模式是参考框架，不是模板。具体提纲应根据选题特点调整。
2. 一篇论文可以混合多种模式。如"制度分析+实证验证""规范解释+比较法参照"。
3. 无论哪种模式，应用法学论文必须包含规范分析（法律条文分析）。
4. 纯理论分析（不涉及具体条文的）不属于应用法学论文，应调整选题方向。
5. 篇幅分配仅供参考，实际应根据论文内容的重要性灵活调整。
