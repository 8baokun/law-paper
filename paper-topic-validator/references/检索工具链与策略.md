# 选题验证型文献综述：检索工具链与策略

> 本文件从SKILL.md外移，包含选题验证型文献综述的检索要求、核心文献下载策略、检索工具链、检索策略和法学检索式优化。

---

## 检索要求

| 项目 | 要求 |
|------|------|
| 文献量 | 5-15篇核心文献（不追求穷尽） |
| 文献类型 | 优先学理文献（核心期刊+专著），辅以规范文献和典型案例 |
| 检索来源 | 至少2个来源交叉验证（如NCPSSD+WebSearch，或OpenAlex+威科） |
| 真实性要求 | 所有文献必须真实存在，不可凭记忆判断。如无法验证，标注"[待验证]" |
| 时间范围 | 近10年为主，经典文献不限 |

## 核心文献下载策略

> 选题验证型综述筛选出的5-15篇核心文献，尝试下载PDF全文作为后续人工核实的依据。
> **原则**：能下则下，付费墙文献不下但记录核心信息，不做PDF转文本。

| 项目 | 规范 |
|------|------|
| 下载目录 | `[论文项目目录]/papers/`（与论文产物同目录下的 papers 子文件夹） |
| 文件命名 | `[编号]_[作者]_[年份]_[短标题].pdf`（如 `L1_张三_2023_自甘风险构成要件.pdf`） |
| 下载来源 | NCPSSD返回的PDF链接优先下载；OpenAlex仅下载OA标记为✅的 |
| 付费墙处理 | **不下载**，在文献清单中标注"付费墙·待人工获取"，记录论文名/作者/期刊/年份等核心信息 |
| 下载间隔 | 每篇间隔≥3秒，避免触发反爬 |
| 失败处理 | 连续下载失败3次，暂停下载，剩余文献仅记录信息 |
| 会话上限 | 单次会话下载总量不超过15篇（环节1配额） |
| 下载状态标注 | ✅已下载 / ❌付费墙·待人工获取 / ⚠️下载失败·待重试 / —无需下载 |

## 检索工具链（paper-harvester 集成）

> 本技能集成 paper-harvester 技能的多源检索脚本，实现自动化文献检索。以下为工具链使用规范。

### 工具链总览

| 工具 | 检索源 | 覆盖范围 | 角色 | 使用要点 |
|------|--------|----------|------|----------|
| `search_ncpssd.py` | 国家哲社文献中心（NCPSSD） | 中文核心期刊论文 | **主力中文源** | ⚠️ **单词查询**：NCPSSD不支持多词组合检索，需拆分为多个单词分别查询后人工合并 |
| `search_openalex.py` | OpenAlex | 全球英文文献（含DOI、被引量、OA状态） | **主力英文源** | 适合比较法文献检索，可用短语查询 |
| `search_crossref.py` | Crossref | 全球英文文献（含DOI） | **英文补充源** | 与OpenAlex结果去重合并 |
| `search_semantic_scholar.py` | Semantic Scholar | 全球英文文献（含语义关联） | **英文补充源** | 有限流（429），非必须 |
| WebSearch | 互联网公开搜索 | 法院实务文章、学位论文、新闻报道 | **补充源** | 覆盖NCPSSD不收录的实务类和学位论文类文献 |

### 检索策略

```
步骤1：NCPSSD 中文核心文献检索（主力源）
  - 将选题拆分为2-4个核心关键词
  - 每个关键词单独查询（如"自甘风险""重大过失""体育侵权"分别查）
  - 每次返回上限20篇，可按需调大
  - 每篇含标题、作者、来源、年份、摘要、PDF链接
  ↓
步骤2：OpenAlex 英文文献检索（比较法素材）
  - 用英文短语查询（如"assumption of risk sports injury"）
  - 重点关注被引量高的文献和OA可下载全文
  - Crossref 作为补充，与OpenAlex结果去重
  ↓
步骤3：WebSearch 补充检索（实务+学位论文）
  - 搜索法院实务文章、裁判文书实证研究
  - 搜索硕博学位论文
  - 搜索NCPSSD可能遗漏的近年新刊
  ↓
步骤4：多源去重合并
  - 按标题（小写化）去重
  - 按DOI去重（如有DOI的文献）
  - 合并后按相关性排序，筛选5-15篇核心文献
  ↓
步骤5：文献验证
  - 每篇文献标注检索来源（NCPSSD/OpenAlex/Crossref/WebSearch）
  - 如无法验证真实性，标注"[待验证]"
  ↓
步骤6：核心文献下载
  - 对筛选出的5-15篇核心文献，逐篇尝试下载PDF
  - 下载目录：[论文项目目录]/papers/
  - 文件命名：[编号]_[作者]_[年份]_[短标题].pdf
  - 下载间隔≥3秒，会话上限15篇
  - 付费墙文献不下载，标注"付费墙·待人工获取"
  - 连续失败3次暂停下载，剩余仅记录信息
  - 在文献综述报告的核心文献清单中标注下载状态
```

### 法学检索式优化

法学论文检索与通用文献检索有差异，需注意以下优化：

| 优化项 | 说明 | 示例 |
|--------|------|------|
| **法条编号检索** | 以核心法条编号为关键词单独检索 | "民法典1176条"、"第1176条" |
| **核心期刊预设** | NCPSSD返回结果按来源期刊筛选，优先保留CLSCI/CSSCI法学期刊 | 《法学研究》《中国法学》《法学》《法学评论》《政法论坛》等 |
| **单词拆分原则** | NCPSSD不支持多词组合，必须拆分为单个概念词分别查 | "自甘风险 重大过失 体育" → 拆为3次查询 |
| **同义词扩展** | 法学概念常有多种表述，需用同义词扩展查询 | "自甘风险"→也查"自甘冒险"；"重大过失"→也查"重大过失认定" |
| **英文检索词** | 比较法检索用英文标准术语 | "assumption of risk"、"gross negligence"、"sports injury liability" |
