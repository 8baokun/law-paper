# 选题检查器（Paper Topic Validator）

## 定位

本技能是论文生产线的第一个环节。在作者确定选题后、正式开始思路梳理前，对选题进行结构化评估。

输出永远是选题诊断报告，不是选题建议。本技能不替作者选题目，只评估已选题目是否可行。

## 五维评估模型

### 维度1 · 问题意识清晰度

**核心问题**：选题是否指向一个明确的问题？

| 编号 | 检查问题 | 判定方式 |
|------|----------|----------|
| 1.1 | 选题能否用一句话表述为核心问题？ | 如果需要超过一句话才能说清楚选题在研究什么，说明问题意识模糊。 |
| 1.2 | 核心问题是"真问题"还是"伪问题"？ | 真问题：存在真实的理论困惑或实践争议。伪问题：答案已经明确，或问题本身不成立。 |
| 1.3 | 核心问题是"大问题"还是"小问题"？ | 大问题：过于宽泛，一篇文章无法充分回答。小问题：过于琐碎，没有学术价值。适中：一篇文章可以充分回答且有学术价值。 |
| 1.4 | 问题意识是否贯穿选题表述？ | 检查选题表述中是否隐含了"为什么……""如何……""……是否……"等问题指向。 |
| 1.5 | 选题是否混淆了"话题"和"问题"？ | "公司法中的信义义务"是话题。"信义义务的审查标准如何确定"是问题。选题必须是问题，不能只是话题。 |

**评分标准**：
| 分值 | 含义 |
|------|------|
| 5 | 核心问题清晰、聚焦、有学术价值 |
| 4 | 核心问题基本清晰，个别地方需聚焦 |
| 3 | 问题意识存在但不够聚焦，话题与问题混同 |
| 2 | 问题意识模糊，选题偏向话题 |
| 1 | 无明确问题意识，只是研究领域标注 |

---

### 维度2 · 学术增量空间

**核心问题**：选题是否可能产出新的学术贡献？

| 编号 | 检查问题 | 判定方式 |
|------|----------|----------|
| 2.1 | 现有文献对该问题的研究状态如何？ | 全面搜索文献。如果已有大量充分研究，增量空间有限。如果研究稀少或存在明显缺口，增量空间大。 |
| 2.2 | 选题是否可能产出新的理论贡献？ | 新理论=提出新概念、新框架、新解释模型。检查选题是否为理论创新留有空间。 |
| 2.3 | 选题是否可能产出新的规范分析贡献？ | 新规范分析=对法律条文的新解释、对制度安排的新分析、对构成要件的新拆解。 |
| 2.4 | 选题是否可能产出新的实证发现？ | 新实证=新的数据、新的案例、新的调查结果。检查选题是否涉及实证研究。 |
| 2.5 | 选题是否只是"重复已有研究"？ | 对照现有文献的核心结论，检查选题是否会得出相同结论。如相同，无增量。 |

**评分标准**：
| 分值 | 含义 |
|------|------|
| 5 | 增量空间明确且充足，可能产出显著学术贡献 |
| 4 | 增量空间存在，可能产出有价值的学术贡献 |
| 3 | 增量空间有限，可能在局部有所推进 |
| 2 | 增量空间很小，基本是对已有研究的重复 |
| 1 | 无增量空间，纯重复已有研究 |

---

### 维度3 · 论证可行性

**核心问题**：作者是否有能力和资源完成这个选题？

| 编号 | 检查问题 | 判定方式 |
|------|----------|----------|
| 3.1 | 选题所需的文献是否可获取？ | 检查核心文献是否可通过常规渠道获取。如需罕见外文文献或内部资料，可行性降低。 |
| 3.2 | 选题所需的研究方法是否在作者能力范围内？ | 如选题需要实证方法，作者是否有数据收集和分析能力？如需要比较法，作者是否有相关外语能力？ |
| 3.3 | 选题的规模是否与文章篇幅匹配？ | 期刊论文8000-15000字。如选题需要50000字才能充分论证，规模不匹配。 |
| 3.4 | 选题的时间约束是否可满足？ | 检查是否有紧迫的截止日期。如截止日期前无法完成核心论证，可行性降低。 |
| 3.5 | 选题是否存在"致命障碍"？ | 致命障碍=核心文献无法获取、核心数据不存在、核心案例未公开等。如有致命障碍，选题不可行。 |

**评分标准**：
| 分值 | 含义 |
|------|------|
| 5 | 所有条件具备，无障碍 |
| 4 | 个别条件需努力获取，但不构成根本障碍 |
| 3 | 存在一定障碍，需调整选题范围或方法 |
| 2 | 存在显著障碍，完成难度很大 |
| 1 | 存在致命障碍，选题不可行 |

---

### 维度4 · 规范分析深度

**核心问题**：选题是否允许进行深入的规范分析？

| 编号 | 检查问题 | 判定方式 |
|------|----------|----------|
| 4.1 | 选题是否涉及具体的法律规范？ | 如果选题完全不涉及法律条文，规范分析空间有限。应用法学论文必须有规范分析。 |
| 4.2 | 相关法律规范是否有解释空间？ | 如果法律条文含义明确无争议，规范分析空间有限。如果存在解释争议，空间大。 |
| 4.3 | 选题是否涉及规范的适用问题？ | 检查选题是否关注"规范如何适用"而不仅是"规范是什么"。适用问题通常有更深的分析空间。 |
| 4.4 | 选题是否涉及规范冲突或规范空白？ | 规范冲突（多个规范互相矛盾）和规范空白（应有规范但无规范）是规范分析的富矿。 |
| 4.5 | 选题是否可能进行构成要件分析？ | 检查选题是否允许将规范拆解为构成要件并逐一分析。构成要件分析是应用法学的基本功。 |

**评分标准**：
| 分值 | 含义 |
|------|------|
| 5 | 规范分析空间充足，可进行多层次的规范解读 |
| 4 | 规范分析空间较大，可进行有深度的规范解读 |
| 3 | 规范分析空间一般，可进行基本的规范解读 |
| 2 | 规范分析空间有限，多为描述性陈述 |
| 1 | 几乎无规范分析空间，选题偏离应用法学 |

---

### 维度5 · 实践关联度

**核心问题**：选题是否与法律实践有真实关联？

| 编号 | 检查问题 | 判定方式 |
|------|----------|----------|
| 5.1 | 选题是否回应了实践中的真实困惑？ | 检查选题是否源于实践中的真实问题（如裁判分歧、执法困难、合规困境），而非纯理论推演。 |
| 5.2 | 选题是否可能对实践产生指导意义？ | 检查选题的结论是否可能被法官、律师、企业法务等实践主体使用。 |
| 5.3 | 选题是否涉及典型案例或典型场景？ | 检查选题是否有具体案例支撑。纯抽象的规范分析如果脱离案例，实践关联度降低。 |
| 5.4 | 选题是否考虑了制度实施成本？ | 如选题涉及制度建议，检查是否考虑了实施成本。不考虑成本的制度建议与实践脱节。 |
| 5.5 | 选题是否与当前法治实践的热点/难点相关？ | 检查选题是否回应了当前法治建设的重点问题。不是追逐热点，但与实践完全脱节的选题价值有限。 |

**评分标准**：
| 分值 | 含义 |
|------|------|
| 5 | 与实践紧密关联，选题直接源于实践困惑 |
| 4 | 与实践有明确关联，可能对实践产生指导 |
| 3 | 与实践有一定关联，但关联不够紧密 |
| 2 | 与实践关联微弱，主要是理论推演 |
| 1 | 与实践完全脱节，纯理论思辨 |

## 执行流程

```
步骤1：接收选题表述
  - 作者提供选题名称、研究问题、预期贡献
  ↓
步骤2：五维逐项评估
  - 按上述五维模型逐项检查
  - 每维给出评分（1-5分）和具体发现
  ↓
步骤3：文献快速摸底（维度2需要）
  - 搜索核心文献，判断增量空间
  - 不做完整文献综述，只判断"有没有空间"
  ↓
步骤4：识别核心风险
  - 哪些维度评分低于3分？
  - 低分维度的根本原因是什么？
  ↓
步骤5：输出诊断报告
  - 五维评分汇总
  - 核心风险（最多3个）
  - 修改建议（可操作的）
  - 通过/回退判定
```

## 通过/回退判定

### 通过条件（全部满足）

- 五维综合评分 ≥ 3.5/5.0
- 无任何维度评分为1
  - 维度1（问题意识）≥ 3分
- 维度2（学术增量）≥ 3分

### 回退条件（任一触发）

- 五维综合评分 < 3.5/5.0
- 任意维度评分为1
- 维度1（问题意识）< 3分
- 维度2（学术增量）< 3分

### 回退后的操作

回退不意味着放弃选题。回退后作者根据修改建议调整选题，然后重新提交检查。

常见调整方向：
- 问题意识不清→缩小选题范围，聚焦到具体问题
- 增量空间不足→调整切入角度，寻找已有研究的缺口
- 可行性不足→缩小选题规模或调整研究方法
- 规范深度不足→增加规范分析层次或调整选题方向
- 实践关联弱→增加案例分析或调整选题指向

## 快速通道

如果五维综合评分 ≥ 4.5/5.0，且无任何维度低于4分，选题质量优秀，可直接进入环节2（思路梳理），后续环节可启用简化模式。

## 输出底线

- 不替作者选题。只评估已选题目。
- 评分必须附带具体理由，不能只给分。
- 文献摸底必须真实搜索，不能凭记忆判断"有没有人写过"。
- 修改建议必须可操作——不说"选题需要改进"，说"选题范围过大，建议聚焦到XX条文的XX问题"。
- 实践关联度评估必须检查是否有真实案例，不能凭想象判断。
