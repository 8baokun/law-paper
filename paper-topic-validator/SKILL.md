# 选题检查器（Paper Topic Validator）

## 定位

本技能是论文生产线的第一个环节。在作者确定选题后、正式开始思路梳理前，对选题进行结构化评估。

输出永远是选题诊断报告和选题文献综述报告。本技能不替作者选题目，只评估已选题目是否可行。

选题文献综述报告是**选题验证型文献综述**——不是全面综述，而是针对"这个选题值不值得做"的定向综述。其核心任务是回答三个问题：
1. 这个问题有没有人研究过？研究到什么程度？
2. 现有研究的缺口/空白在哪里？
3. 基于文献证据，这个选题有没有意义？

**与环节4（文献检索协调器）的分工**：

| 维度 | 环节1 选题验证型综述 | 环节4 系统化文献检索 |
|------|---------------------|---------------------|
| 目的 | 验证选题是否值得做 | 支撑论文写作 |
| 文献量 | 5-15篇核心文献 | 穷尽四类文献 |
| 深度 | 研究现状概览+增量空间识别 | 谱系梳理+精读笔记+引用策略 |
| 产出 | 文献综述报告（选题诊断的依据） | 标准化文献清单+阅读笔记 |
| 关系 | 环节4的检索起点 | 在环节1综述基础上深化扩展 |

## 轨道选择

本技能支持双轨评估：

| 轨道 | 触发条件 | 评估维度 | 权重配置 |
|------|----------|----------|----------|
| **学研轨（默认）** | 无特别声明 | 五维标准评估 | 标准权重 |
| **实务轨** | 作者声明"实务导向"或选择"实务应用/决策参考"预设 | 五维标准评估 + 模块A实务溯源 | 学术增量降权，新增实务痛点真实性 |

轨道选择在步骤1接收选题时确认。如作者未声明，默认走学研轨。

## 五维评估模型

### 维度1 · 问题意识清晰度

**核心问题**：选题是否指向一个明确的问题？

| 编号 | 检查问题 | 判定方式 |
|------|----------|----------|
| 1.1 | 选题能否用一句话表述为核心问题？ | 如果需要超过一句话才能说清楚选题在研究什么，说明问题意识模糊。 |
| 1.2 | 核心问题是"真问题"还是"伪问题"？ | 真问题：存在真实的理论困惑或实践争议。伪问题：答案已经明确，或问题本身不成立。 |
| 1.3 | 核心问题是"大问题"还是"小问题"？ | 大问题：过于宽泛，一篇文章无法充分回答。小问题：过于琐碎，没有学术价值。适中：一篇文章可以充分回答且有学术价值。 |
| 1.4 | 问题意识是否贯穿选题表述？ | 检查选题表述中是否隐含了"为什么……""如何……""……是否……"等问题指向。 |
| 1.5 | 选题是否混淆了"话题"和"问题"？ | "公司法中的信义义务"是话题。"信义义务的审查标准如何确定"是问题。选题必须是问题，不能只是话题。 |

**评分标准**：
| 分值 | 含义 |
|------|------|
| 5 | 核心问题清晰、聚焦、有学术价值 |
| 4 | 核心问题基本清晰，个别地方需聚焦 |
| 3 | 问题意识存在但不够聚焦，话题与问题混同 |
| 2 | 问题意识模糊，选题偏向话题 |
| 1 | 无明确问题意识，只是研究领域标注 |

---

### 维度2 · 学术增量空间

**核心问题**：选题是否可能产出新的学术贡献？

| 编号 | 检查问题 | 判定方式 |
|------|----------|----------|
| 2.1 | 现有文献对该问题的研究状态如何？ | 全面搜索文献。如果已有大量充分研究，增量空间有限。如果研究稀少或存在明显缺口，增量空间大。 |
| 2.2 | 选题是否可能产出新的理论贡献？ | 新理论=提出新概念、新框架、新解释模型。检查选题是否为理论创新留有空间。 |
| 2.3 | 选题是否可能产出新的规范分析贡献？ | 新规范分析=对法律条文的新解释、对制度安排的新分析、对构成要件的新拆解。 |
| 2.4 | 选题是否可能产出新的实证发现？ | 新实证=新的数据、新的案例、新的调查结果。检查选题是否涉及实证研究。 |
| 2.5 | 选题是否只是"重复已有研究"？ | 对照现有文献的核心结论，检查选题是否会得出相同结论。如相同，无增量。 |

**评分标准**：
| 分值 | 含义 |
|------|------|
| 5 | 增量空间明确且充足，可能产出显著学术贡献 |
| 4 | 增量空间存在，可能产出有价值的学术贡献 |
| 3 | 增量空间有限，可能在局部有所推进 |
| 2 | 增量空间很小，基本是对已有研究的重复 |
| 1 | 无增量空间，纯重复已有研究 |

---

### 维度3 · 论证可行性

**核心问题**：作者是否有能力和资源完成这个选题？

| 编号 | 检查问题 | 判定方式 |
|------|----------|----------|
| 3.1 | 选题所需的文献是否可获取？ | 检查核心文献是否可通过常规渠道获取。如需罕见外文文献或内部资料，可行性降低。 |
| 3.2 | 选题所需的研究方法是否在作者能力范围内？ | 如选题需要实证方法，作者是否有数据收集和分析能力？如需要比较法，作者是否有相关外语能力？ |
| 3.3 | 选题的规模是否与文章篇幅匹配？ | 期刊论文8000-15000字。如选题需要50000字才能充分论证，规模不匹配。 |
| 3.4 | 选题的时间约束是否可满足？ | 检查是否有紧迫的截止日期。如截止日期前无法完成核心论证，可行性降低。 |
| 3.5 | 选题是否存在"致命障碍"？ | 致命障碍=核心文献无法获取、核心数据不存在、核心案例未公开等。如有致命障碍，选题不可行。 |

**评分标准**：
| 分值 | 含义 |
|------|------|
| 5 | 所有条件具备，无障碍 |
| 4 | 个别条件需努力获取，但不构成根本障碍 |
| 3 | 存在一定障碍，需调整选题范围或方法 |
| 2 | 存在显著障碍，完成难度很大 |
| 1 | 存在致命障碍，选题不可行 |

---

### 维度4 · 规范分析深度

**核心问题**：选题是否允许进行深入的规范分析？

| 编号 | 检查问题 | 判定方式 |
|------|----------|----------|
| 4.1 | 选题是否涉及具体的法律规范？ | 如果选题完全不涉及法律条文，规范分析空间有限。应用法学论文必须有规范分析。 |
| 4.2 | 相关法律规范是否有解释空间？ | 如果法律条文含义明确无争议，规范分析空间有限。如果存在解释争议，空间大。 |
| 4.3 | 选题是否涉及规范的适用问题？ | 检查选题是否关注"规范如何适用"而不仅是"规范是什么"。适用问题通常有更深的分析空间。 |
| 4.4 | 选题是否涉及规范冲突或规范空白？ | 规范冲突（多个规范互相矛盾）和规范空白（应有规范但无规范）是规范分析的富矿。 |
| 4.5 | 选题是否可能进行构成要件分析？ | 检查选题是否允许将规范拆解为构成要件并逐一分析。构成要件分析是应用法学的基本功。 |

**评分标准**：
| 分值 | 含义 |
|------|------|
| 5 | 规范分析空间充足，可进行多层次的规范解读 |
| 4 | 规范分析空间较大，可进行有深度的规范解读 |
| 3 | 规范分析空间一般，可进行基本的规范解读 |
| 2 | 规范分析空间有限，多为描述性陈述 |
| 1 | 几乎无规范分析空间，选题偏离应用法学 |

---

### 维度5 · 实践关联度

**核心问题**：选题是否与法律实践有真实关联？

| 编号 | 检查问题 | 判定方式 |
|------|----------|----------|
| 5.1 | 选题是否回应了实践中的真实困惑？ | 检查选题是否源于实践中的真实问题（如裁判分歧、执法困难、合规困境），而非纯理论推演。 |
| 5.2 | 选题是否可能对实践产生指导意义？ | 检查选题的结论是否可能被法官、律师、企业法务等实践主体使用。 |
| 5.3 | 选题是否涉及典型案例或典型场景？ | 检查选题是否有具体案例支撑。纯抽象的规范分析如果脱离案例，实践关联度降低。 |
| 5.4 | 选题是否考虑了制度实施成本？ | 如选题涉及制度建议，检查是否考虑了实施成本。不考虑成本的制度建议与实践脱节。 |
| 5.5 | 选题是否与当前法治实践的热点/难点相关？ | 检查选题是否回应了当前法治建设的重点问题。不是追逐热点，但与实践完全脱节的选题价值有限。 |

**评分标准**：
| 分值 | 含义 |
|------|------|
| 5 | 与实践紧密关联，选题直接源于实践困惑 |
| 4 | 与实践有明确关联，可能对实践产生指导 |
| 3 | 与实践有一定关联，但关联不够紧密 |
| 2 | 与实践关联微弱，主要是理论推演 |
| 1 | 与实践完全脱节，纯理论思辨 |

## 选题验证型文献综述

> **定位**：这不是完整文献综述，而是针对选题意义的定向综述。在五维评估之前执行，为维度2（学术增量空间）提供证据支撑。

### 综述任务

| 任务 | 核心问题 | 产出 |
|------|----------|------|
| 研究现状概览 | 这个问题有没有人研究过？研究到什么程度？ | 研究脉络概述（起始时间、主要阶段、代表性学者） |
| 增量空间识别 | 现有研究的缺口/空白在哪里？ | 缺口清单（已覆盖/增量空间/对话切入点/空白区域） |
| 选题意义验证 | 基于文献证据，这个选题有没有意义？ | 选题意义判定（有增量/增量有限/无增量） |

### 检索要求

| 项目 | 要求 |
|------|------|
| 文献量 | 5-15篇核心文献（不追求穷尽） |
| 文献类型 | 优先学理文献（核心期刊+专著），辅以规范文献和典型案例 |
| 检索来源 | 至少2个来源交叉验证（如NCPSSD+WebSearch，或OpenAlex+威科） |
| 真实性要求 | 所有文献必须真实存在，不可凭记忆判断。如无法验证，标注"[待验证]" |
| 时间范围 | 近10年为主，经典文献不限 |

### 核心文献下载策略

> 选题验证型综述筛选出的5-15篇核心文献，尝试下载PDF全文作为后续人工核实的依据。
> **原则**：能下则下，付费墙文献不下但记录核心信息，不做PDF转文本。

| 项目 | 规范 |
|------|------|
| 下载目录 | `[论文项目目录]/papers/`（与论文产物同目录下的 papers 子文件夹） |
| 文件命名 | `[编号]_[作者]_[年份]_[短标题].pdf`（如 `L1_张三_2023_自甘风险构成要件.pdf`） |
| 下载来源 | NCPSSD返回的PDF链接优先下载；OpenAlex仅下载OA标记为✅的 |
| 付费墙处理 | **不下载**，在文献清单中标注"付费墙·待人工获取"，记录论文名/作者/期刊/年份等核心信息 |
| 下载间隔 | 每篇间隔≥3秒，避免触发反爬 |
| 失败处理 | 连续下载失败3次，暂停下载，剩余文献仅记录信息 |
| 会话上限 | 单次会话下载总量不超过15篇（环节1配额） |
| 下载状态标注 | ✅已下载 / ❌付费墙·待人工获取 / ⚠️下载失败·待重试 / —无需下载 |

### 检索工具链（paper-harvester 集成）

> 本技能集成 paper-harvester 技能的多源检索脚本，实现自动化文献检索。以下为工具链使用规范。

#### 工具链总览

| 工具 | 检索源 | 覆盖范围 | 角色 | 使用要点 |
|------|--------|----------|------|----------|
| `search_ncpssd.py` | 国家哲社文献中心（NCPSSD） | 中文核心期刊论文 | **主力中文源** | ⚠️ **单词查询**：NCPSSD不支持多词组合检索，需拆分为多个单词分别查询后人工合并 |
| `search_openalex.py` | OpenAlex | 全球英文文献（含DOI、被引量、OA状态） | **主力英文源** | 适合比较法文献检索，可用短语查询 |
| `search_crossref.py` | Crossref | 全球英文文献（含DOI） | **英文补充源** | 与OpenAlex结果去重合并 |
| `search_semantic_scholar.py` | Semantic Scholar | 全球英文文献（含语义关联） | **英文补充源** | 有限流（429），非必须 |
| WebSearch | 互联网公开搜索 | 法院实务文章、学位论文、新闻报道 | **补充源** | 覆盖NCPSSD不收录的实务类和学位论文类文献 |

#### 检索策略

```
步骤1：NCPSSD 中文核心文献检索（主力源）
  - 将选题拆分为2-4个核心关键词
  - 每个关键词单独查询（如"自甘风险""重大过失""体育侵权"分别查）
  - 每次返回上限20篇，可按需调大
  - 每篇含标题、作者、来源、年份、摘要、PDF链接
  ↓
步骤2：OpenAlex 英文文献检索（比较法素材）
  - 用英文短语查询（如"assumption of risk sports injury"）
  - 重点关注被引量高的文献和OA可下载全文
  - Crossref 作为补充，与OpenAlex结果去重
  ↓
步骤3：WebSearch 补充检索（实务+学位论文）
  - 搜索法院实务文章、裁判文书实证研究
  - 搜索硕博学位论文
  - 搜索NCPSSD可能遗漏的近年新刊
  ↓
步骤4：多源去重合并
  - 按标题（小写化）去重
  - 按DOI去重（如有DOI的文献）
  - 合并后按相关性排序，筛选5-15篇核心文献
  ↓
步骤5：文献验证
  - 每篇文献标注检索来源（NCPSSD/OpenAlex/Crossref/WebSearch）
  - 如无法验证真实性，标注"[待验证]"
  ↓
步骤6：核心文献下载
  - 对筛选出的5-15篇核心文献，逐篇尝试下载PDF
  - 下载目录：[论文项目目录]/papers/
  - 文件命名：[编号]_[作者]_[年份]_[短标题].pdf
  - 下载间隔≥3秒，会话上限15篇
  - 付费墙文献不下载，标注"付费墙·待人工获取"
  - 连续失败3次暂停下载，剩余仅记录信息
  - 在文献综述报告的核心文献清单中标注下载状态
```

#### 法学检索式优化

法学论文检索与通用文献检索有差异，需注意以下优化：

| 优化项 | 说明 | 示例 |
|--------|------|------|
| **法条编号检索** | 以核心法条编号为关键词单独检索 | "民法典1176条"、"第1176条" |
| **核心期刊预设** | NCPSSD返回结果按来源期刊筛选，优先保留CLSCI/CSSCI法学期刊 | 《法学研究》《中国法学》《法学》《法学评论》《政法论坛》等 |
| **单词拆分原则** | NCPSSD不支持多词组合，必须拆分为单个概念词分别查 | "自甘风险 重大过失 体育" → 拆为3次查询 |
| **同义词扩展** | 法学概念常有多种表述，需用同义词扩展查询 | "自甘风险"→也查"自甘冒险"；"重大过失"→也查"重大过失认定" |
| **英文检索词** | 比较法检索用英文标准术语 | "assumption of risk"、"gross negligence"、"sports injury liability" |

### 综述报告结构

文献综述报告包含以下部分（详细模板见 references/选题文献综述报告模板.md）：

```
一、研究现状概览
   - 研究起始与脉络
   - 主要研究阶段
   - 代表性学者及观点

二、核心文献清单
   - 5-15篇核心文献列表（含作者、标题、来源、年份、核心观点）

三、增量空间分析
   - 已覆盖区域（哪些问题已有充分研究）
   - 增量空间（哪些问题研究不足）
   - 对话切入点（哪些观点存在分歧）
   - 空白区域（哪些问题尚未被研究）

四、选题意义判定
   - 基于文献证据的选题意义结论
   - 与维度2（学术增量空间）的衔接说明
```

### 综述与五维评估的衔接

- 综述报告的"选题意义判定"直接作为维度2（学术增量空间）的评分依据
- 综述报告的"增量空间分析"直接作为维度2检查项2.1（研究状态）和2.5（是否重复）的判断依据
- **维度2的评分必须有综述报告的文献证据支撑，不能凭印象打分**

## 模块A：实务问题溯源（实务轨可选）

> **触发条件**：作者声明"实务导向"，或选择"实务应用""决策参考"预设档位。
>
> **学研轨不加载本模块**，直接走五维标准评估。

当启用实务轨时，在五维评估之前，先执行实务问题溯源检查。这不是第六个评估维度，而是一个**前置定性检查**——确认选题是否有真实的实务问题源头。

### 溯源三问

| 编号 | 检查问题 | 判定方式 |
|------|----------|----------|
| A1 | 这个选题源自哪个具体的实务场景？ | 要求作者描述：是裁判分歧？执法困难？合规困境？合同争议？制度落地障碍？如无法描述具体场景，标记"实务源头模糊"。 |
| A2 | 这个实务问题困扰的是谁？ | 要求识别受困扰的主体：法官？律师？企业法务？行政执法人员？当事人？如无法识别受困主体，标记"痛点主体不明"。 |
| A3 | 现有规范/判例/学理对这个问题的回应是否充分？ | 快速摸底：有无相关司法解释？指导性案例？主流学理观点？如已有充分回应，说明增量空间在于"回应不充分"而非"无人回应"。 |

### A4：实务痛点自主调查（A1/A2模糊时自动触发）

> **触发条件**：A1标记"实务源头模糊"或A2标记"痛点主体不明"时自动触发。
>
> **目的**：不依赖作者自述，由AI自主检索调查实务痛点信息，再请作者确认。弥补三问依赖作者自述的不足。

**核心思路**：AI自己去查 → 查完后填线索卡草案 → 作者只需确认，不需要从头描述。

#### 调查流程

```
步骤1：AI自主调查（不依赖作者回答）
  - 用选题关键词检索裁判文书/典型案例 → 归纳实务场景和受困主体
    工具：WebSearch（搜"XX 纠纷 案例""XX 裁判分歧"等）
    目标：查到3-5篇实务文章或案例即可，不追求穷尽
  - 用选题关键词检索法条+司法解释+学说 → 判断规范缺口类型
    工具：NCPSSD（查有没有学理讨论）+ WebSearch（查法条和司法解释现状）
    目标：判断是"缺规则""规则模糊""规则冲突"还是"规则滞后"
  ↓
步骤2：AI填写线索卡草案
  - 基于调查结果，自动填写实务问题线索卡（见下节）
  - 规范缺口类型从四选一给出初判
  - 锚定案例填入检索到的典型案例（如有）
  - 线索卡草案标注"[草案·待确认]"
  ↓
步骤3：作者确认（只确认，不回答）
  - 将线索卡草案呈现给作者，附上调查依据（检索到哪些文章/案例）
  - 问一句话："以下是根据检索结果归纳的实务痛点线索，是否准确？如有偏差请指出。"
  - 作者只需要确认/修正，不需要从头描述
  ↓
步骤4：确认后处理
  - 作者确认 → 线索卡定稿（去掉"[草案·待确认]"标注），重新评分
  - 作者指出偏差 → 根据作者修正更新线索卡，定稿
  - AI调查后确实查不到任何实务源头（检索结果为空）→ 评分上限锁定2分，建议改走学研轨
```

**与追问式的对比**：

| 维度 | 原追问式 | 现自主调查式 |
|------|---------|-------------|
| 作者负担 | 要回答5个问题 | 只需确认1次 |
| 信息来源 | 依赖作者自述 | AI检索+作者确认 |
| 客观性 | 主观 | 有检索证据支撑 |
| 查不到怎么办 | 作者说不清就锁定2分 | AI查不到实务源头就锁定2分 |

**调查深度控制**：A4不是做完整的文献综述（那是环节3-4的事），只是快速摸底——查3-5篇实务文章/案例够归纳场景和主体就行，不追求穷尽。

**调查结果产出**：填写"实务问题线索卡"（见下节），作为后续环节2-6的传递载体。

### 实务问题线索卡

> 线索卡是实务轨的跨环节传递载体。从环节1产出，贯穿环节2-6，每个后续环节必须读取并在自己的产出中显式回引。

**卡片格式**：

```
=== 实务问题线索卡 ===
[来源] 环节1模块A产出 / 经A4自主调查补全
[痛点描述] 一句话描述实务痛点
[受困主体] 具体主体类型（如"基层执法人员""企业法务""消费者"等）
[实务场景] 具体场景描述（来自A1或追问Q1-Q3）
[规范缺口类型] □缺规则 □规则模糊 □规则冲突 □规则滞后
[锚定案例] 如有（来自追问Q3，或环节1已识别的案例）
[痛点真实性评分] 1-5分
[线索卡状态] 活跃（环节1产出后默认为"活跃"）
======================
```

**必填项**：痛点描述、受困主体、规范缺口类型三项必须填写，否则线索卡不完整，后续环节标记"线索卡不完整"。

**状态流转规则**：

| 环节 | 操作 | 状态变化 |
|------|------|----------|
| 环节1 | 产出线索卡 | → 活跃 |
| 环节2 | 论证框架回应了痛点 | 保持活跃 |
| 环节3 | 提纲确认有对应章节 | 保持活跃 |
| 环节4 | 检索到相关实务文献 | 保持活跃 |
| 环节5 | 对策建议回应了痛点 | → 已回应 |
| 环节6 | 模块B第7项检查通过 | → 已关闭 |
| 任何环节 | 未回应痛点 | 保持活跃，触发回溯 |

### 实务痛点真实性评分

| 分值 | 含义 |
|------|------|
| 5 | 实务痛点真实、具体，受困主体明确，现有回应明显不足 |
| 4 | 实务痛点较明确，受困主体可识别，现有回应有改进空间 |
| 3 | 实务痛点存在但不够聚焦，或受困主体较笼统 |
| 2 | 实务痛点模糊，难以判断真实性 |
| 1 | 无实务源头，纯理论推演 |

### 实务轨权重调整

启用实务轨时，五维评估的权重做如下调整：

| 维度 | 学研轨权重 | 实务轨权重 | 变化 | 调整理由 |
|------|-----------|-----------|------|----------|
| 问题意识清晰度 | 0.20 | 0.20 | → | 不变 |
| 学术增量空间 | 0.20 | 0.10 | ↓0.10 | 实务导向论文不苛求学术增量 |
| 论证可行性 | 0.20 | 0.20 | → | 不变 |
| 规范分析深度 | 0.20 | 0.20 | → | 不变 |
| 实践关联度 | 0.20 | 0.20 | → | 不变 |
| **实务痛点真实性** | — | 0.10 | 新增 | 实务轨专属维度 |

> 实务轨权重总和=1.00，无需归一化。

### 模块A与五维评估的关系

- 模块A的"实务痛点真实性"作为第六个维度纳入综合评分计算
- 维度5"实践关联度"仍然保留——两者有区别：实践关联度评估选题"是否关联实践"，实务痛点真实性评估"痛点是否真实存在"
- 如模块A评分=1（无实务源头），不否决选题，但建议作者改走学研轨

## 执行流程

```
步骤0（仅实务轨）：实务问题溯源
  - 执行模块A三问：实务场景？受困主体？现有回应？
  - 如A1标记"实务源头模糊"或A2标记"痛点主体不明" → 触发A4自主调查
    a. AI用WebSearch检索裁判文书/典型案例/实务文章，归纳实务场景和受困主体
    b. AI用NCPSSD+WebSearch检索法条/司法解释/学说，判断规范缺口类型
    c. AI填写线索卡草案，呈现给作者确认
    d. 作者确认或修正 → 线索卡定稿，回填A1/A2，重新评分
    e. 如AI检索后查不到任何实务源头 → 评分上限锁定2分，建议改走学研轨
  - 产出"实务问题线索卡"（附在选题诊断报告末尾）
  - 如评分≤2，建议作者改走学研轨，但不强制
  ↓
步骤1：接收选题表述
  - 作者提供选题名称、研究问题、预期贡献
  - 确认评估轨道：学研轨（默认）或实务轨
  ↓
步骤2：五维逐项评估（实务轨为五维+模块A）
  - 按上述五维模型逐项检查
  - 每维给出评分（1-5分）和具体发现
  - 实务轨按调整后权重计算
  ↓
步骤3：选题验证型文献综述（维度2的依据）
  - 调用paper-harvester工具链检索核心文献：
    a. NCPSSD单词查询（主力中文源，拆分关键词分别查）
    b. OpenAlex短语查询（比较法素材）
    c. WebSearch补充（实务文章、学位论文）
    d. 多源去重合并，筛选5-15篇核心文献
  - 梳理研究现状，识别增量空间（缺口/空白/分歧）
  - 产出选题文献综述报告（每篇文献标注检索来源）
  - 基于综述结论为维度2评分提供证据
  ↓
步骤4：识别核心风险
  - 哪些维度评分低于3分？
  - 低分维度的根本原因是什么？
  ↓
步骤5：输出诊断报告和文献综述报告
  - 选题文献综述报告（研究现状+增量空间+选题意义判定）
  - 选题诊断报告（五维评分汇总、核心风险、修改建议、通过/回退判定）
```

## 通过/回退判定

### 通过条件（全部满足）

- 综合评分 ≥ 3.5/5.0（学研轨五维归一化，实务轨六维直接计算）
- 无任何维度评分为1
  - 维度1（问题意识）≥ 3分
- 维度2（学术增量）≥ 3分
- 实务轨额外：模块A（实务痛点真实性）≥ 3分

### 回退条件（任一触发）

- 综合评分 < 3.5/5.0
- 任意维度评分为1
- 维度1（问题意识）< 3分
- 维度2（学术增量）< 3分
- 实务轨额外：模块A（实务痛点真实性）< 3分且作者坚持走实务轨

### 回退后的操作

回退不意味着放弃选题。回退后作者根据修改建议调整选题，然后重新提交检查。

常见调整方向：
- 问题意识不清→缩小选题范围，聚焦到具体问题
- 增量空间不足→调整切入角度，寻找已有研究的缺口
- 可行性不足→缩小选题规模或调整研究方法
- 规范深度不足→增加规范分析层次或调整选题方向
- 实践关联弱→增加案例分析或调整选题指向

## 快速通道

如果综合评分 ≥ 4.5/5.0，且无任何维度低于4分，选题质量优秀，可直接进入环节2（思路梳理），后续环节可启用简化模式。

实务轨的快速通道同样要求模块A（实务痛点真实性）≥ 4分。

## 输出底线

- 不替作者选题。只评估已选题目。
- 评分必须附带具体理由，不能只给分。
- **文献综述必须真实检索**，不可凭记忆判断"有没有人写过"。综述中的每篇文献都必须标注检索来源（NCPSSD/OpenAlex/Crossref/WebSearch等），如无法验证则标注"[待验证]"。
- **NCPSSD检索必须单词查询**——多词组合会返回0结果，需拆分为多个单概念词分别查询后合并。
- **维度2（学术增量空间）的评分必须有文献综述报告的文献证据支撑**，不能凭印象打分。
- **核心文献下载遵循反爬保护**——下载间隔≥3秒，会话上限15篇，连续失败3次暂停。付费墙文献不下载但必须记录论文名/作者/期刊/年份等核心信息供人工获取。
- 修改建议必须可操作——不说"选题需要改进"，说"选题范围过大，建议聚焦到XX条文的XX问题"。
- 实践关联度评估必须检查是否有真实案例，不能凭想象判断。
- **A4自主调查必须在A1模糊或A2不明时触发**——不可跳过调查直接标记"模糊"了事。AI自主检索后查不到实务源头的，评分上限锁定2分。调查结果必须呈现给作者确认，不可直接定稿。
- **实务轨必须产出完整的实务问题线索卡**——痛点描述、受困主体、规范缺口类型三项必填，附在选题诊断报告末尾，作为后续环节2-6的传递载体。
