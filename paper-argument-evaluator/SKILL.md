# 应用法学论文学证强度评估器

## 概述

本技能是应用法学论文生产线的环节6。在环节5（论文写作）完成后、环节7（文风处理）之前，对论文初稿的论证强度进行全面评估。

本技能整合了两套评估能力：
- **法律论证强度评估框架**：六维/七维评估、四阶段流程、薄弱环节类型学、否决规则、置信度标注
- **投稿场景适配**：权重调整、学术增量核心标准、审稿人预判、修改建议优先级排序

### 模块B：第七维度"实操建议可落地性"（可选）

> **触发条件**：论文包含"对策""建议""路径""方案"等内容，或作者选择"实务应用/决策参考"预设。
>
> **学研标准预设不加载本模块**，走原始六维评估。

当论文提出了实操建议时，仅评估论证质量不够——还需要评估建议本身能否落地。模块B作为可选第七维度加载，权重从其他维度适当压缩。详见 `references/投稿场景权重详解.md`。

## 概述表格

| 项目 | 内容 |
|------|------|
| 能力类型 | 元认知/自我评估 |
| 核心功能 | 对论文中的论证进行强度评估，识别薄弱环节，预判审稿人质疑 |
| 输入 | 论文初稿（含核心命题、论证过程、引用文献） |
| 输出 | 论文学证强度评估报告（投稿场景） |
| 关键风险 | 过度自信导致遗漏风险、过度保守导致结论无用 |

## 法律声明

> **重要提示：** 本技能产出的论证强度评估仅为辅助分析工具，不构成对论文发表可行性的最终判断。论文能否发表取决于多种因素（选题价值、期刊偏好、审稿人主观判断等），论证强度只是其中之一。评估本身具有主观性，不同评估者可能得出不同结论。使用者应将评估结果作为参考而非定论。

## 一、核心概念

### 1.1 论证强度

论证强度（Argument Strength）是指论文从前提到结论的支撑力度，反映该论证在学术同行评审中的说服力。它不是一个二元判断（对/错），而是一个连续光谱上的定位。

### 1.2 六维/七维评估框架

| 维度 | 含义 | 投稿场景权重（六维） | 投稿场景权重（七维，含模块B） |
|------|------|--------------|--------------|
| **法源支撑充分性** | 论文引用的法条、司法解释等是否准确、完整、层级恰当 | 0.20 | 0.15 |
| **实证/案例基础充分性** | 案例选择是否有代表性、数据是否可靠、正反案例是否平衡 | 0.20 | 0.15 |
| **论证逻辑严密性** | 从前提到结论的推理过程是否存在逻辑跳跃或谬误 | 0.25 | 0.20 |
| **学术对话能力** | 是否与已有文献进行了实质对话、是否回应了不同观点 | 0.20 | 0.15 |
| **司法实践关联度** | 论文是否回应了司法实践中的真实问题 | 0.10 | 0.15 |
| **学术增量贡献度** | 论文是否有明确的学术增量、增量是否有充分论证 | 0.20 | 0.10 |
| **实操建议可落地性**（模块B，可选） | 建议是否有操作主体、操作路径、体制兼容性、成本效益 | — | 0.10 |

> 六维权重总和=1.15，使用时归一化处理。
> 七维权重总和=1.00，无需归一化。
> 模块B启用时，司法实践关联度权重从0.10提升至0.15（实务导向论文更看重实践关联），学术对话和学术增量各降0.05。

### 1.3 薄弱环节的类型学

| 薄弱环节类型 | 定义 | 严重程度 | 示例 |
|-------------|------|----------|------|
| **致命缺陷** | 足以推翻整个论证的根本性问题 | ★★★★★ | 引用已废止法条、捏造引用、核心命题无法成立 |
| **重大弱点** | 显著削弱论证说服力的问题 | ★★★★☆ | 关键论点缺乏文献支撑、存在强有力的反对观点未回应 |
| **中度风险** | 可能被审稿人利用但不致命的问题 | ★★★☆☆ | 案例选择代表性不足、概念使用不一致 |
| **轻度瑕疵** | 影响论证完美性但不影响核心结论 | ★★☆☆☆ | 引用格式不规范、个别论述顺序不佳 |
| **潜在隐患** | 当前不构成问题但可能在特定条件下暴露 | ★☆☆☆☆ | 立法修订趋势、司法政策变化风险 |

### 1.4 常见论证故障类型

> 以下11种论证故障在法学论文中高频出现，评估时须逐项排查。

| 编号 | 故障名称 | 定义 | 典型表现 | 对应维度 |
|------|----------|------|----------|----------|
| F01 | **循环论证** | 前提与结论互相支撑，论证空转 | "该条属于管理性规范，因为立法目的不是禁止行为而是管理行为；立法目的是管理行为，因为该条属于管理性规范" | 逻辑严密性 |
| F02 | **概念漂移** | 核心概念在论证过程中悄然变换内涵 | 第一章"合规"指制度层面合规体系，第三章"合规"变为操作层面合规行为，结论用第三章的含义回扣第一章的主张 | 逻辑严密性 |
| F03 | **以偏概全** | 从个别案例推出普遍结论，缺乏代表性论证 | 从2个案例归纳出"司法实践普遍认为" | 案例基础充分性 |
| F04 | **规范与描述混同** | 将"是什么"（描述）与"应当是什么"（规范）混用 | 从"实践中法院普遍这样做"直接推出"法院应当这样做"，跳过规范性论证 | 逻辑严密性 |
| F05 | **诉诸权威** | 以学者身份/职务替代论证本身 | "王泽鉴教授认为……故该观点成立"——不分析论证过程，只引用结论 | 学术对话能力 |
| F06 | **稻草人谬误** | 歪曲对方观点后反驳 | 将他人"有条件的认可"歪曲为"完全否定"后反驳 | 学术对话能力 |
| F07 | **虚假二分** | 将多元可能简化为非此即彼 | "要么认定为有效，要么认定为无效"，忽视效力待定、可撤销等中间状态 | 逻辑严密性 |
| F08 | **规范依据断裂** | 核心命题与援引法条之间缺少推理桥接 | 引用《民法典》第465条后直接得出"合同具有拘束力"的结论，跳过"拘束力"的规范内涵分析 | 法源支撑充分性 |
| F09 | **比较法滥用** | 选择性引用外国法，不论证可比性 | 只引用支持论点的外国制度，回避相反制度安排；不做功能比较只做概念比较 | 案例基础充分性 |
| F10 | **增量空心化** | 声称有学术增量但实际只是换表述 | "已有研究关注制度A，本文从制度B视角研究制度A"——换了视角但结论与已有研究一致 | 学术增量贡献度 |
| F11 | **对策悬空** | 建议无操作主体、无操作路径、无前提条件 | "应当完善相关立法""应当加强部门协作"——谁完善、怎么完善、何时完善均不明确 | 实操建议可落地性（模块B） |

## 二、完整工作流程

### 阶段一：论证解构

**目标：** 将论文中的论证拆解为可独立评估的组成部分。

**步骤1：识别论证结构**

```
1.1 提取核心结论（Conclusion）
    → 论文最终要证明什么？（核心命题）
1.2 提取主要前提（Premises）
    → 核心命题依赖哪些前置论点？
1.3 识别推理规则（Inference Rules）
    → 从前提到结论使用了什么推理方法？
    （演绎推理/归纳推理/类比推理/目的解释/体系解释等）
1.4 识别隐含假设（Hidden Assumptions）
    → 论证中有哪些未明示但必须成立的前提？
1.5 绘制论证链条图
    → 将上述要素组织为清晰的推理链条
```

**步骤2：标记评估节点**

```
对论证链条中的每个节点标记：
- [F] 事实节点：需要评估事实/案例基础
- [L] 法律节点：需要评估法源支撑
- [R] 推理节点：需要评估逻辑关系
- [A] 假设节点：需要评估隐含假设的合理性
- [V] 价值节点：需要评估价值判断的合理性
```

### 阶段二：逐维度评估（投稿场景）

**步骤3：评估法源支撑充分性**

```
检查清单：
□ 论文引用的法条是否准确？（逐条核对法条编号、内容、施行日期）
□ 法条引用是否标注了版本？（如《民法典》施行后仍引用旧法，需说明理由）
□ 司法解释引用是否准确？（检查名称、文号、内容）
□ 是否区分了法律、司法解释、部门规章？（混淆效力层级是学术瑕疵）
□ 引用的外国法是否准确？（比较法引用需标注法域、法源名称、译文出处）
□ 规范依据链条是否完整？（从上位法到下位法的层级是否覆盖）

评分标准：
- 5分：法源引用全面准确，效力层级清晰，无遗漏
- 4分：法源引用基本准确，存在细微疏漏
- 3分：法源引用存在个别错误或不完整
- 2分：法源引用存在明显错误（如引用已废止法条未说明）
- 1分：法源引用严重错误或大量缺失
```

**步骤4：评估实证/案例基础充分性**

```
检查清单：
□ 案例选择是否有代表性？（能否支撑论文的核心命题）
□ 案例数量是否足够？（规范分析型至少3-5个；实证研究型需更多）
□ 案例信息是否完整？（裁判文书号、裁判法院、裁判日期）
□ 是否存在选择性引用案例？（只引用支持论点的案例=选择性偏差）
□ 实证数据是否可靠？（来源是否可追溯）
□ 正反案例是否平衡？（反面案例是否被讨论）
□ 是否存在以偏概全？（F03：从个别案例推出普遍结论，缺乏代表性论证）
□ 是否存在比较法滥用？（F09：选择性引用外国法，不论证可比性）

评分标准：
- 5分：案例选择典型且充分，正反平衡，数据可靠
- 4分：案例选择较好，个别方面可加强
- 3分：案例选择基本可以，但代表性或平衡性不足
- 2分：案例选择有明显问题（选择性偏差或数量不足）
- 1分：缺乏案例支撑或案例严重不足
```

**步骤5：评估论证逻辑严密性**

```
检查清单：
□ 核心命题的论证链条是否完整？（从核心命题倒推，每个环节是否有支撑）
□ 是否存在逻辑跳跃？（前提不能直接推出结论=逻辑跳跃）
□ 概念使用是否前后一致？（概念漂移是学术硬伤）
□ 是否混淆了描述与规范？（"是什么"和"应当是什么"的混同）
□ 类比推理是否有实质相似性？（比较法研究中的类比需论证可比性）
□ 多步推理中每一步是否都经得起检验？
□ 是否存在循环论证？（F01：前提与结论互相支撑，论证空转）
□ 是否存在概念漂移？（F02：核心概念在论证中悄然变换内涵）
□ 是否存在规范与描述混同？（F04：从"是什么"直接推出"应当是什么"）
□ 是否存在虚假二分？（F07：将多元可能简化为非此即彼）
□ 是否存在规范依据断裂？（F08：法条与结论之间缺少推理桥接）
□ **主张是否超出材料状态？**（对照环节2标准化论证框架文档的"主张上限"标注——如材料状态为一级（仅有理论推演）但论文使用了"显著提升""实践证明"等三级措辞 → 标记"主张越级"）

评分标准：
- 5分：推理严密，逻辑无瑕疵，概念完全一致
- 4分：推理基本严密，存在可忽略的小瑕疵
- 3分：推理大体成立，但存在可被质疑的逻辑环节
- 2分：推理存在明显逻辑问题，需要补充论证
- 1分：推理存在根本性逻辑错误
```

**步骤6：评估学术对话能力**

```
检查清单：
□ 是否与已有文献进行了对话？（学术论文必须置于学术对话中）
□ 是否回应了主要的不同观点？（不能自说自话）
□ 回应是否有实质内容？（"某某观点值得商榷"不是有效回应）
□ 是否预见了审稿人可能的质疑？
□ 论证是否过于依赖单一视角？
□ 是否明确标注了自身观点在学术谱系中的定位？
□ 是否存在诉诸权威？（F05：以学者身份替代论证本身，只引用结论不分析过程）
□ 是否存在稻草人谬误？（F06：歪曲对方观点后反驳，如将"有条件的认可"歪曲为"完全否定"）
□ **转述是否忠实于原文？**（转述偏差检查——引用他人观点时是否：
  · 混淆了"作者自己的主张"与"作者转述的观点"与"作者反驳的对象"？
  · 扩大或缩小了原文的讨论范围？
  · 删除或弱化了原文的限定词，如把"可能"写成"必然"、把"有学者提出"写成"学界认为"、把"在特定场景下"写成"普遍"？）

评分标准：
- 5分：充分识别并有效回应了主要不同观点，对话有实质内容
- 4分：能回应大部分不同观点，个别回应力度一般
- 3分：存在较强不同观点，回应效果不确定
- 2分：存在难以有效回应的重大质疑
- 1分：完全缺乏学术对话，自说自话
```

**步骤7：评估司法实践关联度**

```
检查清单：
□ 论文是否回应了司法实践中的真实问题？
□ 案例分析是否反映了真实的裁判倾向？
□ 是否关注了指导性案例/公报案例？
□ 论文的结论是否对司法实践有参考价值？
□ 是否关注了司法实践的最新动态？

评分标准：
- 5分：紧密结合司法实践，结论对实践有明确指导价值
- 4分：与司法实践有较好关联
- 3分：涉及司法实践但关联不够紧密
- 2分：基本脱离司法实践
- 1分：纯理论推演，与司法实践完全脱节
```

**步骤8：评估学术增量贡献度**

```
检查清单：
□ 论文是否有明确的学术增量？（理论/规范分析/实证方面的新贡献）
□ 增量是否被清晰表述？（"本文在XX方面推进了XX研究"必须具体）
□ 增量是否有充分论证支撑？（增量不能只停留在主张层面）
□ 增量是否与已有研究区分？（"已有研究认为A，本文认为B"）
□ 增量的学术价值是否足够？（微小增量可能不足以发表）
□ 是否存在增量空心化？（F10：声称有增量但实际只是换表述，结论与已有研究一致）

评分标准：
- 5分：增量明确且有价值，论证充分，与已有研究区分清晰
- 4分：增量较明确，但表述或论证可加强
- 3分：存在增量但不突出，或表述不够清晰
- 2分：增量模糊，难以判断与已有研究的区别
- 1分：缺乏学术增量，属于重复研究
```

**步骤8B：评估实操建议可落地性（模块B，可选）**

> **触发条件**：论文包含"对策""建议""路径""方案"等内容，或选择"实务应用/决策参考"预设。
>
> **学研标准预设跳过本步骤**。

```
检查清单：
□ 建议是否有明确的操作主体？（谁来做——主管部门/执行主体是否真实存在）
□ 建议是否有明确的操作路径？（怎么做——具体步骤是否可执行）
□ 建议是否与现行体制兼容？（能不能做——是否与现行行政/司法体制兼容）
□ 建议是否有成本效益分析？（值不值得做——实施成本是否合理）
□ 建议是否标注了前提条件？（在什么条件下这个建议才成立）
□ 建议是否考虑了地域差异？（不同地区的实践差异是否被考虑）
□ 是否存在对策悬空？（F11：建议无操作主体、无操作路径、无前提条件——"应当完善相关立法"式空话）
□ 【线索卡闭环】建议是否回应了线索卡中的实务痛点？（对照线索卡的痛点描述和受困主体，检查对策建议是否直接回应。如未回应→评分扣分，触发回溯到环节5）

评分标准：
- 5分：建议完全可落地，操作主体明确，路径清晰，体制兼容，成本合理
- 4分：建议基本可落地，个别环节需进一步完善
- 3分：建议有可落地性，但操作主体或路径不够清晰
- 2分：建议落地困难，体制不兼容或成本过高
- 1分：建议无法落地，脱离实际

特别注意：
- 如建议涉及的主管部门不存在或职责权限不匹配 → 评分≤2
- 如建议与现行法律冲突且未说明解决方案 → 评分≤2
- 如建议完全不考虑实施成本 → 评分≤3
```

### 阶段三：综合评定

**步骤9：计算综合强度评分**

```
六维加权计算公式（学研标准预设）：
综合评分 = 法源支撑充分性 × 0.20 + 实证/案例基础充分性 × 0.20 +
           论证逻辑严密性 × 0.25 + 学术对话能力 × 0.20 +
           司法实践关联度 × 0.10 + 学术增量贡献度 × 0.20

归一化：综合评分 = 加权总分 / 1.15

七维加权计算公式（实务应用/决策参考预设，含模块B）：
综合评分 = 法源支撑充分性 × 0.15 + 实证/案例基础充分性 × 0.15 +
           论证逻辑严密性 × 0.20 + 学术对话能力 × 0.15 +
           司法实践关联度 × 0.15 + 学术增量贡献度 × 0.10 +
           实操建议可落地性 × 0.10

（七维权重总和=1.00，无需归一化）

注意：存在致命缺陷时，无论综合评分如何，整体评级应降至"弱"或"极弱"。
```

**步骤10：确定论证强度等级**

| 综合评分 | 强度等级 | 含义 | 投稿建议 |
|----------|----------|------|----------|
| 4.5-5.0 | **极强** | 论证几乎无懈可击 | 建议投稿 |
| 3.5-4.4 | **强** | 论证有力，存在轻微不足 | 建议投稿 |
| 2.5-3.4 | **中等** | 论证有一定说服力，但存在明显不足 | 修改后投稿 |
| 1.5-2.4 | **弱** | 论证说服力不足 | 大修后投稿 |
| 1.0-1.4 | **极弱** | 论证基本不成立 | 不建议投稿 |

**流程通过线与回退规则**（本技能SKILL.md为唯一权威源）：

| 分界线 | 阈值 | 含义 | 动作 |
|--------|------|------|------|
| **流程通过线** | 综合评分 ≥ 3.0 | 论证达到可进入环节7的最低标准 | 通过 → 进入环节7（文风处理） |
| **回退线** | 综合评分 < 3.0 | 论证未达最低标准 | 回退到环节5（重写论证部分） |
| **投稿建议线** | 综合评分 ≥ 3.5 | 论证质量足以建议投稿 | 投稿建议标注"建议投稿" |
| **修改后投稿线** | 3.0 ≤ 综合评分 < 3.5 | 论证通过流程线但需修改 | 投稿建议标注"修改后投稿" |

> 注：流程通过线（3.0）是"能否进入下一环节"的及格线；投稿建议线（3.5）是"投稿建议等级"的分界线。两者不冲突——评分3.0-3.4的论文通过流程但投稿建议为"修改后投稿"。

**步骤11：标注薄弱环节**

```
对每个识别出的薄弱环节，记录：
1. 环节位置：在论证链条中的具体位置
2. 薄弱类型：致命缺陷/重大弱点/中度风险/轻度瑕疵/潜在隐患
3. 具体描述：该环节为何薄弱
4. 影响范围：该薄弱环节影响论证的哪些部分
5. 投稿影响：审稿人可能如何利用该薄弱环节
6. 可修复性：是否可以通过修改来修复
7. 修复建议：如何加强该环节
```

### 阶段四：元评估

**步骤12：评估自身评估的置信度**

```
对整个评估过程进行反思：
□ 我是否充分理解了论文的完整论证？
□ 我是否可能存在确认偏差？
□ 我是否遗漏了重要的评估维度？
□ 我的评分是否受到锚定效应影响？
□ 该领域是否存在我不了解的最新发展？

元置信度等级：
- 高置信度：评估基于充分信息，方法论适当，结论可靠
- 中置信度：评估基于合理信息，但存在信息缺口或方法论局限
- 低置信度：评估基于有限信息，结论仅供参考
```

## 三、否决规则

### 原版否决规则（5条）

```
规则1（致命缺陷否决规则）：
  IF 任一维度评分 = 1 AND 该维度为法源支撑充分性或实证/案例基础充分性
  THEN 整体评级 ≤ "弱"，无论综合评分如何

规则2（短板效应规则）：
  IF 任意两个及以上维度评分 ≤ 2
  THEN 整体评级 ≤ "中等"

规则3（一致性校验规则）：
  IF 综合评分与直觉判断差异 > 1个等级
  THEN 触发复核流程，重新审视各维度评分

规则4（领域特殊规则）：
  IF 论文涉及刑事案件 AND 实证/案例基础充分性 ≤ 3
  THEN 整体评级自动降一级

规则5（信息不足降级规则）：
  IF 元置信度 = "低"
  THEN 在最终评级后附加"[信息不足，评估可靠性有限]"标注
```

### 投稿场景否决规则（4条）

```
规则6（学术不端否决规则）：
  IF 存在学术不端行为（抄袭、伪造数据、伪造引用）
  THEN 直接否决，不进入强度评估

规则7（增量缺失否决规则）：
  IF 学术增量贡献度 = 1
  THEN 整体评级 ≤ "弱"，无论综合评分如何
  说明：没有学术增量的论文不具备投稿价值

规则8（法源错误否决规则）：
  IF 引用的法条已废止且未说明理由
  OR IF 引用的法条编号/内容错误
  THEN 法源支撑充分性 ≤ 2，且标注为"致命缺陷"

规则9（选择性偏差否决规则）：
  IF 案例分析存在明显的选择性引用（只引用支持论点的案例，回避反面案例）
  AND 未对此作出说明
  THEN 实证/案例基础充分性 ≤ 2

规则10（引注格式严重缺陷否决规则）：
  IF 参考文献存在系统性引注格式缺陷（依据《法学引注手册》检查）
  缺陷类型包括：
    · 期刊论文/教材普遍缺少页码（第45条）
    · 司法解释普遍缺少文号（第64条）
    · 案例案号普遍不完整或格式错误（第71条）
    · 网络文献普遍缺少访问日期（第48条）
  THEN 标注为"引注格式缺陷"，要求回退环节5修正引注
  说明：引注格式是学术规范的基本面，系统性缺陷影响投稿成功率

规则11（文献幻觉否决规则）：
  IF 发现以下任一情况：
    · 捏造引用（引用的文献实际不存在——作者真实、期刊真实但论文未发表）
    · 转述歪曲（文献真实存在，但论文引用时歪曲了原文核心观点——
      如把"介绍的观点"写成"作者的主张"，把"有条件的"写成"普遍的"，
      把"可能存在关联"写成"存在因果关系"）
    · 字段系统性错误（大量引用的年份/卷期/页码与原文不符）
  THEN 标注为"致命缺陷"，要求回退环节4（文献检索）重新核验或环节5（论文写作）修正引用
  说明：文献幻觉是AI辅助写作最危险的风险——书目全对但观点被歪曲，
  比完全捏造更隐蔽，审稿人发现后直接拒稿
```

## 四、置信度标注体系

### 4.1 维度评分置信度

| 标注符号 | 含义 | 使用场景 |
|----------|------|----------|
| `[确定]` | 评分基于明确的法律规定或确凿事实 | 法条明确、事实无争议 |
| `[较确定]` | 评分基于充分但非绝对的依据 | 有主流观点支撑但存在少数不同意见 |
| `[不确定]` | 评分基于有限信息或存在较大争议 | 法律空白、事实不明、裁判分歧 |
| `[推测]` | 评分基于推断而非直接依据 | 缺乏直接信息，基于经验或类比判断 |
| `[待验证]` | 评分依赖于尚未核实的信息 | 需要进一步检索或确认 |


## 回溯协议

- 如综合评分 < 3.0 → 回退到环节5（论文写作），需重新撰写薄弱章节
- 如模块B第7项（线索卡闭环检查）未通过 → 单独触发回退到环节5，重写对策建议部分使其直接回应线索卡痛点
- 如存在致命缺陷 → 回退到环节5，需修正致命缺陷后重新评估
- 如发现文献幻觉（捏造引用/转述歪曲/字段系统性错误）→ 回退到环节4重新核验文献或环节5修正引用
- 如学术增量贡献度 ≤ 2 → 回退到环节2（思路梳理），需重新梳理论证框架
- 如法源引用存在致命错误 → 回退到环节4（文献检索），需重新核查法源
- 如核心命题无法成立 → 回退到环节1（选题检查），需重新选题

## 快速通道

- 如上游环节（环节3+环节4+环节5）综合评分均 ≥ 4.5 → 环节6可启用简化模式：
  - 仅评估法源支撑充分性和论证逻辑严密性两个核心维度
  - 快速扫描是否存在致命缺陷
  - 使用简要输出模板
- **但环节6不可跳过**——无论上游质量多高，投稿前必须进行论证强度核验
