# 投稿场景权重调整详解

## 权重对比总表

| 维度 | 原版权重（常规案件） | 投稿场景权重 | 变化 | 调整原因 |
|------|----------------------|--------------|------|----------|
| 法源支撑充分性 | 0.25 | 0.20 | ↓0.05 | 法源引用是基本功，区分度不如其他维度 |
| 实证/案例基础充分性 | 0.25 | 0.20 | ↓0.05 | 并非所有应用法学论文都依赖实证数据 |
| 论证逻辑严密性 | 0.20 | 0.25 | ↑0.05 | 逻辑严密性是学术论文的核心质量指标 |
| 学术对话能力 | 0.15 | 0.20 | ↑0.05 | 学术对话能力直接影响审稿通过率 |
| 司法实践关联度 | 0.10 | 0.10 | → | 不变 |
| 学术增量贡献度 | 0.05 | 0.20 | ↑0.15 | 学术增量是期刊投稿的核心标准 |

> 投稿场景权重总和=1.15，使用时归一化处理（除以1.15）。

## 各维度投稿场景评估要点详解

### 维度1：法源支撑充分性（权重0.20）

**与原版的差异**：从"法律依据确定性"调整为"法源支撑充分性"。原版关注"所援引法律规范是否现行有效、效力层级是否足够"，投稿场景在此基础上增加学术引用规范的要求。

**投稿场景特殊检查项**：

| 检查项 | 评估方式 | 常见问题 |
|--------|----------|----------|
| 法条版本标注 | 引用须标注施行日期和版本 | 引用旧法未说明理由 |
| 效力层级区分 | 法律/司法解释/规章不可混淆 | 将部门规章等同于法律 |
| 规范链条完整性 | 从上位法到下位法的层级覆盖 | 缺少中间层级规范 |
| 比较法引用规范 | 标注法域、法源名称、译文出处 | 只标注国名不标注法源 |
| 规范性质标注 | 区分强制性/任意性/宣示性规范 | 将宣示性条款当作创设性条款 |

**评分锚点**：
- 5分示例：某论文分析《合规管理办法》第26条，逐条标注了该办法的文号、施行日期，区分了部门规章与法律的效力层级，规范链条从《公司法》到《企业内控基本规范》到《合规管理办法》完整覆盖。
- 2分示例：某论文引用了《合规管理办法》但未标注文号和施行日期，且将其中宣示性条款当作强制性规范使用。

### 维度2：实证/案例基础充分性（权重0.20）

**与原版的差异**：从"事实基础充分性"调整为"实证/案例基础充分性"。原版关注证据的充分性，投稿场景关注案例的代表性和平衡性。

**投稿场景特殊检查项**：

| 检查项 | 评估方式 | 常见问题 |
|--------|----------|----------|
| 案例代表性 | 案例能否支撑核心命题 | 选取边缘案例当典型 |
| 案例数量 | 规范分析型≥3-5个 | 只有1-2个案例 |
| 案例信息完整 | 文书号、法院、日期 | 缺少文书号 |
| 正反平衡 | 正反案例都讨论 | 只讨论支持论点的案例 |
| 实证数据可靠性 | 数据来源可追溯 | 数据来源不明 |
| 案例类型覆盖 | 指导性/公报/普通案例 | 只有普通案例 |

**选择性偏差的识别**：
- 如论文讨论的所有案例都支持论文观点，而实际存在大量反面案例 → 选择性偏差
- 如论文只引用了某一种类型的案例（如只引一审不引二审） → 选择性偏差
- 如论文引用的案例都来自同一法院 → 代表性不足

### 维度3：论证逻辑严密性（权重0.25，提升）

**与原版的差异**：权重从0.20提升到0.25。学术论文对逻辑严密性的要求高于法律实务。

**投稿场景特殊检查项**：

| 检查项 | 评估方式 | 常见问题 |
|--------|----------|----------|
| 论证链条完整性 | 从核心命题倒推每个环节 | 存在断链 |
| 概念一致性 | 核心概念在全文定义一致 | 概念漂移 |
| 描述与规范区分 | "是"与"应当"不混同 | 从描述直接推导规范 |
| 类比可比性 | 比较法类比论证可比性 | 未论证可比性 |
| 循环论证 | 结论不在前提中出现 | 用结论证明结论 |

**概念漂移的识别**：
- 第一章定义"业法财融合=A"，第三章使用"业法财融合=B"，B≠A → 概念漂移
- 如概念有演变，须在文中明确说明演变过程和原因

**描述-规范混淆的识别**：
- "第26条规定了X"（描述）→"因此企业应当X"（规范）：如果没有论证"规定的就是应当的"，存在逻辑跳跃
- "外国法规定了X"（描述）→"中国也应当规定X"（规范）：如果没有论证可比性和移植必要性，存在逻辑跳跃

### 维度4：学术对话能力（权重0.20，提升）

**与原版的差异**：从"反驳抗辩力"调整为"学术对话能力"。原版关注能否抵御可预见的反对意见，投稿场景关注与学术共同体的对话。

**投稿场景特殊检查项**：

| 检查项 | 评估方式 | 常见问题 |
|--------|----------|----------|
| 文献对话 | 是否与已有文献对话 | 自说自话 |
| 不同观点回应 | 是否回应主要不同观点 | 回避不同观点 |
| 回应实质内容 | 回应是否有实质内容 | "值得商榷"了事 |
| 审稿人预判 | 是否预见审稿人质疑 | 未换位思考 |
| 视角多元性 | 是否依赖单一视角 | 视角单一 |

**有效对话 vs 无效对话**：

| 类型 | 示例 | 评价 |
|------|------|------|
| 有效对话 | "张三教授基于A理由认为X，本文基于B理由认为Y，分歧在于C" | 识别+理解+回应 |
| 部分有效 | "张三教授认为X，本文不同意" | 识别但未实质回应 |
| 无效 | "有学者持不同观点" | 未识别是谁、什么观点 |
| 无效 | "张三教授的观点值得商榷" | 未说明商榷理由 |

### 维度5：司法实践关联度（权重0.10，不变）

**与原版的差异**：从"司法实践一致性"调整为"司法实践关联度"。原版关注结论是否与主流裁判一致，投稿场景关注论文是否回应了司法实践中的真实问题。

**投稿场景特殊检查项**：

| 检查项 | 评估方式 | 常见问题 |
|--------|----------|----------|
| 实践问题回应 | 是否回应司法实践真实问题 | 纯理论推演 |
| 裁判倾向反映 | 案例分析是否反映真实倾向 | 选取不代表主流的案例 |
| 指导性案例关注 | 是否讨论相关指导性案例 | 忽略已有指导性案例 |
| 实践参考价值 | 结论对实践是否有参考价值 | 结论无实践意义 |
| 最新动态关注 | 是否纳入最新裁判趋势 | 使用过时案例 |

### 维度6：学术增量贡献度（权重0.20，大幅提升）

**与原版的差异**：从"价值判断合理性"调整为"学术增量贡献度"。权重从0.05大幅提升到0.20。这是投稿场景最重要的调整——学术增量是期刊投稿的核心标准。

**投稿场景特殊检查项**：

| 检查项 | 评估方式 | 常见问题 |
|--------|----------|----------|
| 增量明确性 | 是否有明确的学术增量 | "本文有创新"但不说创新什么 |
| 增量表述清晰 | "本文在XX方面推进了XX"是否具体 | 模糊表述 |
| 增量论证支撑 | 增量是否有论证而非主张 | 只主张不论证 |
| 与已有研究区分 | "已有研究A，本文B" | 未与已有研究区分 |
| 增量价值 | 增量是否有发表价值 | 微小增量 |

**增量类型**：

| 增量类型 | 说明 | 示例 |
|----------|------|------|
| 理论增量 | 提出新的理论框架或概念 | 提出业法财融合的规范构造理论 |
| 规范分析增量 | 对法条的新解释 | 对第26条的新解释路径 |
| 实证增量 | 新的实证发现 | 首次对该制度实施效果的实证分析 |
| 方法增量 | 使用新的研究方法 | 首次用法律经济学方法分析该问题 |
| 比较法增量 | 引入新的比较法视角 | 首次系统比较中外该制度 |

## 按论文类型的权重微调

上述权重是投稿场景的默认配置。根据论文类型，可做微调：

| 论文类型 | 微调建议 | 理由 |
|----------|----------|------|
| 制度分析型 | 逻辑严密性权重可提升至0.30 | 制度分析的核心是逻辑推演 |
| 规范解释型 | 法源支撑权重可提升至0.25 | 解释论研究以法源为核心 |
| 实证研究型 | 案例基础权重可提升至0.30 | 实证研究的核心是数据 |
| 比较法研究型 | 学术对话权重可提升至0.25 | 比较法研究需与外国学理对话 |

微调后须重新归一化，确保权重总和=1.0。
