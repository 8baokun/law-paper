# 评估偏差防范与特殊场景处理

> 本文件从SKILL.md外移，包含评估偏差防范（常见错误表+常见陷阱表）和特殊场景处理规则。

---

## 一、常见错误与防范

### 1.1 致命错误表

| 编号 | 错误名称 | 错误描述 | 后果 | 防范措施 |
|------|----------|----------|------|----------|
| E01 | **过度自信偏差** | 系统性高估论证强度 | 误导投稿决策 | 强制执行"魔鬼代言人"检查 |
| E02 | **确认偏差** | 倾向于寻找支持论文的证据 | 评估失去客观性 | 在评估前明确列出可能的反面论据 |
| E03 | **锚定效应** | 被论文的自信表述影响评分 | 评分偏离实际质量 | 将论证内容与表述风格分离评估 |
| E04 | **遗漏致命缺陷** | 未识别出根本性问题 | 给出虚假的高评级 | 严格执行前置验证和否决规则 |
| E05 | **维度混淆** | 将不同维度的问题混为一谈 | 评估结构混乱 | 严格按维度逐一评估 |
| E06 | **忽视学术增量** | 只评估论证质量不评估增量 | 高估重复研究的价值 | 增量缺失否决规则（规则7） |
| E07 | **静态评估** | 未考虑法律变化趋势 | 评估结论可能过时 | 标注时效性和变化因素 |

### 1.2 常见陷阱

| 陷阱 | 表现 | 应对 |
|------|------|------|
| **权威崇拜** | 因为引用了权威学者就给高分 | 评估论证本身的逻辑 |
| **复杂性幻觉** | 论证越复杂越觉得有说服力 | 复杂论证更可能隐藏漏洞 |
| **数量偏差** | 论据数量多就给高分 | 关注论据质量而非数量 |
| **新颖性偏差** | 对新颖论证过于宽容或苛刻 | 以相同标准评估 |
| **结果导向** | 因为结论"看起来合理"就给高分 | 严格评估推理过程 |
| **忽视沉默** | 未注意论文回避了什么 | 主动检查论文是否回避不利问题 |

## 二、特殊场景处理

### 2.1 法律空白场景

```
当论文涉及法律空白（无直接法律规定）时：
1. 法源支撑充分性维度评分上限为3分
2. 重点评估类推适用的合理性
3. 增加对法律原则、立法目的的评估权重
4. 明确标注"法律空白"风险
5. 建议关注立法动态和司法解释趋势
```

### 2.2 新型问题场景

```
当论文涉及新型法律问题（无先例可循）时：
1. 司法实践关联度维度标注为"不适用"或降低权重
2. 增加学术增量贡献度的权重
3. 重点评估论证的内在逻辑一致性
4. 标注"新型问题，结论不确定性高"
```

### 2.3 多论证竞争场景

```
当论文提出了与主流观点不同的论证时：
1. 对论文论证独立评估
2. 同时评估主流观点的论证强度
3. 制作比较表格，逐维度对比
4. 评估论文论证在审稿人面前的可能表现
5. 重点关注学术对话能力维度
```
