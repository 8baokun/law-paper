# 去AI腔（De-AI Polish）

## 定位

本技能检测并去除文章中的AI化表述模式。不改变文章的核心观点和论证逻辑，只处理表达层面的AI痕迹。

与lawbox原版的区别：去除了法律工作总控绑定（案件隔离、事项路径、台账等），保留了全部检测规则和改写方法，增加了论文写作场景的适配。

## 何时使用

- 用户要求检测/去除文章中的AI腔、AI味道、AI痕迹
- 论文初稿完成后进入文风处理环节（生产线环节7）
- 用户要求润色、优化文本表达
- 上游环节（argument-evaluation-patch或academic-writing-patch）输出后需要文风处理

## 执行流程

```
步骤1：完整阅读文章
  - 理解核心观点和论证逻辑
  - 识别文章风格和表达习惯
  ↓
步骤2：按检测规则逐类扫描
  - 先扫"绝对禁止类"（规则1-14），这些在任何情况下都应去除
  - 再扫"弹性检测类"（规则15-18），根据上下文判断
  ↓
步骤3：判断是否修改
  - 不是所有匹配都需要修改
  - 判断标准：是否真的影响表达自然度？是否符合文章整体风格？是否有特定修辞目的？
  ↓
步骤4：重新表述
  - 核心原则：重新表述整个句子，不要只删除词汇
  - 理解原句想表达的核心意思，用自然的方式重新组织语言
  ↓
步骤5（可选）：注入个人风格
  - 弹性表达、思维过程展示、自然过渡
  - 目标比例：学术严谨性60% / 个人化40%
```

## 检测模式与修改模式

### 检测模式（detect）

逐段扫描文章，标注AI痕迹，输出检测报告：

```
## 去AI腔检测报告

**扫描范围**：全文 / 指定段落
**AI痕迹总数**：[N]处

### 按类别统计

| 类别 | 命中数 | 严重程度 |
|------|--------|----------|
| 对比句式 | [N] | 🔴高 |
| 程式化连接词 | [N] | 🔴高 |
| 结尾姿态句 | [N] | 🔴高 |
| 口语化表述 | [N] | 🟡中 |
| 绝对化表述 | [N] | 🟡中 |
| 工整排比 | [N] | 🟢低 |
| 学术自我指涉 | [N] | 🔴高 |
| 标签式概括 | [N] | 🟡中 |

### 逐条标注

| 位置 | 原文 | 类别 | 问题 | 建议改写 |
|------|------|------|------|----------|
| 第X段 | "..." | [类别] | [具体问题] | [改写建议] |
```

### 修改模式（fix）

直接在原文上进行改写，输出修改后的完整文章。修改原则：

1. **重新表述，而非删除标记词**——"它更像一种框架"不应改为"这是一种框架"（生硬），应改为"这符合框架的特征"
2. **保持上下文逻辑连贯**
3. **避免使用固定替换模板**
4. **保持语言的多样性和个性**

## 输出底线

- 不改变文章的核心观点和论证逻辑，只处理表达层面的AI痕迹。
- 检测模式必须逐条标注位置、原文、类别和建议改写，不能只说"有AI腔"。
- 修改模式必须重新表述整个句子，不能只删除标记词。
- 弹性检测类（规则15-18）的修改必须说明判断理由，不能无理由修改。
- 论文场景下，学术术语的引号和列表（如规范列举）属于合理使用，不应去除。
- 中文文档默认使用中文全角引号（""、''），去除半角英文引号。
