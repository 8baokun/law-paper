# 去AI腔（De-AI Polish）

## 定位

本技能检测并去除法学学术论文中的AI化表述模式。不改变文章的核心观点和论证逻辑，只处理表达层面的AI痕迹。

与lawbox原版的区别：去除了法律工作总控绑定，保留了全部检测规则和改写方法，增加了论文写作场景的适配。

与humanizer skill的区别：humanizer面向通用文本（博客、文章），本技能专门面向法学学术论文，检测规则和改写方向均基于真实法学论文的写作特征校准。

## 何时使用

- 用户要求检测/去除文章中的AI腔、AI味道、AI痕迹
- 论文初稿完成后进入文风处理环节（生产线环节7）
- 用户要求润色、优化文本表达
- 上游环节（argument-evaluation-patch或academic-writing-patch）输出后需要文风处理

## 双重体系

本技能同时运行两套标准：

**负向体系（检测规则）**——18类AI痕迹检测规则，扫描"AI会怎么写"的特征
**正向体系（写作特征参照）**——从100篇真实法学论文提炼的"真人学者怎么写"的特征

改写时两套标准同时起作用：
- 负向标准判断"这句话有没有AI痕迹"
- 正向标准判断"改写后这句话读起来像不像真人学者写的"

只有同时满足两套标准——去掉了AI痕迹，且改写后的文本符合真人法学学者的写作习惯——才算合格的改写。

## 执行流程

```
步骤1：完整阅读文章
  - 理解核心观点和论证逻辑
  - 识别文章的学科分支（法理学/宪法/民法/刑法/诉讼法等）和对应的学术话语习惯
  - 判断文章类型（学理轨/实务轨），实务轨论文的改写应保留实务用语
  ↓
步骤2：读取正向参照
  - 按需读取 references/法学论文写作特征.md
  - 重点理解：句式特征、连接过渡特征、论证结构特征、开头结尾特征
  - 这些特征不是用来模仿的模板，而是判断"改写后是否像真人写的"的参照系
  ↓
步骤3：按检测规则逐类扫描
  - 先扫"绝对禁止类"（规则1-14），这些在任何情况下都应去除
  - 再扫"弹性检测类"（规则15-18），根据上下文判断
  - 每检测到一处，同时检查正向参照：真人在此处会怎么写？
  ↓
步骤4：判断是否修改
  - 不是所有匹配都需要修改
  - 判断标准：
    · 是否真的影响表达自然度？
    · 是否符合法学学术论文的整体风格？
    · 是否有特定修辞目的？
    · 正向参照中是否有类似用法被真人学者合理使用？
  - 如果正向参照中真人学者也这么写，即使匹配了检测规则，也不应修改
  ↓
步骤5：重新表述
  - 核心原则：重新表述整个句子，不要只删除词汇
  - 理解原句想表达的核心意思，用真人法学学者的表述方式重新组织语言
  - 参照正向特征：
    · 用条件/让步从句替代平行结构
    · 用语义衔接替代程式化连接词
    · 用具体判断替代空洞强化词
    · 让引用嵌入论证，不要罗列观点
    · 每步论证给出限定条件
  ↓
步骤6：润色前后语义比对（防止润色强化判断）
  - 润色可能删掉限定词、强化判断力度，导致语义偏离原文
  - 逐段比对润色前后，重点检查以下高危模式：
    · 限定词删除："可能"→"必然"/"一定"；"通常"→"总是"；"在特定场景下"→"普遍"
    · 归属升级："有学者提出"→"学界认为"/"研究表明"；"部分研究显示"→"研究证实"
    · 关系强化："相关"→"导致"/"造成"；"有关联"→"有因果关系"
    · 范围扩大："在某些情况下"→"在所有情况下"；"部分"→"全部"
  - 如发现上述模式，须恢复原文限定词或调整表述使语义与原文一致
  - 此步骤不可跳过——润色阶段是文献幻觉（第三类：正文误用）的高发区
  ↓
步骤7：改写质量校验
  - 朗读测试：改写后的段落读起来是否自然？
  - 节奏测试：是否有长短句交替，还是句式均匀？
  - 论证测试：改写是否保持了原文的论证链条完整性？
  - 风格测试：改写后是否像有学术训练的人写的，而不是像博客或公文？
  - 如任何一项不通过，回到步骤5重新表述
```

## 检测模式与修改模式

### 检测模式（detect）

逐段扫描文章，标注AI痕迹，输出检测报告：

```
## 去AI腔检测报告

**扫描范围**：全文 / 指定段落
**AI痕迹总数**：[N]处

### 按类别统计

| 类别 | 命中数 | 严重程度 |
|------|--------|----------|
| 对比句式 | [N] | 🔴高 |
| 程式化连接词 | [N] | 🔴高 |
| 结尾姿态句 | [N] | 🔴高 |
| 口语化表述 | [N] | 🟡中 |
| 绝对化表述 | [N] | 🟡中 |
| 工整排比 | [N] | 🟢低 |
| 学术自我指涉 | [N] | 🔴高 |
| 标签式概括 | [N] | 🟡中 |
| 论文八股开头 | [N] | 🔴高 |
| 虚假深度分析 | [N] | 🔴高 |

### 逐条标注

| 位置 | 原文 | 类别 | 问题 | 建议改写 | 正向参照 |
|------|------|------|------|----------|----------|
| 第X段 | "..." | [类别] | [具体问题] | [改写建议] | [真人学者类似语境的写法] |
```

### 修改模式（fix）

直接在原文上进行改写，输出修改后的完整文章。修改原则：

1. **重新表述，而非删除标记词**——"它更像一种框架"不应改为"这是一种框架"（生硬），应改为"这符合框架的特征"
2. **保持上下文逻辑连贯**——改写不能断裂原文的论证链条
3. **避免使用固定替换模板**——同一个AI痕迹在不同语境下的改写方式应不同
4. **保持语言的多样性和个性**——不要把所有句子都改成同一种风格
5. **参照真人学者的写作特征**——改写后的表述应符合法学论文的学术话语习惯

## 输出底线

- 不改变文章的核心观点和论证逻辑，只处理表达层面的AI痕迹。
- **润色不得强化判断力度**——润色前后须逐段比对语义，不得删除限定词（"可能""通常""在特定场景下"）、不得升级归属（"有学者提出"→"学界认为"）、不得强化关系（"相关"→"导致"）。如发现，须恢复原文限定词。
- 检测模式必须逐条标注位置、原文、类别和建议改写，不能只说"有AI腔"。
- 修改模式必须重新表述整个句子，不能只删除标记词。
- 弹性检测类（规则15-18）的修改必须说明判断理由，不能无理由修改。
- **改写后须通过正向参照校验**——改写后的文本应符合法学论文写作特征，不能去掉AI腔后变成博客腔或公文腔。
- 论文场景下，学术术语的引号和列表（如规范列举）属于合理使用，不应去除。
- 正文中偶尔使用"笔者""本文认为"是法学论文的规范表达，不是AI痕迹，不应去除。摘要中的"本文"才是AI痕迹。
- 中文文档默认使用中文全角引号（""、''），去除半角英文引号。
- 改写不得引入原文没有的法条、判例、学说——改写只处理表达层面，不增加实质内容。
