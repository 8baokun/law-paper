# 报告腔检测（补充检测场景）

> 本文件是 de-ai-polish 规则1-18的补充检测场景，不新增规则编号。
> 适用对象：素材来自工作报告、调研报告、年度总结的论文初稿。
> 与AI腔的区别：AI腔来自生成式AI的痕迹，报告腔来自国企/机关工作文风的残留。两者是不同的"污染源"，检测和改写方向不同。

## 一、什么是报告腔

论文作者在国企、机关、事业单位工作，论文素材常从工作报告、调研报告、年度总结中提取。这些材料带有鲜明的工作汇报文风，直接搬进学术论文会形成"报告腔"——看起来规范、正式，但不符合学术论文的表述习惯。

报告腔的本质是**自我评价式语言**和**口号式成效表述**——工作报告需要展示工作成果，所以天然倾向使用没有判定标准的正面评价词；学术论文需要论证和证据，不需要自我表扬。

## 二、报告腔特征清单

### 特征1：空壳自我评价

**表现**：使用没有客观判定标准的正面评价词，读者无法验证。

| 报告腔 | 问题 | 改写方向 |
|--------|------|----------|
| "取得了显著成效" | "显著"无标准 | 列出具体数据或可验证的指标 |
| "运行平稳" | "平稳"无标准 | 给出运行时间、故障率等具体数据 |
| "效果良好" | "良好"无标准 | 改为可验证的功能描述 |
| "获得了广泛认可" | "广泛"无标准 | 列出认可的主体和形式 |
| "具有较强的可操作性" | "较强"无标准 | 说明操作步骤和条件 |

### 特征2：口号式成效表述

**表现**：用口号句式概括成效，没有论证过程。

| 报告腔 | 问题 | 改写方向 |
|--------|------|----------|
| "迈上了新台阶" | 口号，无实质信息 | 改为具体变化：从X变为Y |
| "实现了全覆盖" | "全覆盖"需验证 | 说明覆盖的范围和验证方式 |
| "形成了闭环" | "闭环"需论证 | 说明闭环的构成环节和反馈机制 |
| "做到了应管尽管" | 口号式绝对化 | 改为具体管理范围和标准 |
| "打造了XX体系" | "打造"是工作用语 | 改为"构建了""建立了" |

### 特征3：相对时间无绝对日期

**表现**：使用"近年来""近期""目前"等相对时间词，不标注绝对日期。

| 报告腔 | 问题 | 改写方向 |
|--------|------|----------|
| "近年来，合规管理……" | "近年来"无起止 | 标注具体年份或时间范围 |
| "近期出台的……" | "近期"不可查 | 标注文件名称和发布日期 |
| "目前实践中……" | "目前"是写作时点 | 标注数据截止日期 |
| "下一步将……" | 工作计划用语 | 改为"未来应当"或"有待" |

### 特征4：工作部署句式

**表现**：使用工作部署/动员句式，论文不需要动员读者。

| 报告腔 | 问题 | 改写方向 |
|--------|------|----------|
| "要深刻认识……的重要性" | 动员句式 | 改为描述+分析 |
| "必须高度重视……" | 指令句式 | 改为论证其重要性的理由 |
| "应当进一步加大……力度" | 部署句式 | 改为具体建议+前提条件 |
| "切实做好……工作" | 工作用语 | 删除"工作"，改为具体行为 |
| "深入推进……" | 工作用语 | 改为具体推进措施 |

### 特征5：成效归因过度简化

**表现**：将多因素结果归因于单一因素，报告腔的典型逻辑跳跃。

| 报告腔 | 问题 | 改写方向 |
|--------|------|----------|
| "通过XX机制，实现了XX目标" | 归因单一化 | 改为"XX机制是促成XX目标的重要因素之一" |
| "得益于……，成效明显" | 因果简化 | 补充其他因素或限定条件 |
| "在……的推动下，取得了……" | 归因过度 | 改为"……与……存在关联" |

## 三、检测流程

```
1. 识别来源：论文素材是否来自工作报告/调研报告/年度总结？
   - 是 → 启动报告腔检测
   - 否 → 仅按规则1-18检测AI腔

2. 逐段扫描五个特征清单
   - 每命中一处，标注特征编号和具体问题

3. 判断是否改写
   - 如该处是论文的实证分析部分，引用了报告数据 → 保留数据，改写评价词
   - 如该处在论证部分 → 按改写方向改写
   - 如该处在引言/背景介绍 → 可适当保留工作用语，但需标注来源

4. 改写质量校验
   - 改写后是否仍有报告腔残留？
   - 改写后是否符合学术论文的客观表述习惯？
   - 改写是否保持了原文的论证信息量？（不能因为去掉评价词而丢失信息）
```

## 四、与AI腔检测的关系

| 维度 | AI腔（规则1-18） | 报告腔（本文件） |
|------|-----------------|----------------|
| 来源 | 生成式AI的痕迹 | 国企/机关工作文风的残留 |
| 典型表现 | 程式化连接词、学术自我指涉、平行排比 | 空壳自我评价、口号式成效、工作部署句式 |
| 检测时机 | 所有论文 | 素材来自工作报告的论文 |
| 改写方向 | 像真人学者写的 | 像客观分析的，不是自我表扬的 |
| 重叠区域 | "全面""有效"等空洞强化词同时被两个体系命中 → 按AI腔规则处理 |

> 两个体系同时运行时，先按规则1-18处理AI腔，再按本文件处理报告腔。如同一处同时命中两个体系，按AI腔规则优先处理。
