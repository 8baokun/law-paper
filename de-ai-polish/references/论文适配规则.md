# 论文适配规则

> 处理法学学术论文时的特殊检测和改写规则。在通用检测规则基础上追加适用。
>
> 本文件基于《法学研究》等核心期刊100篇真实论文的写作特征校准。

---

## 一、论文中的合理使用（不应去除）

以下模式在法学学术论文中属于合理使用，不应被当作AI痕迹去除：

### 1. 学术术语的引号

- 首次引入的核心概念可以加引号：如"结构耦合""二值代码"（但注意全角引号）
- 法学术语首次出现时加引号标注是学术惯例，不是AI痕迹
- **判断标准**：如果该术语在后续文中不再加引号，说明首次加引号是合理的

**正向参照**：
- "拉伦茨将法律漏洞定义为'违反计划的不圆满性'"——首次定义加引号
- "'法律发现说'认为"——学说名称加引号
- "'不得违背公序良俗'的适用条件"——法条原文加引号

### 2. 规范列举的列表

- 法条条文列举、构成要件列举属于必要的列表使用
- "该条规定的构成要件为：①……②……③……"是学术规范，不是AI痕迹
- **判断标准**：列表内容是"规范性列举"还是"观点堆积"

**正向参照**：
- "法律漏洞的两个重要特征：（1）对于某一个案，欠缺可以适用的法律规定；（2）法律上应当有可以适用于该个案的规定。"——行内编号列举构成要件，是学术规范

### 3. "一方面…另一方面"的学术用法

- 在分析制度功能的双重性时，"一方面…另一方面"是合理的分析框架
- **判断标准**：如果两方面的内容确实构成对立统一关系，保留；如果只是强行凑对，去除

**正向参照**：
- "一方面通过终结本次执行及执行和解来规避压力，另一方面通过周期性启动运动式执行来缓解压力。"——两方面描述不同策略，有实质内容

### 4. 比较法研究的对比结构

- "大陆法系…而英美法系…"是比较法研究的标准分析结构
- 这不是AI式的对比句式，而是学术分析的必要工具
- **判断标准**：对比是否有实质性的学术意义

### 5. 让步式转折

- "当然……但是……"在学术论证中用于预判反对意见并作出回应
- 属于论证回路闭合的一部分，不是AI痕迹
- **判断标准**：让步的内容是否有实质性的论证功能

**正向参照**：
- "否定说不承认法律漏洞的存在，意味着司法上无漏洞填补之必要。然而，司法实践总会面临无法律规则可适用的情形，若坚持彻底否定的态度，司法将无法及时应对社会之发展变迁。"——先陈述对立观点，再转折反驳

### 6. 正文中的"笔者"和"本文"

- 正文中使用"笔者"表达学术立场是法学论文的规范表达
- 正文中偶尔使用"本文"表明立场或解释选择是可接受的
- **判断标准**：是否有实质功能（表明立场、区分观点、解释选择），还是空洞的自我指涉

**正向参照**：
- "笔者对此持否定态度"——区分自己与他人观点
- "本文持'肯定说'之观点"——表明学术立场
- "本文特意选用'违约获益交出责任'这一概念"——解释概念选择

### 7. 法学专业表述

以下表述是法学论文的学术规范，不是AI痕迹：
- "自不待言""毋庸赘述""概因""有鉴于此"
- "本文持肯定说之观点""本文支持介入说的立场"
- "该定义被引入我国后，逐渐成为……通说"
- "参见""转引自"等引用标注

## 二、论文中的高发AI痕迹（重点检测）

以下模式在法学学术论文中特别高发，需重点检测：

### 1. 学术八股开头

**AI痕迹**：
- "随着……的不断发展，……问题日益凸显"
- "近年来，……受到了学界的广泛关注"
- "在……背景下，……问题的研究具有重要意义"
- "本文拟从……角度出发，对……问题进行深入探讨"

**改写方向**：
- 用具体问题或争议开头
- 用文献中的观点分歧开头
- 用制度实践中的矛盾现象开头
- 用立法现状或制度缺失开头

**正向参照**：
- "执行难是人民法院面临的突出问题，具体表现为法院执行措施难以实施。"——从具体问题开头
- "关于'违约获益'及其法律处置，我国民法典并无明文。"——从立法现状开头
- "权利冲突是21世纪初我国法学界的研究热点之一，曾在法理学界和部门法学界引发激烈争论。"——从学术争议开头
- "法律漏洞填补是法学方法论的传统议题，也是立法和司法实践面临的常见难题。"——从概念定位开头

### 2. 虚假深度的分析短语

**AI痕迹**：
- "这一制度安排深刻反映了……的价值取向"
- "上述分析充分揭示了……的内在逻辑"
- "这一现象的背后，是……的深层原因"
- "这不仅是……问题，更是……问题"

**改写方向**：
- 删除"深刻""充分""深层"等虚假深度修饰词
- 将"不仅是A更是B"改为"A和B两个层面"
- 直接陈述分析结论，不加修饰性评价

**正向参照**：
- "说理论证是司法裁判的内生性要求"——直接判断，不用"深刻反映"
- "上述不同版本的定义，都是通过发展'违反计划的不圆满性'这一定义得来的"——直接分析，不用"充分揭示"

### 3. 公式化的"挑战与展望"结尾

**AI痕迹**：
- "尽管该制度仍面临诸多挑战，但其发展方向是明确的"
- "未来，随着……的完善，……问题将得到更好的解决"
- "这一问题的解决需要学界和实务界的共同努力"
- "本文的研究仅为初步探索，尚有待进一步深入"

**改写方向**：
- 用具体的制度建议结尾
- 用尚未解决的问题清单结尾
- 直接陈述结论，删除公式化展望
- "本文的研究仅为初步探索"可改为具体的局限说明

**正向参照**：
- "承认违约获益交出责任的独立性，既无需高昂的制度变革成本，亦能与现有的制度和概念体系有效衔接，是一个可行的选择。"——直接陈述结论
- "本文的经验材料主要来源于对中部地区基层法院的调研，在区域经济社会发展不平衡的背景下，东、中、西部地区基层法院的执行情况必然存在一定的差异。"——指出具体局限
- "穷尽规则引入（引入论证），方可无规则填补（创设论证）。"——以论证原则收束

### 4. 过度抽象的概括句

**AI痕迹**：
- "这一制度安排具有深刻的现实意义"
- "该规则的确立对于法治建设具有重要的推动作用"
- "这一分析框架为相关研究提供了新的视角"

**改写方向**：
- "具有深刻的现实意义" → 具体说明意义是什么
- "具有重要的推动作用" → 具体说明推动的是什么
- "提供了新的视角" → 具体说明新在哪里

**正向参照**：
- "导致同案不同判现象的发生，凸显了填补方法的选择、排序之难题"——具体说明问题是什么
- "为司法裁判的说理论证带来现实困难"——具体说明困难是什么

### 5. 强行关联的"从…到…"结构

**AI痕迹**：
- "从理论建构到制度实践"
- "从宏观框架到微观操作"
- "从规范分析到实证检验"

**改写方向**：
- 检查"从…到…"是否描述了真实的递进关系
- 如果只是修饰性的大词堆砌，改为具体的研究内容
- "从理论建构到制度实践" → "本文先讨论理论框架，再分析制度实施"

### 6. "深入探讨"等空洞学术动词

**AI痕迹**：
- "本文拟对……进行深入探讨"
- "本文将深入分析……"
- "对……进行了全面系统的分析"

**改写方向**：
- "深入探讨" → "分析""考察""讨论"
- "深入分析" → "分析"
- "全面系统的分析" → 直接说明分析了什么

**正向参照**：
- "本文的研究重点即在于此"——简洁说明研究重点
- "以下分析……"——直接引出分析

## 三、引号规范（论文场景）

### 应使用中文全角引号

- 上引号：""（U+201C）
- 下引号：""（U+201D）
- 不使用半角英文引号 `"..."" '...'`
- 不使用直角引号「」（除非引用日文文献）

### 引号配对规则

- 上引号与下引号必须成对出现
- 奇数为上引号，偶数为下引号
- 修改后必须校验配对完整性

### 不需要引号的情况

- 法条名称不加引号：《民法典》不加引号
- 案件名称不加引号
- 普通法学术语不加引号（除非首次引入需特别标注）
- 描述性短语、比喻性描述、动作描述不加引号

## 四、论文去AI腔的平衡原则

### 不可过度去AI化

去AI腔的目的是让文章读起来像人写的，不是让文章失去学术性。以下情况不应去除：

1. **必要的学术规范表达**：如"笔者认为""本文认为"（正文中的使用）是学术论文的规范表达
2. **必要的限定语**：如"在一般情况下""就规范层面而言"是学术严谨性的体现
3. **必要的引用标注**：如"参见""转引自"是学术规范
4. **必要的逻辑连接**：如"与此相关""需要指出的是"在有实质逻辑功能时应保留

### 目标比例

- 学术严谨性60%：核心概念准确、论证逻辑清晰、学术规范遵守
- 个人化40%：弹性表达、思维过程展示、自然的句子节奏

### 判断标准

改写后的文章应该满足：
- 读起来像一个有学术训练的人写的
- 不像AI生成的（没有AI痕迹）
- 也不像口语化的博客（保持学术性）
- 有作者的声音（有立场、有判断、有风格）

### 改写不得引入的内容

- 不得引入原文没有的法条、判例、学说
- 不得引入原文没有的数据、案例
- 不得改变原文的论证立场（从肯定改为否定，或反之）
- 不得改变原文的论证结构（增删论证层次）
- 改写只处理表达层面，不增加实质内容
