# 改写示例库

> 本文件提供各类AI化表述的改写对比示例。仅在需要具体改写参考时读取。

---

## 一、重新表述原则

### 核心原则

重新表述整个句子，不要只删除词汇。

### 错误方式 vs 正确方式

| 原句 | 删除式修改（×） | 重新表述（✓） |
|------|------------------|----------------|
| 它其实是第二类问题 | 这是第二类问题 | 这属于第二类问题 |
| 这里其实有三种可能 | 这里有三种可能 | 此处存在三种可能性 |
| 天然会形成这种结构 | 会形成这种结构 | 通常会形成这种结构 |
| 会更清楚这一点 | 更清楚这一点 | 这样可以更好地理解这一点 |
| 它更像一种框架 | 这是一种框架 | 这符合框架的特征 |

## 二、对比句式改写

| 原句 | 改写 |
|------|------|
| 不是A而是B | 直接陈述B，或拆为两个独立陈述句 |
| 并非A而是B | 直接陈述B |
| 不在于A在于B | B是关键因素 |
| 看似在讲A，实则在讲B | 文章表面上讨论A，但核心关注的是B |
| 与A是两回事 | A和B存在显著差异（如需对比则具体说明差异） |
| 与A不等同于B | A和B在功能上存在区分 |

## 三、程式化连接词改写

| 原句 | 改写 |
|------|------|
| 首先，A。其次，B。 | A。在此基础上，B。/ 直接按逻辑顺序陈述，不用序数词 |
| 一方面A，另一方面B | A，同时B / A，而B |
| 综上所述 | 删除，直接陈述结论 |
| 总而言之 | 删除，直接陈述结论 |
| 然而 | 但 / 删除，用句号断开后直接转折 |
| 因此 | 删除，用因果逻辑自然衔接 |

## 四、结尾姿态句改写

| 原句 | 改写 |
|------|------|
| 方向已经明确 | 删除，用具体的下一步行动结尾 |
| 未来可期 | 删除，用具体的事实或数据结尾 |
| 拭目以待 | 删除，直接结束 |
| 这只是开始 | 删除，或改为"当前进展仅覆盖了[具体范围]" |
| 尽管面临挑战，机遇与挑战并存 | 删除，或改为具体的风险和应对措施 |
| 我们将继续关注 | 删除 |

## 五、绝对化表述改写

| 原句 | 改写 |
|------|------|
| 本质上 | 通常 / 在某种程度 / 就其基本特征而言 |
| 从根本上说 | 通常 / 一般而言 |
| 必然 | 往往 / 多半 / 可能 |
| 真正的 | 删除"真正的"，直接陈述 |
| 天然 | 通常 / 一般情况下 |
| 其实 | 删除"其实"，直接陈述 |
| 立刻/马上 | 随后 / 在短期内 |
| 并不是一个绝对命题 | 这个问题没有简单的是非答案 |
| 标志着关键时刻 | 在[具体时间/事件]中起到重要作用 |
| 不可或缺的组成部分 | 重要组成部分 |
| 为…奠定基础 | 对…有重要影响 |

## 六、工整排比改写

| 原句 | 改写 |
|------|------|
| 既要A，又要B，还要C | 需要同时处理A、B和C三个方面（改为简单列举） |
| 讲清楚A、讲清楚B、讲清楚C | 需要阐明A、B和C（去掉重复结构） |
| 三个"讲清楚" | 改为混合结构的陈述句 |

## 七、口语化表述改写

| 原句 | 改写 |
|------|------|
| 迟早得拆 | 需要考虑拆分 / 应当拆分 |
| 肯定行 | 通常可行 / 一般情况下有效 |
| 跑偏 | 偏离预期 / 出现偏差 |
| 很顺 | 顺畅 / 流畅 |
| 接下来要盯的东西 | 接下来需要关注的是 |
| 搞定 | 完成 / 处理 |
| 作为X的Y | X是Y |
| 设有Z个W | 有Z个W |
| 坐落于 | 位于 / 在 |

## 八、论文场景特化改写

以下示例针对法学学术论文中常见的AI痕迹：

| 原句 | 改写 | 说明 |
|------|------|------|
| 这一制度安排本质上是对效率价值的追求 | 这一制度安排主要体现了效率价值取向 | 去掉"本质上"的绝对化 |
| 法治建设必然要求…… | 法治建设通常要求…… | 去掉"必然"的绝对化 |
| 这种做法看似合理，实则存在重大缺陷 | 这种做法存在以下问题：…… | 去掉对比句式，直接陈述问题 |
| 综上所述，上述分析充分表明…… | 上述分析表明…… | 去掉"综上所述"和"充分" |
| 这不仅是一个法律问题，更是一个社会问题 | 这一问题同时涉及法律和社会两个层面 | 去掉"不仅是…更是…"的对比结构 |
| 从根本上说，规范与事实之间存在结构性张力 | 规范与事实之间存在一定程度的张力 | 去掉"从根本上说"的绝对化 |
| 这一制度的真正意义在于…… | 这一制度的意义在于…… | 去掉"真正"的过度修饰 |
| 毋庸置疑，该方案具有重要的实践价值 | 该方案具有一定的实践价值 | 去掉"毋庸置疑"的绝对化 |

## 九、个人风格注入示例

### 开头的真实感

**AI式开头（应去除）**：
- "本文将探讨……"
- "随着……的发展"
- "近年来……受到广泛关注"
- "在这个背景下……"

**真人开头特征**：
- 用具体问题/现象开头
- 用平实判断开头
- 用文献中的争议开头

### 弹性表达的适度使用

**过度绝对化（应去除）**：
- "必然""绝对""必须"

**弹性表达（可保留/添加）**：
- "可能""或许""某种程度"
- "往往""通常""一般情况下"
- "可以说"（审慎判断）

### 句子节奏

- 长短句搭配：长句论述（学术严谨性）+ 短句点睛（个人化）
- 避免连续长句或连续短句
- 自然断句，不刻意追求工整
