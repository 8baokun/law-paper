# 改写示例库

> 本文件提供各类AI化表述的改写对比示例。仅在需要具体改写参考时读取。
>
> 所有法学场景示例均参照《法学研究》等核心期刊真实论文的写作风格。

---

## 一、重新表述原则

### 核心原则

重新表述整个句子，不要只删除词汇。

### 错误方式 vs 正确方式

| 原句 | 删除式修改（×） | 重新表述（✓） |
|------|------------------|----------------|
| 它其实是第二类问题 | 这是第二类问题 | 这属于第二类问题 |
| 这里其实有三种可能 | 这里有三种可能 | 此处存在三种可能性 |
| 天然会形成这种结构 | 会形成这种结构 | 通常会形成这种结构 |
| 会更清楚这一点 | 更清楚这一点 | 这样可以更好地理解这一点 |
| 它更像一种框架 | 这是一种框架 | 这符合框架的特征 |

## 二、法学论文场景：AI腔 vs 真人写法对照

以下示例基于法学学术论文中常见的AI痕迹，对照真人学者的写法。

### 1. 开头改写

| AI腔 | 真人写法 | 说明 |
|------|----------|------|
| 随着数字经济的不断发展，数据确权问题日益凸显，受到了学界的广泛关注。 | 数据确权是数字经济发展的基础性问题。关于数据确权的理路，学界已有较多讨论，但方法层面的分歧依然明显。 | 从具体问题进入，不用"随着……发展"八股开头 |
| 近年来，基本权利冲突问题引起了宪法学界的高度重视。 | 权利冲突是21世纪初我国法学界的研究热点之一，曾在法理学界和部门法学界引发激烈争论。该场争论启发了宪法学界对于基本权利冲突问题的思考。 | 从学术争议进入，交代背景有实质内容 |
| 在全面依法治国的背景下，执行难问题的研究具有重要的理论和实践意义。 | 执行难是人民法院面临的突出问题，具体表现为法院执行措施难以实施，案件执行效果不理想，判决所确认的权利未能充分转化为现实的利益。 | 从具体问题进入，不用"在……背景下"八股开头 |

### 2. 连接与过渡改写

| AI腔 | 真人写法 | 说明 |
|------|----------|------|
| 首先，需要明确法律漏洞的概念。其次，需要分析认定标准。最后，需要讨论填补方法。 | 法律漏洞的概念厘定是讨论的前提。在此基础上，认定标准的分析构成论证的核心，填补方法的讨论则是落脚点。 | 用语义衔接替代"首先/其次/最后" |
| 综上所述，上述分析充分表明，法律漏洞的填补需要系统化的论证框架。 | 由此，法律漏洞的填补指向了系统化的论证框架。 | 删除"综上所述"和"充分"，直接陈述 |
| 值得注意的是，这一问题不仅涉及理论层面，更涉及实践层面。 | 需要指出的是，这一问题在理论和实践两个层面都有待回应。 | "需要指出的是"引出实质内容，不用"不仅……更……"对比结构 |
| 一方面，该制度具有促进效率的功能。另一方面，该制度也存在损害公平的风险。 | 该制度在促进效率的同时，也带来了损害公平的风险。 | 合并为一句话，不用"一方面/另一方面" |

### 3. 学说引述改写

| AI腔 | 真人写法 | 说明 |
|------|----------|------|
| 关于法律漏洞的定义，学界存在不同观点。张三认为……李四认为……王五认为……各种观点都有一定道理。 | 关于法律漏洞的定义，学理上仍见争议，但亦有通说。拉伦茨将法律漏洞定义为"违反计划的不圆满性"，该定义被引入我国后，逐渐成为法律漏洞的概念通说。 | 引述后紧跟判断，不罗列完就走 |
| 许多学者对该问题进行了深入探讨，提出了许多深刻的见解。 | 有学者指出，民事执行危机更多地表现为"程序匮乏的危机"，现有执行程序缺乏有效的措施来保障债权人实现债权。 | 给出具体观点，不用"深入探讨""深刻见解"空洞评价 |
| 有学者提出了颇具启发性的观点，认为…… | 有学者认为，权利冲突是个伪问题，只要把权利的边界划定清楚，就不会发生权利冲突。该观点对于避免权利滥用和侵权无疑是有帮助的。 | "颇具启发性"是空洞评价，改为具体说明该观点的贡献 |

### 4. 论证推进改写

| AI腔 | 真人写法 | 说明 |
|------|----------|------|
| 这一制度的本质在于效率价值的追求。 | 这一制度安排主要体现了效率价值取向。 | "本质在于"改为"主要体现了"，去掉绝对化 |
| 必然会导致同案不同判现象的发生。 | 可能导致同案不同判现象的发生。 | "必然"改为"可能"，保留限定 |
| 这一现象的背后，是深层的原因。 | 这一现象的成因涉及多个方面。 | "深层的原因"改为具体表述 |
| 从根本上说，规范与事实之间存在结构性张力。 | 规范与事实之间存在一定程度的张力。 | "从根本上说"改为"一定程度的"，去掉绝对化 |

### 5. 结尾改写

| AI腔 | 真人写法 | 说明 |
|------|----------|------|
| 尽管该制度仍面临诸多挑战，但其发展方向是明确的。未来，随着相关制度的完善，这一问题将得到更好的解决。 | 承认违约获益交出责任的独立性，既无需高昂的制度变革成本，亦能与现有的制度和概念体系有效衔接，是一个可行的选择。 | 直接陈述结论，不用"尽管……但……未来……"公式化展望 |
| 这一问题的解决需要学界和实务界的共同努力。 | 本文的经验材料主要来源于对中部地区基层法院的调研，在区域经济社会发展不平衡的背景下，东、中、西部地区基层法院的执行情况必然存在一定的差异。 | 指出局限，不用"共同努力"空洞呼吁 |
| 本文的研究仅为初步探索，尚有待进一步深入。 | 本文未覆盖……，后续研究可进一步考察…… | 具体说明局限，不用"初步探索"套话 |
| 综上所述，本文从理论建构到制度实践，对……问题进行了全面深入的分析。 | 行文至此，法律漏洞的填补论证可以归结为一条原则：穷尽规则引入，方可无规则填补。 | 以论证原则收束，不用"综上所述"和"全面深入" |

### 6. 强化词改写

| AI腔 | 真人写法 | 说明 |
|------|----------|------|
| 这一制度安排具有深刻的现实意义。 | 这一制度安排对……有直接影响。 | "深刻的现实意义"改为具体影响 |
| 该规则的确立对于法治建设具有重要的推动作用。 | 该规则的确立有助于……。 | "重要的推动作用"改为具体作用 |
| 这一分析框架为相关研究提供了新的视角。 | 这一分析框架可以用于分析……问题。 | "新的视角"改为具体应用 |
| 尤为重要的是，该制度…… | 该制度直接决定了…… | "尤为重要"改为具体重要性 |

## 三、对比句式改写

| 原句 | 改写 |
|------|------|
| 不是A而是B | 直接陈述B，或拆为两个独立陈述句 |
| 并非A而是B | 直接陈述B |
| 不在于A在于B | B是关键因素 |
| 看似在讲A，实则在讲B | 文章表面上讨论A，但核心关注的是B |
| 与A是两回事 | A和B存在显著差异（如需对比则具体说明差异） |
| 与A不等同于B | A和B在功能上存在区分 |

## 四、程式化连接词改写

| 原句 | 改写 |
|------|------|
| 首先，A。其次，B。 | A。在此基础上，B。/ 直接按逻辑顺序陈述，不用序数词 |
| 一方面A，另一方面B | A，同时B / A，而B |
| 综上所述 | 删除，直接陈述结论 |
| 总而言之 | 删除，直接陈述结论 |
| 然而 | 但 / 删除，用句号断开后直接转折 |
| 因此 | 删除，用因果逻辑自然衔接 |

## 五、绝对化表述改写

| 原句 | 改写 |
|------|------|
| 本质上 | 通常 / 在某种程度 / 就其基本特征而言 |
| 从根本上说 | 通常 / 一般而言 |
| 必然 | 往往 / 多半 / 可能 |
| 真正的 | 删除"真正的"，直接陈述 |
| 天然 | 通常 / 一般情况下 |
| 其实 | 删除"其实"，直接陈述 |
| 立刻/马上 | 随后 / 在短期内 |
| 并不是一个绝对命题 | 这个问题没有简单的是非答案 |
| 标志着关键时刻 | 在[具体时间/事件]中起到重要作用 |
| 不可或缺的组成部分 | 重要组成部分 |
| 为…奠定基础 | 对…有重要影响 |

## 六、工整排比改写

| 原句 | 改写 |
|------|------|
| 既要A，又要B，还要C | 需要同时处理A、B和C三个方面（改为简单列举） |
| 讲清楚A、讲清楚B、讲清楚C | 需要阐明A、B和C（去掉重复结构） |
| 三个"讲清楚" | 改为混合结构的陈述句 |

## 八、个人风格注入示例

### 开头的真实感

**AI式开头（应去除）**：
- "本文将探讨……"
- "随着……的发展"
- "近年来……受到广泛关注"
- "在这个背景下……"

**真人开头特征**：
- 用具体问题/现象开头
- 用平实判断开头
- 用文献中的争议开头
- 用制度实践中的矛盾现象开头

### 弹性表达的适度使用

**过度绝对化（应去除）**：
- "必然""绝对""必须"

**弹性表达（可保留/添加）**：
- "可能""或许""某种程度"
- "往往""通常""一般情况下"
- "可以说"（审慎判断）

### 句子节奏

- 长短句搭配：长句论述（学术严谨性）+ 短句点睛（个人化）
- 避免连续长句或连续短句
- 自然断句，不刻意追求工整
