# 盲区扫描清单

> 系统化盲区枚举辅助。当维度5（盲区扫描）需要更穷尽的枚举时读取本文件。
> 不是检查清单（不逐项打分），而是枚举工具——帮助扫描者"想到没想到的"。

---

## 一、隐含假设类盲区

### 1.1 事实假设

| 编号 | 假设类型 | 触发问题 |
|------|----------|----------|
| A1 | 现状假设 | 方案是否默认了"现状是什么"的判断？这个判断有无实证支撑？ |
| A2 | 趋势假设 | 方案是否默认了某种发展趋势会持续？如默认"问题会越来越严重"或"技术会越来越好"。 |
| A3 | 同质性假设 | 方案是否默认所有对象都是同质的？如默认"所有企业都一样""所有法官都一样"。 |
| A4 | 可测性假设 | 方案是否默认效果是可测量的？如默认"合规水平可以量化"。 |
| A5 | 信息完备假设 | 方案是否默认决策者拥有充分信息？ |

### 1.2 规范假设

| 编号 | 假设类型 | 触发问题 |
|------|----------|----------|
| B1 | 价值假设 | 方案是否默认了某种价值排序？如默认"效率优先于公平"或"安全优先于自由"。 |
| B2 | 目的假设 | 方案是否默认了立法目的与条文目的一致？ |
| B3 | 可欲性假设 | 方案是否默认"应当做的就能做到"？混淆了"应当"和"能够"。 |
| B4 | 普遍性假设 | 方案是否默认某项原则适用于所有情境？检查是否有例外被忽略。 |

### 1.3 方法假设

| 编号 | 假设类型 | 触发问题 |
|------|----------|----------|
| C1 | 比较法假设 | 比较法论证是否默认了制度可比性？比较的对象在功能、结构、语境上是否真的可比？ |
| C2 | 历史假设 | 历史论证是否默认"过去有效的现在仍然有效"？ |
| C3 | 类型化假设 | 类型化分析是否默认类型之间界限清晰？实际上是否存在模糊地带？ |
| C4 | 还原论假设 | 方案是否默认整体等于部分之和？忽略了部分组合后的涌现性？ |

## 二、视角盲区

### 2.1 利益相关方盲区

| 编号 | 盲区类型 | 触发问题 |
|------|----------|----------|
| D1 | 被规制者视角 | 方案是否只从规制者视角出发？被规制者的反应是否被考虑？ |
| D2 | 弱势方视角 | 方案是否忽略了弱势方的利益？弱势方是否有能力主张权利？ |
| D3 | 执行者视角 | 方案是否考虑了一线执行者的实际操作空间？执行者是否有能力执行？ |
| D4 | 外部受影响方 | 方案是否考虑了非直接参与方但受影响的主体的利益？ |
| D5 | 未来主体视角 | 方案是否考虑了对未来主体的影响？（如后代、未来市场参与者） |

### 2.2 学科盲区

| 编号 | 盲区类型 | 触发问题 |
|------|----------|----------|
| E1 | 经济学盲区 | 方案是否忽略了激励机制和成本收益分析？ |
| E2 | 社会学盲区 | 方案是否忽略了社会结构和群体行为模式？ |
| E3 | 政治学盲区 | 方案是否忽略了权力配置和利益博弈？ |
| E4 | 技术盲区 | 方案是否忽略了技术可行性和技术演进？ |
| E5 | 心理学盲区 | 方案是否忽略了行为主体的认知偏差和非理性因素？ |

## 三、路径盲区

### 3.1 异常路径

| 编号 | 盲区类型 | 触发问题 |
|------|----------|----------|
| F1 | 输入异常 | 如果输入信息不完整、错误或恶意，方案如何处理？ |
| F2 | 中间环节失败 | 如果某个中间环节失败或拒绝执行，系统如何应对？ |
| F3 | 输出无效 | 如果方案的输出不被接受或被推翻，有无替代方案？ |
| F4 | 并发冲突 | 如果多个主体同时触发方案，是否产生冲突？ |
| F5 | 累积效应 | 方案反复执行后是否产生累积性的副作用？ |

### 3.2 极端情境

| 编号 | 盲区类型 | 触发问题 |
|------|----------|----------|
| G1 | 紧急状态 | 在紧急状态（战争、灾害、疫情）下，方案是否仍然适用？ |
| G2 | 资源匮乏 | 在资源严重不足时，方案的优先级如何调整？ |
| G3 | 制度真空 | 在相关制度尚未建立时，方案如何运行？ |
| G4 | 制度冲突 | 在多个制度同时适用且相互冲突时，方案如何处理？ |

## 四、时间盲区

| 编号 | 盲区类型 | 触发问题 |
|------|----------|----------|
| H1 | 短期vs长期 | 方案的短期效果和长期效果是否一致？是否存在"短期有效长期有害"的情况？ |
| H2 | 时滞效应 | 方案从实施到见效的时滞有多长？时滞期内如何应对？ |
| H3 | 路径依赖 | 方案实施后是否产生路径依赖？未来如需调整，退出成本有多高？ |
| H4 | 时代变迁 | 方案是否预设了当前的社会条件不变？如果社会条件变化，方案是否仍然适用？ |

---

## 五、元盲区（盲区本身的盲区）

| 编号 | 盲区类型 | 触发问题 |
|------|----------|----------|
| M1 | 已知未知 | 扫描者知道自己不知道的——是否都已列出？ |
| M2 | 未知未知 | 扫描者不知道自己不知道的——能否通过类比、参照其他领域来枚举？ |
| M3 | 盲区盲区 | 扫描者是否只扫描了"方便扫描的"盲区，回避了"不方便扫描的"？ |
| M4 | 确认偏误 | 扫描者是否只寻找了支持方案的盲区，而忽略了反驳方案的盲区？ |

## 使用说明

1. 本清单是**枚举工具**，不是评分表。不需要逐项打分，而是逐项思考"这个盲区是否存在"。
2. 使用方法：从第一节到第五节依次扫过，对每个触发问题快速判断"是/否/不确定"。
   - "是"→该盲区存在，需在诊断报告中记录。
   - "否"→该盲区不存在，跳过。
   - "不确定"→需要进一步调查，在诊断报告中标记为"待查"。
3. 不必每次都扫描全部条目。根据分析对象的性质选择重点章节：
   - 制度方案→重点扫第一节（隐含假设）和第二节（视角盲区）
   - 论文论证→重点扫第一节（隐含假设）和第三节（路径盲区）
   - 流程设计→重点扫第三节（路径盲区）和第四节（时间盲区）
   - 所有对象→第五节（元盲区）必扫
4. 本清单不完整。如果扫描过程中发现新的盲区类型，应即时补充。
