# 法律生态可落地性审查清单

## 审查1：制度兼容性·详细清单

### 核查步骤

```
步骤1：提取建议涉及的法律法规
  - 逐条列出论文建议中引用或涉及的法律法规
  - 标注每条法规的层级（法律/行政法规/部门规章/规范性文件/地方性法规）
  ↓
步骤2：逐条核查现行有效性
  - 每条法规是否现行有效？
  - 是否有最近修订？修订内容是否影响建议？
  - 如已废止，是否有替代法规？
  ↓
步骤3：冲突检查
  - 建议是否与上位法冲突？
  - 建议是否与同位法不一致？
  - 如有冲突，是否说明了冲突解决方案？
  ↓
步骤4：立法趋势检查
  - 相关法律是否正在修订？
  - 修订方向是否与建议兼容？
```

### 常见问题

| 问题类型 | 表现 | 处理建议 |
|----------|------|----------|
| 引用已废止法规 | 建议依据的法规已废止 | 标记"制度兼容性不通过"，要求更新法规依据 |
| 与上位法冲突 | 建议要求做的事情上位法禁止 | 标记否决项，要求修改建议或增加修法前提 |
| 部门规章越权 | 建议依据的部门规章超出法律授权 | 标记风险，建议寻找法律层面的依据 |
| 忽视立法趋势 | 相关法律正在修订但建议未考虑 | 标记风险，建议关注立法动态 |

## 审查2：主体可行性·详细清单

### 核查步骤

```
步骤1：提取建议涉及的主体
  - 逐条列出论文建议中提到的主管部门、执行主体、配合部门
  ↓
步骤2：逐个核对主体是否存在
  - 核对部门设置（可通过国务院机构设置、地方政府组织法等）
  - 如是内设机构，核对是否在编制序列中
  ↓
步骤3：核对职责权限
  - 该主体的法定职责是否覆盖建议内容？
  - 是否存在超越职权的问题？
  ↓
步骤4：多部门协同检查
  - 如涉及多部门，是否有协调机制？
  - 牵头部门是否明确？
```

### 常见问题

| 问题类型 | 表现 | 处理建议 |
|----------|------|----------|
| 部门不存在 | 建议由已撤并的部门负责 | 标记"主体可行性不通过"，要求更新主体 |
| 超越职权 | 建议要求某部门行使超出法定职权的职能 | 标记否决项 |
| 牵头不明 | 多部门协同但未指定牵头部门 | 标记风险，要求明确牵头 |
| 能力不足 | 执行主体缺乏相应的专业能力 | 标记风险，建议增加能力建设配套 |

## 审查3：程序可行性·详细清单

### 核查步骤

```
步骤1：提取建议的操作步骤
  - 逐条列出论文建议中的操作步骤
  ↓
步骤2：核对程序合法性
  - 每个步骤是否符合现行法定程序？
  - 是否存在绕开法定程序的情况？
  ↓
步骤3：核对程序时限
  - 操作周期是否在法定时限内？
  - 如超出，是否有合法的例外安排？
  ↓
步骤4：核对程序衔接
  - 多个程序之间的衔接是否顺畅？
  - 是否存在程序空转或重复程序？
```

## 审查4：资源可行性·详细清单

### 核查步骤

```
步骤1：评估实施成本
  - 人员成本（新增编制/外包/培训）
  - 经费成本（一次性投入+持续运营）
  - 技术成本（系统建设/维护）
  - 场地成本（如涉及）
  ↓
步骤2：核对配套资源
  - 配套资源是否有来源？
  - 是否有预算保障？
  ↓
步骤3：成本合理性判断
  - 与同类制度实施的常规成本比较
  - 成本效益比是否合理？
```

### 成本评估参考框架

| 成本类型 | 评估要点 | 合理范围参考 |
|----------|----------|------------|
| 人员成本 | 新增岗位数×人均成本 | 与同类部门比较 |
| 经费成本 | 一次性投入+年度运营 | 占主管部门预算的比例 |
| 技术成本 | 系统建设+年度维护 | 与同类系统比较 |
| 时间成本 | 实施周期 | 是否与法定时限兼容 |

## 审查5：政策兼容性·详细清单

### 核查步骤

```
步骤1：识别相关政策
  - 建议涉及哪些政策领域？
  - 近期有哪些相关政策文件？
  ↓
步骤2：核对政策一致性
  - 建议是否与国家政策导向一致？
  - 建议是否与行业监管政策兼容？
  ↓
步骤3：评估政策风险
  - 政策是否可能调整？
  - 建议是否有适应政策变动的弹性？
```

## 审查6：地域适配性·详细清单

### 核查步骤

```
步骤1：评估适用范围
  - 建议是否具有普遍适用性？
  - 还是仅适用于特定地区/层级？
  ↓
步骤2：核对地区差异
  - 发达地区和欠发达地区的实施条件差异
  - 各地立法差异（如涉及地方事务）
  - 各地实践惯例差异
  ↓
步骤3：评估适配方案
  - 是否有地区适配条款？
  - 是否有试点路径？
  - 是否留有地方自主空间？
```

### 地域适配性处理方式

| 处理方式 | 适用场景 | 示例 |
|----------|----------|------|
| 普遍适用+弹性条款 | 大多数地区可推行，但需留弹性 | "各地可根据实际情况制定实施细则" |
| 分步实施+试点路径 | 部分地区条件成熟，部分不成熟 | "先在XX地区试点，总结经验后推广" |
| 分类指导 | 不同类型地区适用不同方案 | "直辖市适用方案A，地级市适用方案B" |
| 地区例外 | 特殊地区不适用 | "民族自治地区可参照执行" |
