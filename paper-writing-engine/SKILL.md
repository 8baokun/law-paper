# 应用法学论文写作引擎

## 概述

本技能是应用法学论文生产线的环节5。在环节3（提纲审查）通过、环节4（文献检索）完成后，基于通过的提纲和文献清单撰写论文初稿。

**与通用学术写作的区别**：

| 维度 | 通用学术写作 | 本技能（法学论文写作） |
|------|-------------|------------------------|
| 论证方法 | 通用研究方法 | 规范分析、案例分析、比较法等法学专门方法 |
| 引用规范 | 通用引用格式 | 法条/案例/学说/政策各有专门格式 |
| 结构模式 | 通用论文结构 | 法学论文四种典型结构模式 |
| 写作风格 | 学术通用 | 法学学术文体（准确、严谨、避免口语化） |
| 特别要求 | — | 描述与规范的区分、概念一致性、效力层级标注 |

## 四种法学论文结构模式

根据论文类型选择对应的结构模式。按需读取 `references/论文结构模式.md` 获取详细模板。

### 模式一：制度分析型

适用：分析某一法律制度的规范构造、实施效果和完善路径。

```
结构骨架：
一、问题提出（制度背景+核心命题）
二、规范构造分析（条文释义+体系定位+效力层级）
三、实施现状与问题（实践考察+问题识别）
四、比较法参照（可选，3-5个法域对比）
五、制度完善建议（具体建议+可行性分析）
六、结论
```

### 模式二：规范解释型

适用：对某一法律条文或概念进行解释论研究。

```
结构骨架：
一、问题提出（解释争议+核心命题）
二、文义解释（字面含义+核心概念界定）
三、体系解释（在法律体系中的定位+关联条款分析）
四、目的解释（立法目的+价值取向）
五、解释结论与适用方案（结论+适用规则）
六、结论
```

### 模式三：实证研究型

适用：基于案例或数据的实证分析。

```
结构骨架：
一、问题提出（研究背景+核心命题）
二、研究设计（样本选择+分析方法+变量界定）
三、数据呈现与分析（描述性统计+相关性分析）
四、发现与讨论（核心发现+理论解释+政策含义）
五、建议（基于实证发现的政策建议）
六、结论（研究贡献+局限+未来方向）
```

### 模式四：比较法研究型

适用：通过比较法视角分析某一法律问题。

```
结构骨架：
一、问题提出（比较法视角的引入+核心命题）
二、比较法域的选择与论证（法域选择+可比性论证）
三、各法域制度考察（逐个法域的规范与实践分析）
四、比较分析（异同对比+原因解释+规律提炼）
五、对中国的启示（可借鉴经验+移植可行性+本土化路径）
六、结论
```

## 法学论证方法指导

### 方法一：规范分析

按需读取 `references/法学论证方法.md` 获取详细指导。

**核心要求**：
- 区分描述性陈述与规范性陈述
- 法条引用必须标注效力层级和施行日期
- 规范冲突时必须说明解决规则
- 不得将政策文件等同于法律规范

**常见错误**：
- 混淆"应当"（规范）与"是"（描述）
- 将部门规章等同于法律
- 引用已废止法条未加说明
- 忽视规范层级冲突

### 方法二：案例分析

**核心要求**：
- 案例必须标注裁判文书号、法院、日期
- 区分指导性案例的约束力与普通案例的说服力
- 案例分析须提炼裁判要旨，不能只罗列案情
- 正反案例必须平衡呈现

**案例分析框架**：
```
1. 案例基本信息（文书号、法院、日期、案由）
2. 争议焦点（与本文相关的争议点）
3. 裁判要旨（法院的核心观点）
4. 裁判理由（法院的论证逻辑）
5. 案例评析（与本文论点的关系：支撑/反驳/补充）
```

### 方法三：比较法研究

**核心要求**：
- 法域选择须论证可比性
- 外国法引用须标注法域、法源名称、译文出处
- 避免简单的制度罗列，须提炼制度背后的原理
- 制度移植须分析可行性和本土化路径

**比较法分析框架**：
```
1. 法域选择论证（为何选择该法域）
2. 该法域的制度内容（规范+实践）
3. 制度背景分析（历史、文化、法系传统）
4. 与中国的异同对比
5. 可借鉴经验与移植可行性分析
```

### 方法四：学说梳理与对话

**核心要求**：
- 学说引用须标注作者、著作/论文标题、出处
- 须呈现学术观点谱系，不能只引用一家之言
- 与不同观点的对话须有实质内容，不能只说"某某观点值得商榷"
- 须明确自身观点在学术谱系中的定位

## 法学引用规范

### 法条引用格式

```
正文引用：
  《中华人民共和国民法典》第143条[1]。
  《合规管理办法》（国资委令第12号）第26条[2]。

参考文献：
  [1] 《中华人民共和国民法典》，2020年5月28日通过，2021年1月1日施行。
  [2] 《中央企业合规管理办法》，国务院国资委令第12号，2022年8月23日发布，2022年10月1日施行。
```

**注意事项**：
- 首次引用标注全称，后续可用简称
- 必须标注文号（如有）和施行日期
- 如引用已废止法条，必须加注说明
- 司法解释须标注全称和文号

### 案例引用格式

```
正文引用：
  在"XX诉XX案"中，法院认为……[3]。
  最高人民法院指导案例第XX号[4]。

参考文献：
  [3] XX诉XX案，北京市第一中级人民法院（2024）京01民终XX号民事判决书。
  [4] 最高人民法院指导案例第XX号，20XX年XX月XX日发布。
```

### 学说引用格式

```
正文引用：
  有学者认为……[5]。
  张三教授指出："……"[6]。

参考文献：
  [5] 张三：《论业法财融合》，载《法学研究》2024年第3期，第45-67页。
  [6] 李四：《企业合规的理论与实践》，法律出版社2023年版，第123页。
```

### 政策文件引用格式

```
正文引用：
  根据《关于推进XX的指导意见》[7]……

参考文献：
  [7] 《国务院国资委关于推进中央企业合规管理的指导意见》，国资发法规〔2018〕106号，2018年11月2日。
```

### 比较法引用格式

```
正文引用：
  德国《股份法》第93条规定……[8]。
  美国联邦量刑委员会《组织量刑指南》规定……[9]。

参考文献：
  [8] 《德国股份法》（Aktiengesetz），第93条，1965年9月6日颁布，最近修订2023年。译文见杜景林、林灿译：《德国股份法》，法律出版社2019年版。
  [9] U.S. Sentencing Commission, Federal Sentencing Guidelines Manual §8B2.1 (2023).
```

## 执行流程

```
步骤1：接收输入
  - 读取环节3通过的提纲
  - 读取环节4的标准化文献清单和阅读笔记
  - 确认论文类型（制度分析型/规范解释型/实证研究型/比较法研究型）
  - 选择对应的结构模式
  ↓
步骤2：开篇写作
  - 撰写"问题提出"部分
  - 核心命题必须在一节之内清晰呈现
  - 问题意识必须与司法实践或立法需求关联
  ↓
步骤3：主体写作
  - 按提纲逐章撰写
  - 每章写作时参照文献清单的引用策略
  - 确保每个前置论点都有文献支撑
  - 保持概念使用的前后一致
  ↓
步骤4：学术对话嵌入
  - 在适当位置嵌入与已有文献的对话
  - 识别不同观点并作出实质回应
  - 标注自身观点在学术谱系中的定位
  ↓
步骤5：结论写作
  - 重申核心命题
  - 概括论证过程
  - 指出研究局限
  - 展望未来方向
  ↓
步骤6：引用核查
  - 逐条核查引用的准确性
  - 核查引用格式的规范性
  - 核查正反文献的平衡性
  ↓
步骤7：概念一致性检查
  - 核查核心概念在不同章节中的定义是否一致
  - 如有概念演变，须明确说明
  ↓
步骤8：输出论文初稿
  - Markdown格式
  - 包含参考文献列表
  - 标注待完善区域（用[TODO:XX]标记）
```

## 写作规范

### 文体要求

- **准确**：法律术语使用准确，不混用相近概念
- **严谨**：每个论断都有依据，不凭空下判断
- **清晰**：论证层次分明，逻辑推进可见
- **简洁**：避免冗余表述，不堆砌辞藻
- **学术**：避免口语化，不使用网络用语

### 篇幅参考

| 论文类型 | 总篇幅 | 各部分占比 |
|----------|--------|------------|
| 制度分析型 | 1.5-2万字 | 问题10%+规范分析30%+实施25%+比较法15%+建议15%+结论5% |
| 规范解释型 | 1-1.5万字 | 问题10%+文义20%+体系25%+目的20%+结论适用20%+结论5% |
| 实证研究型 | 1.5-2万字 | 问题10%+设计10%+数据分析30%+讨论30%+建议15%+结论5% |
| 比较法研究型 | 1.5-2万字 | 问题10%+法域选择5%+各法域考察35%+比较分析25%+启示20%+结论5% |

### 概念使用规范

- **首次出现时定义**：核心概念首次出现时给出明确定义
- **前后一致**：同一概念在全文中的内涵保持一致
- **区分近似概念**：如"合规"与"合法"、"效力"与"效果"
- **避免概念漂移**：如发现概念在不同章节含义不同，须修正

### 描述与规范的区分

法学论文的核心逻辑问题之一是混淆描述性陈述与规范性陈述：

| 类型 | 特征 | 标志词 | 示例 |
|------|------|--------|------|
| 描述性陈述 | 陈述事实 | "是""有""存在" | "《合规管理办法》规定了业法财融合" |
| 规范性陈述 | 表达应当 | "应当""必须""应该" | "国企应当在合规管理中实现业法财融合" |

**写作时必须注意**：不要从描述性陈述直接推导规范性结论（休谟问题），也不要用规范性判断替代事实描述。

## 输出底线

- **引用必须真实**。所有引用的法条、案例、学说必须是真实可查证的。绝不捏造引用。
- **概念必须一致**。核心概念在全文中的定义必须一致。
- **论点必须有支撑**。每个前置论点都必须有文献支撑或独立论证。
- **正反必须平衡**。案例和学说引用必须包含不同观点。
- **效力层级必须标注**。法条引用必须标注效力层级和施行日期。
- **描述与规范必须区分**。不得混淆"是什么"与"应当是什么"。
- **待完善区域必须标注**。用[TODO:XX]标记需要进一步完善的段落。

## 回溯协议

- 如写作中发现某个前置论点缺乏文献支撑 → 回退到环节4（文献检索）补充检索
- 如写作中发现论证框架有结构性问题 → 回退到环节2（思路梳理）调整框架
- 如写作中发现核心命题无法成立 → 回退到环节1（选题检查）重新选题
- 如写作中发现概念定义冲突且无法调和 → 回退到环节2（思路梳理）重新梳理

## 快速通道

- 如环节3（提纲审查）和环节4（文献检索）综合评分均 ≥ 4.5 → 可启用简化模式：
  - 跳过步骤7（概念一致性检查的逐项深挖）
  - 引用核查聚焦核心引用（法条和指导性案例）
- 但步骤2（开篇写作）、步骤3（主体写作）、步骤8（输出）不可跳过
