# 法学引注规范

**依据**：《法学引注手册》（2019年11月版，中国法学会法学期刊研究会推荐，共100条）

**适用范围**：应用法学论文写作全流程中的引注格式规范，涵盖中文文献和外文文献。

---

## 一、引注基本要求（第1-23条）

### 1.1 引注原则

- **必要而适度**：涉及学术观点、法律文件、事件、案例、统计数据等，需要交代出处而不便在正文中叙明的，才予以注明。避免繁琐引注，尽量避免一句多注或连续一句一注。
- **真实可靠**：引用真实可靠、内容相关、权威稳定的文献。不得引用未经查核的文献，不得歪曲他人观点。
- **优先级**：中文优先、纸质优先、原创优先。有纸质出版文献的，不引用网络资料。有多个相关文献的，引用最初文献。慎用转引。
- **准确完整**：已出版文献的作者、名称和出版信息，原则上从原文原著。在保证基本信息完整的前提下，引注信息尽可能简洁、流畅。

### 1.2 引注符号

- 使用阿拉伯数字，可带圆圈或六角括号（第4条）。
- 对全句引用：引注符号置于句号后。
- 对句子部分引用：引注符号置于该部分后（第5条）。

### 1.3 同一文献多次出现（第14条）

同一文献多次出现的，第一次引用完整信息，后面可使用缩略写法：

```
同前注〔×〕，作者：《文献名》，第×页。
```

> **编号制说明**：如采用文后编号参考文献制（非脚注制），同一文献使用同一编号即可，无需"同前注"写法。

### 1.4 "载"字使用规则（第11条）

"载"字用于以下文献来源前：
- 期刊文章
- 报纸文章
- 网络文章
- 独立作品组成的文集中的文章

示例：`作者：《文章标题》，载《期刊名》年份第期，第×页。`

## 二、中文引注体例（第24-76条）

### 2.1 纸质出版文献

#### 2.1.1 作者标注

| 情形 | 规范（条号） | 格式 | 示例 |
|------|------------|------|------|
| 原创作品 | 省略"著"字（第24条） | `作者：《书名》` | 王利明：《侵权责任法研究》 |
| 编辑作品 | 标明"主编""编"（第24条） | `主编：《书名》` | 张新宝主编：《侵权责任法》 |
| 翻译作品 | 标明"译"（第24条） | `[国籍]作者：《书名》，译者译` | [德]拉伦茨：《法学方法论》，黄家镇译 |
| 合作作品（2人） | 一一列明（第32条） | `甲、乙：《书名》` | 熊瑛子、贺清：《……》 |
| 合作作品（3人以上） | 列第一作者后加"等"（第32条） | `甲等：《书名》` | 王利明等：《侵权责任法》 |
| 职务/谦称 | 不写职务，不用"拙文""拙著"（第30条） | 直写姓名 | ~~王利明教授~~ → 王利明 |
| 外籍作者 | 方括号注明国籍（第31条） | `[国籍]作者` | [美]波斯纳 |

#### 2.1.2 文献名称

- 用书名号，用全称（第34条）。
- 原文原著名称包含多个部分的，原则上全文引用，不省略。

#### 2.1.3 图书出版信息

| 项目 | 规范（条号） | 格式 | 示例 |
|------|------------|------|------|
| 版本 | 初版无需标明；再版括注"（第×版）"（第37条） | `（第×版）` | （第3版） |
| 出版社 | 名称完整，前不写城市名（第38条） | `出版社×年版` | 中国人民大学出版社2021年版 |
| 出版时间 | 只写年（第38条） | `×年` | 2021年 |

**完整图书格式**：
```
作者：《书名》（第×版），出版社×年版，第×页。
```

示例：
```
王利明：《侵权责任法研究》（第3版），中国人民大学出版社2021年版，第156页。
```

#### 2.1.4 期刊出版信息

- 格式：`××年第×期`（第39条）
- "载"字置于期刊名前

**完整期刊格式**：
```
作者：《文章标题》，载《期刊名》年份第期，第×-×页。
```

示例：
```
曹权之：《民法典"自甘风险"条文研究》，载《东方法学》2021年第4期，第45-67页。
```

#### 2.1.5 文集出版信息

- 以"载"字开头，完整标注编者、书名和出版信息（第41条）

**完整文集格式**：
```
作者：《文章标题》，载编者主编：《书名》，出版社×年版，第×页。
```

#### 2.1.6 页码标注（第45条）

- **引用特定部分的内容，必须标明页码**。
- 概括提及整篇文献的，不标页码。
- 页码格式：`第×-×页`（连续多页）或`第×页`（单页）。

> ⚠️ **常见错误**：参考文献列表中引用了期刊论文的特定观点或段落，却未标明页码。这是引注手册明确要求的。

### 2.2 网络文献（第48条）

- 标明**网站名称、上传日期和网页地址**。
- 无上传日期时，标明**访问日期**。
- 有纸质出版文献的，不引用网络资料。

**格式**：
```
作者：《文章标题》，载网站名×年×月×日，URL。
```

或（无上传日期时）：
```
作者：《文章标题》，载网站名，URL（×年×月×日访问）。
```

### 2.3 法律文件（第58-69条）

#### 2.3.1 法律名称

- 加书名号（第58条）。
- "中华人民共和国"可省略（第59条）。
- 已失效法律文件应予注明（第60条）。
- 条款序数采用阿拉伯数字（第61条）。

#### 2.3.2 援引法律条文（第63条）

- **一般只需提及名称和条文序数，不必详细标明通过日期等**。

> ⚠️ **常见错误**：在参考文献列表中标注法律的"通过日期"。按第63条，援引法律条文一般不需要通过日期。

#### 2.3.3 规范性文件（第64条）

- 应标明**制定机关和文件号**。
- 文件号中年份加**六角括号〔 〕**。

**格式**：
```
《文件名称》，制定机关 文件号，发布日期。
```

示例：
```
《最高人民法院关于审理人身损害赔偿案件适用法律若干问题的解释》，法释〔2022〕14号。
```

> ⚠️ **常见错误**：司法解释缺少文号（法释号）。这违反第64条。

#### 2.3.4 外国法律（第68条）

- 国别置于书名号前，条文序号用阿拉伯数字。
- 有中文译本的，原则上引用中文译本（第77条）。

**格式**：
```
《国别法律名称》第×条。译文见译者译：《书名》，出版社×年版，第×页。
```

### 2.4 司法案例（第70-73条）

#### 2.4.1 案例名称（第70条）

- 民事案件：`×××诉×××案`
- 刑事案件：`×××案`

#### 2.4.2 案件文号（第71条）

- 标明**审判法院、文书名称和案号**。
- 案号中年份加**圆括号（ ）**。

**格式**：
```
案例名称，审判法院（年份）案号 文书名称。
```

示例：
```
周鹏远诉侯守明案，抚顺市新抚区人民法院（2016）辽0402民初885号民事判决书。
```

> ⚠️ **注意**：案号中的年份用圆括号，规范性文件文号中的年份用六角括号——两者不同。

#### 2.4.3 案例来源（第72条）

- **指导性案例**：标注发布机关和序号。
- **公报案例**：可只援引《公报》。
- **典型案例**：标注发布机关和发布批次/年份。

#### 2.4.4 裁判时间（第73条）

- 一般无需标明。

### 2.5 统计数据（第74-76条）

- 标明发布机关、文件名称和发布日期。

## 三、外文引注体例（第77-100条）

### 3.1 一般原则（第77条）

- 有中文译本的外文文献，原则上引用中文译本。
- 引用外文文献，一般不做翻译，直接使用外文。

### 3.2 英文文献

#### 3.2.1 英文学术期刊（第78条）

- 作者名前姓后（Lastname, Firstname）。
- 文章标题斜体，首字母大写。
- 刊物名不斜体。

**格式**：
```
Author, Article Title, Journal Name, Volume (Year), p. xx.
```

示例：
```
Richard A. Posner, Goodbye to the Bluebook, 53 University of Chicago Law Review 1343 (1986).
```

#### 3.2.2 英文书籍（第80条）

- 书名斜体，首字母大写。
- 出版社前不写地址。
- 页码前加 p.

**格式**：
```
Author, Book Title, Publisher, Year, p. xx.
```

#### 3.2.3 美国法院案例（第83条）

- 当事人v.当事人，v.用斜体。
- 案例报告系统。
- 括号中法院和年份。

**格式**：
```
Plaintiff v. Defendant, Volume Reporter Series Page (Court Year).
```

示例：
```
Knight v. Jewett, 3 Cal. 4th 276 (1992).
```

#### 3.2.4 英文网络文章（第85条）

- 标明作者、文章名、网站名、上传时间和网址。
- 无上传日期的，标明访问日期。

**格式**：
```
Author, "Article Title," Website Name (Date), URL.
```

或（无上传日期时）：
```
Author, "Article Title," Website Name, URL (last visited Date).
```

> ⚠️ **常见错误**：英文网络文献缺少访问日期。按第85条，无上传日期时必须标明访问日期。

### 3.3 法文文献（第86-90条）

- 书名斜体，论文题目用双括号« »，杂志名称斜体。
- 页码用 p. xx-xy。

### 3.4 德文文献（第91-95条）

- 作者完整姓名，名在前姓在后，不用斜体。
- 文章名不加引号，不用斜体。
- 刊物名使用惯用缩写。
- 页码用 S. xx。

### 3.5 日文文献（第96-100条）

- 书名用『 』，论文名用「 」。
- 作者名、杂志名、法规名、案例名称用全称。
- 年份用公元纪年。

## 四、引注自检清单

写作完成后，按以下清单逐项检查引注格式：

### 4.1 通用检查

- [ ] 引注符号使用阿拉伯数字，位置正确（句末引用在句号后，部分引用在该部分后）
- [ ] "载"字用于期刊、报纸、网络、文集文章的来源前
- [ ] 同一文献多次出现时使用缩略写法（脚注制）或同一编号（编号制）
- [ ] 不写作者职务，不用"拙文""拙著"

### 4.2 中文文献检查

- [ ] **法律文件**：名称加书名号；援引法条一般不标通过日期；规范性文件标明制定机关和文号（文号年份用六角括号〔 〕）；已废止法律予以注明
- [ ] **案例**：名称格式正确（民事"×××诉×××案"）；案号年份用圆括号（ ）；标明审判法院和文书名称；指导性案例标发布机关和序号；裁判时间一般不标
- [ ] **期刊论文**：作者在前；文章名用书名号；期刊名前加"载"；格式"××年第×期"；**引用特定部分标明页码**（第×-×页）
- [ ] **图书**：再版括注"（第×版）"；出版社名称完整，前不写城市；时间只写年；后加"版"字；**引用特定部分标明页码**
- [ ] **网络文献**：标明网站名称、上传日期（或访问日期）和网址

### 4.3 外文文献检查

- [ ] 有中文译本的优先引用中文译本
- [ ] 英文期刊：作者名前姓后，文章标题斜体
- [ ] 英文书籍：书名斜体，出版社前不写地址，页码前加 p.
- [ ] 美国案例：当事人 v. 当事人（v.斜体），案例报告系统，括号中法院和年份
- [ ] 英文网络文章：标明作者、文章名、网站名、上传/访问日期和网址

### 4.4 常见错误速查

| 错误类型 | 正确格式 | 条号 |
|---------|---------|------|
| 期刊论文未标页码 | ……载《期刊》年份第期，**第×-×页**。 | 第45条 |
| 教材未标页码 | ……出版社×年版，**第×页**。 | 第45条 |
| 司法解释缺文号 | ……，**法释〔20××〕×号**。 | 第64条 |
| 法律标注通过日期 | ~~通过日期~~ → 一般只需名称和条文序数 | 第63条 |
| 版本用中文数字 | ~~（第三版）~~ → **（第3版）** | 第37条 |
| 案号年份用六角括号 | ~~〔2016〕~~ → **（2016）** | 第71条 |
| 文号年份用圆括号 | ~~（2022）~~ → **〔2022〕** | 第64条 |
| 网络文献缺访问日期 | ……URL**（×年×月×日访问）** | 第48条 |
| 英文网络文献缺日期 | ……URL**(last visited Date)** | 第85条 |
| 外籍作者未标国籍 | ~~波斯森~~ → **[美]波斯纳** | 第31条 |

## 五、参考文献列表编排规则

参考文献列表按文献类型分组编排，组内按引用先后顺序编号：

1. **规范文献**（法律、法规、司法解释）
2. **案例文献**（裁判文书、指导性案例、典型案例）
3. **学说文献**（专著、期刊论文、文集文章）
4. **比较法文献**（外国法律、外国案例、外文学术文献）

> **编号制与脚注制的区别**：
> - 编号制：正文中用[×]标注，文后统一列表。同一文献使用同一编号。
> - 脚注制：每页脚注单独编号，同一文献多次出现使用"同前注〔×〕"缩略写法。
> - 本规范以编号制为主，兼顾脚注制要求。
