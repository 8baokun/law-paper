# 法学论文结构模式详解

> 前四种为通用模式，适用于学研轨和实务轨。后两种为**实务轨推荐模式**，特别适合面向实务工作者的论文。

## 模式一：制度分析型

### 适用场景

分析某一法律制度的规范构造、实施效果和完善路径。典型如：分析某一条款的规范内涵、评估某一制度的实施状况、提出制度完善建议。

### 结构模板

```
一、问题提出
  1.1 制度背景
    - 该制度产生的立法/政策背景
    - 该制度要解决的核心问题
  1.2 核心命题
    - 一句话判断句
  1.3 研究意义
    - 理论意义（对学理的贡献）
    - 实践意义（对实践的指导）

二、规范构造分析
  2.1 条文释义
    - 条文的字面含义
    - 核心概念的界定
  2.2 体系定位
    - 在法律体系中的位置
    - 与关联条款的关系
  2.3 效力层级
    - 规范的效力来源
    - 与上位法/下位法的关系
  2.4 规范性质
    - 是强制性规范还是任意性规范？
    - 是实体规范还是程序规范？
    - 是创设性规范还是宣示性规范？

三、实施现状与问题
  3.1 实施概况
    - 实施的主要做法
    - 实施中的典型案例
  3.2 问题识别
    - 规范层面的问题（条文本身的问题）
    - 实施层面的问题（执行中的问题）
    - 制度衔接的问题（与其他制度的摩擦）
  3.3 原因分析
    - 规范原因（条文不完善）
    - 体制原因（管理体制不顺）
    - 能力原因（执行能力不足）

四、比较法参照（可选）
  4.1 法域选择
  4.2 各法域制度考察
  4.3 异同对比与经验提炼

五、制度完善建议
  5.1 规范完善
    - 条文修改建议
    - 配套规范建议
  5.2 实施优化
    - 实施机制建议
    - 监督机制建议
  5.3 可行性分析
    - 制度可行性
    - 资源可行性
    - 时机可行性

六、结论
  - 重申核心命题
  - 概括论证过程
  - 指出研究局限
```

### 写作要点

- **规范分析部分是核心**，须占全文30%左右
- **问题识别须具体**，不能泛泛而谈"存在不足"
- **建议须可操作**，不能只说"应当完善"
- **比较法部分如无实质内容宁可不要**，避免凑数

## 模式二：规范解释型

### 适用场景

对某一法律条文或概念进行解释论研究。典型如：解释某一条款的含义、界定某一法律概念的内涵、解决法条适用争议。

### 结构模板

```
一、问题提出
  1.1 解释争议
    - 关于该条文/概念的主要争议
    - 争议对司法实践的影响
  1.2 核心命题
  1.3 研究方法
    - 说明采用何种解释方法及为何

二、文义解释
  2.1 字面含义
    - 条文字面含义分析
    - 核心词的语义分析
  2.2 概念界定
    - 核心概念的内涵与外延
    - 与近似概念的区别
  2.3 文义解释的局限
    - 文义可能的多种理解
    - 文义无法涵盖的情形

三、体系解释
  3.1 法律体系中的定位
    - 在该法律中的位置
    - 与同法其他条款的关系
  3.2 关联条款分析
    - 与上位条款的关系
    - 与平行条款的关系
    - 与下位条款的关系
  3.3 跨法域体系考察
    - 与其他法律的协调
    - 与司法解释的衔接

四、目的解释
  4.1 立法目的
    - 立法资料分析（如可得）
    - 立法要解决的问题
  4.2 价值取向
    - 该条文体现的价值选择
    - 与整体法律价值体系的协调
  4.3 社会效果考量
    - 不同解释的社会效果
    - 效果导向的解释选择

五、解释结论与适用方案
  5.1 解释结论
    - 综合各种解释方法的结论
    - 与既有观点的异同
  5.2 适用规则
    - 在具体案件中如何适用
    - 适用的例外情形
  5.3 争议回应
    - 对不同解释观点的回应

六、结论
```

### 写作要点

- **解释方法的选择须有论证**，不是每种方法都要用
- **文义解释是起点**，须先确定文义的可能范围
- **体系解释和目的解释是对文义解释的限缩或扩张**
- **解释结论须有适用方案**，不能停留在理论层面

## 模式三：实证研究型

### 适用场景

基于案例或数据的实证分析。典型如：裁判分歧的实证分析、制度实施效果的量化评估、类案裁判规律的统计研究。

### 结构模板

```
一、问题提出
  1.1 研究背景
  1.2 核心命题
  1.3 研究价值

二、研究设计
  2.1 样本选择
    - 案例来源（裁判文书网/法宝/万方等）
    - 检索策略（关键词+法院层级+时间范围）
    - 筛选标准（纳入标准/排除标准）
  2.2 分析方法
    - 描述性统计
    - 相关性分析
    - 回归分析（如适用）
  2.3 变量界定
    - 因变量
    - 自变量
    - 控制变量
  2.4 研究局限说明
    - 样本代表性局限
    - 数据完整性局限
    - 方法论局限

三、数据呈现与分析
  3.1 描述性统计
    - 样本基本情况
    - 核心变量的分布
  3.2 相关性分析
    - 变量间的关系
    - 统计显著性
  3.3 分组比较
    - 不同法院/地区/时间段的差异

四、发现与讨论
  4.1 核心发现
    - 数据揭示的主要规律
  4.2 理论解释
    - 用理论解释数据背后的原因
  4.3 与既有研究的对话
    - 与已有研究发现的异同
  4.4 政策含义
    - 发现对制度完善的启示

五、建议
  5.1 规范建议
  5.2 实施建议
  5.3 研究建议（后续研究方向）

六、结论
  - 研究贡献
  - 研究局限
  - 未来方向
```

### 写作要点

- **样本选择须可复制**，他人按同样方法应能获取类似样本
- **研究局限须主动说明**，不能掩盖数据缺陷
- **数据与理论须结合**，不能只列数据不分析
- **政策建议须基于数据**，不能脱离数据空谈建议

## 模式四：比较法研究型

### 适用场景

通过比较法视角分析某一法律问题。典型如：中外制度比较研究、法系间制度差异分析、国际经验的本土化路径研究。

### 结构模板

```
一、问题提出
  1.1 比较法视角的引入
    - 为何需要比较法视角
    - 比较法研究的价值
  1.2 核心命题
  1.3 研究范围界定

二、比较法域的选择与论证
  2.1 法域选择
    - 选择的法域清单
    - 选择标准（法系代表性/制度相关性/资料可得性）
  2.2 可比性论证
    - 比较的制度对应性
    - 不可比因素的排除
  2.3 比较框架
    - 比较的维度设定

三、各法域制度考察
  3.1 法域A
    - 规范内容
    - 实践运行
    - 制度背景
  3.2 法域B
    [同上]
  3.3 法域C
    [同上]

四、比较分析
  4.1 异同对比
    - 规范层面的异同
    - 实践层面的异同
  4.2 原因解释
    - 制度差异的历史原因
    - 法系传统的影响
    - 社会经济背景的影响
  4.3 规律提炼
    - 共性规律
    - 趋势方向

五、对中国的启示
  5.1 可借鉴经验
    - 直接可借鉴的制度要素
    - 需要改造的制度要素
  5.2 移植可行性分析
    - 制度环境的兼容性
    - 配套条件的要求
    - 移植成本评估
  5.3 本土化路径
    - 短期路径
    - 中长期路径

六、结论
```

### 写作要点

- **法域选择须有论证**，不能随意选几个国家
- **比较须有框架**，不能逐个国家介绍后就结束
- **启示须有可行性分析**，不能简单说"中国应当借鉴"
- **避免"外国月亮圆"倾向**，须客观呈现外国制度的不足

## 模式五：问题对策型（实务轨推荐）

### 适用场景

以实务问题为起点，分析规范困境，给出可操作对策。典型如：某类合同纠纷的裁判分歧与应对路径、某项行政监管的合规风险与防范措施、某个制度落地难的成因与破解方案。

与制度分析型的区别：制度分析型以"制度"为中心，问题对策型以"问题"为中心。前者问"这个制度怎么样"，后者问"这个问题怎么解决"。

### 结构模板

```
一、问题提出
  1.1 实务痛点
    - 直接描述实务中碰到的具体问题
    - 用真实案例或数据引出，不用学术综述开头
  1.2 核心命题
    - 一句话判断句，指向"应当怎么做"
  1.3 研究价值
    - 对实务工作的指导价值（放在学术价值之前）

二、规范分析
  2.1 现行规范
    - 现行法如何规定
    - 核心条文的含义
  2.2 解释争议
    - 学理上的不同解读
    - 司法解释/指导性案例的态度（如有）
  2.3 适用困境
    - 规范在适用中遇到的障碍
    - 规范与现实的落差

三、实践困境
  3.1 典型案例
    - 用2-3个真实案例说明"规范落不了地"
    - 案例须标注裁判文书号
  3.2 操作障碍
    - 实务操作中的具体难点
    - 各方主体的困惑
  3.3 制度摩擦
    - 与其他制度的衔接问题
    - 不同地区/部门的实践差异

四、成因剖析
  4.1 规范原因
    - 条文本身的不完善
  4.2 体制原因
    - 管理体制不顺、职责交叉等
  4.3 能力原因
    - 执行能力不足、配套资源缺乏等

五、对策建议
  5.1 操作路径
    - 具体的操作步骤，不是"应当完善"
  5.2 主体分工
    - 谁来做——主管部门、配合部门、执行主体
  5.3 配套条件
    - 需要什么制度配套、资源保障、时机条件
  5.4 风险提示
    - 对策自身的局限性和潜在风险

六、结论
  - 重申核心命题
  - 概括对策路径
  - 指出适用边界
```

### 写作要点

- **开头直接抛问题**，不用大段学术综述铺垫
- **案例必须真实**，用裁判文书号或可查证的事实
- **对策必须可操作**——"谁来做、怎么做、需要什么条件"三要素缺一不可
- **成因剖析要有层次**——规范、体制、能力三个层面逐层分析
- **对策建议须标注前提条件**——在什么条件下这个对策才成立

## 模式六：案例评析型（实务轨推荐）

### 适用场景

以真实案例切入，从个案提炼规则适用路径。典型如：指导性案例评析、类案裁判规则提炼、新型案件的法律适用方案。

与实证研究型的区别：实证研究型以数据和统计分析为核心，案例评析型以个案/类案的法律分析为核心。前者关注"多少案例怎么做"，后者关注"这个案例应该怎么做"。

### 结构模板

```
一、问题提出
  1.1 案例切入
    - 简述案例事实和争议焦点（不超过300字）
    - 提炼核心法律问题
  1.2 核心命题
    - 指向"该类案件应当如何适用法律"
  1.3 研究价值
    - 对裁判规则的贡献
    - 对实务操作的指导

二、裁判梳理
  2.1 裁判要旨
    - 法院的核心观点
  2.2 裁判理由
    - 法院的论证逻辑
  2.3 裁判分歧
    - 不同法院对同一问题的不同处理
    - 如有指导性案例，对比分析

三、规范分析
  3.1 相关法条
    - 适用的法律条文
    - 条文的规范性质（强制性/任意性/宣示性）
  3.2 解释路径
    - 文义解释、体系解释、目的解释的运用
    - 不同解释方法得出的不同结论
  3.3 适用争议
    - 规范为什么会产生分歧
    - 争议的焦点在哪里

四、规则提炼
  4.1 裁判规则归纳
    - 从案例中归纳可操作的裁判规则
    - 规则的适用条件
  4.2 学理支撑
    - 该规则是否有学理依据
    - 与主流学说的关系
  4.3 适用边界
    - 规则在什么情形下不适用
    - 例外情形

五、适用指引
  5.1 操作要点
    - 给实务工作者的"操作手册"
    - 举证要点、答辩要点、裁判要点
  5.2 风险提示
    - 适用该规则的风险
    - 需要注意的例外
  5.3 配套建议
    - 制度配套建议
    - 实践改进建议

六、结论
  - 重申核心命题
  - 概括裁判规则
  - 指出适用边界
```

### 写作要点

- **案例事实简明扼要**——不超过300字概括，细节放在后面按需展开
- **裁判分歧须如实呈现**——不能只选支持自己观点的裁判
- **规则提炼须可操作**——不是"应当综合考虑"，而是"在X条件下适用Y规则"
- **适用指引是本文的核心增量**——这是实务工作者最需要的部分
- **适用边界必须明确**——任何规则都有例外，不标注边界是不负责任的
