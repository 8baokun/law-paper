# 应用法学论文文献检索协调器

## 概述

本技能是应用法学论文生产线的环节4。在环节3（提纲审查）通过后、环节5（论文写作）之前，帮助作者系统化地完成文献检索、筛选、阅读和引用规划。

> **实务轨提示**：如使用"实务应用"或"决策参考"预设，文献检索在标准四类基础上需额外关注——实务类文献（行业规范、操作指引、合规手册、实务部门调研报告等）的收集，以及在"决策参考"预设下为环节8法律生态审查预备的制度环境文献（地方实施细则、部门操作规程等）。

**与法律实务检索的区别**：

| 维度 | 法律实务检索 | 本技能（论文文献检索） |
|------|-------------|------------------------|
| 检索目的 | 支撑诉讼策略、庭审准备 | 支撑学术论证、学术对话 |
| 检索重点 | 相关法条、类案裁判、司法解释 | 学理文献、规范文献、案例文献、比较法文献 |
| 检索深度 | 找到可用依据即可 | 需要系统覆盖、梳理谱系、识别增量空间 |
| 输出 | 检索报告（法条+案例列表） | 标准化文献清单+阅读笔记+引用策略 |
| 评估标准 | 与案件的关联度 | 学术贡献度、论证支撑力、对话价值 |

## 四类文献的检索框架

### 第一类：学理文献

**检索目标**：找到与核心命题相关的学术观点谱系，识别主流观点、少数观点和空白区域。

**检索范围**：

| 来源类型 | 优先级 | 说明 |
|----------|--------|------|
| 法学核心期刊（CLSCI/CSSCI） | 🔴 最高 | 法学研究、中国法学、法学、法学评论、政法论坛等 |
| 专著 | 🔴 最高 | 相关领域的权威专著 |
| 博硕学位论文 | 🟡 中 | 特别是近年博士论文的文献综述部分 |
| 普通期刊 | 🟡 中 | 作为补充，注意质量筛选 |
| 会议论文/集刊 | 🟡 中 | 关注最新学术动态 |
| 报纸理论版 | 🟢 低 | 法治日报、人民法院报理论版，关注实务观点 |
| 网络学术平台 | 🟢 低 | 中国法学网、北大法宝法学库，仅作线索 |

**检索策略**：

```
步骤1：关键词矩阵构建
  - 核心概念关键词（如"业法财融合"）
  - 关联概念关键词（如"合规管理""法务合规合署""总法律顾问"）
  - 上位概念关键词（如"国有企业治理""企业合规"）
  - 下位概念关键词（如"合规审查""合规风险评估"）
  ↓
步骤2：谱系梳理
  - 该问题的研究起始时间
  - 主要研究阶段划分
  - 代表性学者及其观点
  - 观点分歧的焦点
  - 当前研究的前沿方向
  ↓
步骤3：增量空间识别
  - 哪些问题已有充分研究？（标记为"已覆盖"）
  - 哪些问题研究不足？（标记为"增量空间"）
  - 哪些问题存在观点分歧？（标记为"对话切入点"）
  - 哪些问题尚未被研究？（标记为"空白区域"）
```

### 第二类：规范文献

**检索目标**：穷尽与核心命题相关的所有规范依据，构建完整的规范依据链条。

**检索范围**：

| 层级 | 内容 | 检索要求 |
|------|------|----------|
| 宪法层面 | 宪法相关条款 | 如涉及国家所有者权益等 |
| 法律层面 | 法律及修正案 | 标注版本和施行日期 |
| 行政法规 | 国务院条例、规定 | 关注国资委相关行政法规 |
| 部门规章 | 国资委、财政部等规章 | 《合规管理办法》本身 |
| 规范性文件 | 国资委通知、指导意见等 | 关注实施配套文件 |
| 司法解释 | 最高法/最高检相关解释 | 如涉及合规不起诉等 |
| 地方性规范 | 地方国资委实施细则 | 如有 |
| 企业内部规范 | 公司章程、合规手册等 | 如有获取渠道 |

**检索策略**：

```
步骤1：规范依据链条构建
  - 从核心命题出发，倒推需要的规范层级
  - 确保每一层级都有规范支撑（或明确标注"规范空白"）
  ↓
步骤2：规范效力核查
  - 逐条核查规范是否现行有效
  - 标注施行日期、最近修订情况
  - 如引用已废止规范，必须说明理由
  ↓
步骤3：规范冲突检查
  - 检查不同层级规范之间是否存在冲突
  - 检查同层级规范之间是否存在不一致
  - 如有冲突，标注冲突点和解决规则
```

### 第三类：案例文献

**检索目标**：找到与核心命题相关的典型案例，支撑或检验论证。

**检索范围**：

| 案例类型 | 优先级 | 说明 |
|----------|--------|------|
| 指导性案例 | 🔴 最高 | 最高法发布的指导性案例 |
| 公报案例 | 🔴 最高 | 最高人民法院公报案例 |
| 典型案例 | 🟡 高 | 各级法院发布的典型案例 |
| 裁判文书 | 🟡 中 | 通过裁判文书网检索 |
| 仲裁裁决 | 🟢 低 | 如涉及仲裁相关内容 |

**检索策略**：

```
步骤1：案例筛选标准设定
  - 与核心命题的关联度标准
  - 时间范围（一般取近5年，特殊需要可扩展）
  - 法院层级要求（一般以中级以上为重点）
  ↓
步骤2：代表性评估
  - 案例是否具有典型性
  - 裁判要旨是否清晰
  - 是否反映了主流裁判倾向
  - 是否存在同案不同判
  ↓
步骤3：正反案例平衡
  - 检索支持论点的案例
  - 检索不支持论点的案例（防止选择性偏差）
  - 如反面案例较多，需调整论证策略
```

### 第四类：比较法文献

**检索目标**：找到可资借鉴的外国法/区际法经验，支撑比较法论证。

**检索范围**：

| 来源类型 | 说明 |
|----------|------|
| 外国法条文 | 原文+权威译本 |
| 外国学理文献 | 该领域的外国权威学者观点 |
| 国际组织文件 | OECD、世界银行等合规指南 |
| 外国案例 | 如有英文/中文译本 |
| 比较法专著 | 专门比较研究的学术著作 |

**检索策略**：

```
步骤1：法域选择
  - 选择与核心命题最相关的法域
  - 应用法学论文一般选择3-5个法域即可
  - 注意法域的可比性论证
  ↓
步骤2：可比性论证
  - 论证选择的法域与我国制度的可比性
  - 标注不可比的因素
  - 避免简单的"外国怎么做+中国该怎么做"模式
  ↓
步骤3：经验提炼
  - 从比较法材料中提炼可借鉴的制度经验
  - 注意制度移植的可行性分析
  - 标注文化、制度背景差异
```

## 执行流程

```
步骤1：接收提纲审查结果和环节1文献综述报告
  - 读取环节3的提纲审查报告
  - 读取环节1的选题文献综述报告（作为检索起点）
  - 确认提纲已通过
  - 提取提纲中的论证框架和依据类型标注
  - 提取文献综述报告中的核心文献清单和待补充检索方向
  ↓
步骤2：制定检索计划
  - 在环节1文献综述报告基础上扩展检索计划
  - 优先覆盖文献综述报告中的"待补充检索方向"
  - 根据提纲的论证框架，确定四类文献的检索优先级
  - 分配检索时间（建议：学理40%、规范20%、案例25%、比较法15%）
  - 构建关键词矩阵（在环节1关键词基础上扩展）
  ↓
步骤3：执行检索
  - 按四类文献分别检索
  - 记录检索来源、检索时间、检索结果数量
  - 初步筛选：剔除明显不相关的文献
  ↓
步骤4：文献评估
  - 对每篇文献评估：相关性、权威性、时效性、贡献度
  - 标注文献在论证框架中的位置（支撑哪个前置论点）
  - 识别文献覆盖度缺口
  ↓
步骤5：精读笔记
  - 对核心文献（每类3-5篇）制作阅读笔记
  - 笔记格式：核心观点+论证方法+与本文的关系+可引用的原文段落
  ↓
步骤6：引用策略规划
  - 规划每个前置论点的引用组合
  - 确保引用的多样性和平衡性
  - 标注必须引用的文献和可选引用的文献
  ↓
步骤7：输出标准化文献清单
```

## 阅读笔记格式

对核心文献（每类3-5篇），制作以下格式的阅读笔记：

```markdown
## 阅读笔记：[文献编号] [作者] [标题]

### 基本信息
- 作者：[姓名]
- 出处：[期刊/出版社]，[年份]，[页码]
- 文献类型：[期刊论文/专著章节/学位论文]

### 核心观点
[2-3句话概括作者的核心观点]

### 论证方法
[作者使用了什么论证方法：规范分析/实证研究/比较法/历史梳理等]

### 关键论据
1. [论据1]
2. [论据2]
3. [论据3]

### 与本文的关系
- **支撑论点**：[本文的哪个前置论点可以引用该文献]
- **对话/分歧**：[该文献与本文的哪些观点不同]
- **增量空间**：[该文献未涉及但本文要讨论的问题]

### 可引用的原文段落
> "[原文段落1]"

> "[原文段落2]"

### 引用格式
[作者]. [标题]. [来源], [年份], [页码].
```

## 输出底线

- **文献必须真实存在**。不捏造任何文献。如不确定，标注"[待验证]"。
- **四类文献缺一不可**。即使某类文献数量较少，也必须说明检索结果。
- **正反案例必须平衡**。不得只检索支持论点的案例。
- **覆盖度评估必须如实**。覆盖不足的论点必须标注。
- **引用策略必须具体到章节和论点**。不能笼统说"可以引用"。
- **待补充清单必须如实列出**。不能掩盖文献缺口。

## 回溯协议

- 如某个前置论点的文献覆盖度=不足（✗）→ 需扩大检索范围后重新评估
- 如案例文献出现大量反面案例且无法回应 → 回退到环节2（思路梳理），核心命题可能需要调整
- 如比较法文献的可比性无法论证 → 放弃比较法论证路线，调整论文类型
- 如关键规范已废止且无替代 → 回退到环节2，论证框架需要调整

## 快速通道

- 如环节3（提纲审查）综合评分 ≥ 4.5 → 可启用简化模式：
  - 学理文献检索聚焦核心期刊（不扩展到普通期刊）
  - 案例文献检索聚焦指导性案例和公报案例
  - 比较法文献可选（如论文类型不是比较法研究型）
- 但规范文献检索不可简化——必须穷尽相关规范
