# 应用法学论文文献检索协调器

## 概述

本技能是应用法学论文生产线的环节4。在环节3（提纲审查）通过后、环节5（论文写作）之前，帮助作者系统化地完成文献检索、筛选、阅读和引用规划。

> **实务轨提示**：如使用"实务应用"或"决策参考"预设，文献检索在标准四类基础上需额外关注——实务类文献（行业规范、操作指引、合规手册、实务部门调研报告等）的收集，以及在"决策参考"预设下为环节8法律生态审查预备的制度环境文献（地方实施细则、部门操作规程等）。
>
> **线索卡强制消费（实务轨）**：如上游传入了"实务问题线索卡"，本环节必须：
> 1. 读取线索卡中的受困主体、实务场景、规范缺口类型
> 2. 针对线索卡字段定向检索实务类文献：以受困主体为关键词、以实务场景为检索方向、以规范缺口类型确定检索范围
> 3. 文献清单中至少3篇与线索卡直接相关的实务文献，否则标注"实务文献覆盖不足"
> 4. 文献评估时标注每篇实务文献与线索卡的对应关系

**与法律实务检索的区别**：

| 维度 | 法律实务检索 | 本技能（论文文献检索） |
|------|-------------|------------------------|
| 检索目的 | 支撑诉讼策略、庭审准备 | 支撑学术论证、学术对话 |
| 检索重点 | 相关法条、类案裁判、司法解释 | 学理文献、规范文献、案例文献、比较法文献 |
| 检索深度 | 找到可用依据即可 | 需要系统覆盖、梳理谱系、识别增量空间 |
| 输出 | 检索报告（法条+案例列表） | 标准化文献清单+阅读笔记+引用策略 |
| 评估标准 | 与案件的关联度 | 学术贡献度、论证支撑力、对话价值 |

## 检索工具链（paper-harvester 集成）

> 本技能集成 paper-harvester 技能的多源检索脚本，实现自动化文献检索。环节1已用此工具链完成选题验证型综述，本环节在其基础上深化扩展。

### 工具链总览

| 工具 | 检索源 | 覆盖范围 | 角色 | 在四类文献中的定位 |
|------|--------|----------|------|-------------------|
| `search_ncpssd.py` | 国家哲社文献中心（NCPSSD） | 中文核心期刊论文 | **主力中文源** | 学理文献（中文）的主力检索源 |
| `search_openalex.py` | OpenAlex | 全球英文文献（含DOI、被引量、OA状态） | **主力英文源** | 比较法文献的主力检索源 |
| `search_crossref.py` | Crossref | 全球英文文献（含DOI） | **英文补充源** | 比较法文献补充，与OpenAlex去重 |
| `search_semantic_scholar.py` | Semantic Scholar | 全球英文文献（含语义关联） | **英文补充源** | 有限流（429），非必须 |
| WebSearch | 互联网公开搜索 | 法院实务文章、学位论文、裁判文书网 | **补充源** | 案例文献、实务指引类文献 |

### NCPSSD 使用规范

> ⚠️ NCPSSD 是中文核心期刊论文的主力检索源，但有以下使用限制。

| 限制项 | 说明 | 应对策略 |
|--------|------|----------|
| **单词查询限制** | 不支持多词组合检索，"自甘风险 重大过失"返回0结果 | 拆分为多个单词分别查询后人工合并 |
| **返回上限** | 每次查询默认返回20篇 | 可调大参数（如50），但仍需多次查询覆盖不同关键词 |
| **同义词覆盖** | 同一概念可能有多种表述 | 需用同义词扩展（如"自甘风险"→也查"自甘冒险"） |
| **法条编号检索** | 可用"民法典1176条"等法条编号作为关键词 | 建议单独用法条编号查一次，补充以法条为核心的文献 |
| **核心期刊筛选** | 返回结果含大量普通期刊 | 按CLSCI/CSSCI法学核心期刊列表筛选优先级 |

### 多源去重合并流程

```
步骤1：收集各源检索结果
  - NCPSSD：多次单词查询的结果集合
  - OpenAlex：多次短语查询的结果集合
  - Crossref：补充查询的结果集合
  - WebSearch：补充检索的结果集合
  ↓
步骤2：按标题去重
  - 标题小写化后比较
  - 同一文献被多源检索到时，保留首次发现的来源标注
  ↓
步骤3：按DOI去重（如有DOI）
  - 有DOI的文献按DOI去重
  - 无DOI的中文文献按标题+作者+年份组合去重
  ↓
步骤4：按相关性排序
  - 优先保留与核心命题直接相关的文献
  - 优先保留核心期刊文献
  - 优先保留高被引文献
  ↓
步骤5：分类归档
  - 按四类文献（学理/规范/案例/比较法）分别归档
  - 与环节1综述报告中的核心文献清单合并（环节1已发现的文献不重复检索）
  ↓
步骤6：记录全文获取信息
  - 每篇文献记录PDF链接（如有）、OA状态
  - 标注获取状态：✅可下载 / ❌付费墙 / —无全文链接
  - 付费墙文献不下载，但必须完整记录论文名/作者/期刊/年份/DOI等核心信息
  ↓
步骤7：文献幻觉三分类核验
  - 第一类核验（作品是否存在）：用题名+作者分别检索独立来源，至少2个来源确认
  - 第二类核验（字段是否准确）：逐字段比对作者/年份/卷期/页码
  - 第三类核验（正文是否误用）：对已下载PDF的核心文献，回原文核对观点归属和限定词
  - 核验结果标注：[已核实]/[暂未核实]/[确认虚构]/[字段存疑]
  - DOI链接须打开后比对题名作者，不能仅凭链接可访问即认为引用准确
```

### 核心文献下载策略

> 环节4系统检索可能返回50-100篇文献，**不全部下载**。采用分级管理：全部记录链接信息，仅对精读笔记的核心文献（每类3-5篇，约12-20篇）按需下载。
> **原则**：记录链接为主，按需下载为辅，付费墙不下载只记录信息，不做PDF转文本。

| 项目 | 规范 |
|------|------|
| 下载目录 | `[论文项目目录]/papers/`（与论文产物同目录下的 papers 子文件夹，与环节1共用） |
| 文件命名 | `[编号]_[作者]_[年份]_[短标题].pdf`（如 `S1_李四_2022_合规审查效力.pdf`） |
| 下载范围 | 仅精读笔记环节选出的核心文献（每类3-5篇），不在检索时全量下载 |
| 下载来源 | NCPSSD返回的PDF链接优先；OpenAlex仅下载OA标记为✅的 |
| 付费墙处理 | **不下载**，在文献清单中标注"付费墙·待人工获取"，记录论文名/作者/期刊/年份/DOI |
| 下载间隔 | 每篇间隔≥3秒，避免触发反爬 |
| 失败处理 | 连续下载失败3次，暂停下载，剩余文献仅记录信息 |
| 会话上限 | 单次会话下载总量不超过15篇（环节4配额，与环节1分账计算） |
| 已下载检查 | 下载前检查环节1是否已下载同一文献，避免重复下载 |
| 下载状态标注 | ✅已下载 / ❌付费墙·待人工获取 / ⚠️下载失败·待重试 / —无需下载 |

## 四类文献的检索框架

### 第一类：学理文献

**检索目标**：找到与核心命题相关的学术观点谱系，识别主流观点、少数观点和空白区域。

**检索范围**：

| 来源类型 | 优先级 | 说明 |
|----------|--------|------|
| 法学核心期刊（CLSCI/CSSCI） | 🔴 最高 | 法学研究、中国法学、法学、法学评论、政法论坛等 |
| 专著 | 🔴 最高 | 相关领域的权威专著 |
| 博硕学位论文 | 🟡 中 | 特别是近年博士论文的文献综述部分 |
| 普通期刊 | 🟡 中 | 作为补充，注意质量筛选 |
| 会议论文/集刊 | 🟡 中 | 关注最新学术动态 |
| 报纸理论版 | 🟢 低 | 法治日报、人民法院报理论版，关注实务观点 |
| 网络学术平台 | 🟢 低 | 中国法学网、北大法宝法学库，仅作线索 |

**检索策略**：

```
步骤1：关键词矩阵构建
  - 核心概念关键词（如"业法财融合"）
  - 关联概念关键词（如"合规管理""法务合规合署""总法律顾问"）
  - 上位概念关键词（如"国有企业治理""企业合规"）
  - 下位概念关键词（如"合规审查""合规风险评估"）
  ↓
步骤2：NCPSSD自动化检索（主力中文源）
  - 将关键词矩阵中的每个词拆分为单词，分别查询NCPSSD
  - 同义词扩展查询（如"自甘风险"→也查"自甘冒险"）
  - 法条编号单独检索（如"民法典1176条"）
  - 按CLSCI/CSSCI核心期刊列表筛选优先级
  ↓
步骤3：谱系梳理
  - 该问题的研究起始时间
  - 主要研究阶段划分
  - 代表性学者及其观点
  - 观点分歧的焦点
  - 当前研究的前沿方向
  ↓
步骤4：增量空间识别
  - 哪些问题已有充分研究？（标记为"已覆盖"）
  - 哪些问题研究不足？（标记为"增量空间"）
  - 哪些问题存在观点分歧？（标记为"对话切入点"）
  - 哪些问题尚未被研究？（标记为"空白区域"）
```

### 第二类：规范文献

**检索目标**：穷尽与核心命题相关的所有规范依据，构建完整的规范依据链条。

**检索范围**：

| 层级 | 内容 | 检索要求 |
|------|------|----------|
| 宪法层面 | 宪法相关条款 | 如涉及国家所有者权益等 |
| 法律层面 | 法律及修正案 | 标注版本和施行日期 |
| 行政法规 | 国务院条例、规定 | 关注国资委相关行政法规 |
| 部门规章 | 国资委、财政部等规章 | 《合规管理办法》本身 |
| 规范性文件 | 国资委通知、指导意见等 | 关注实施配套文件 |
| 司法解释 | 最高法/最高检相关解释 | 如涉及合规不起诉等 |
| 地方性规范 | 地方国资委实施细则 | 如有 |
| 企业内部规范 | 公司章程、合规手册等 | 如有获取渠道 |

**检索策略**：

```
步骤1：规范依据链条构建
  - 从核心命题出发，倒推需要的规范层级
  - 确保每一层级都有规范支撑（或明确标注"规范空白"）
  ↓
步骤2：规范效力核查
  - 逐条核查规范是否现行有效
  - 标注施行日期、最近修订情况
  - 如引用已废止规范，必须说明理由
  ↓
步骤3：规范冲突检查
  - 检查不同层级规范之间是否存在冲突
  - 检查同层级规范之间是否存在不一致
  - 如有冲突，标注冲突点和解决规则
```

### 第三类：案例文献

**检索目标**：找到与核心命题相关的典型案例，支撑或检验论证。

**检索范围**：

| 案例类型 | 优先级 | 说明 |
|----------|--------|------|
| 指导性案例 | 🔴 最高 | 最高法发布的指导性案例 |
| 公报案例 | 🔴 最高 | 最高人民法院公报案例 |
| 典型案例 | 🟡 高 | 各级法院发布的典型案例 |
| 裁判文书 | 🟡 中 | 通过裁判文书网检索 |
| 仲裁裁决 | 🟢 低 | 如涉及仲裁相关内容 |

**检索策略**：

```
步骤1：案例筛选标准设定
  - 与核心命题的关联度标准
  - 时间范围（一般取近5年，特殊需要可扩展）
  - 法院层级要求（一般以中级以上为重点）
  ↓
步骤2：代表性评估
  - 案例是否具有典型性
  - 裁判要旨是否清晰
  - 是否反映了主流裁判倾向
  - 是否存在同案不同判
  ↓
步骤3：正反案例平衡
  - 检索支持论点的案例
  - 检索不支持论点的案例（防止选择性偏差）
  - 如反面案例较多，需调整论证策略
```

### 第四类：比较法文献

**检索目标**：找到可资借鉴的外国法/区际法经验，支撑比较法论证。

**检索范围**：

| 来源类型 | 说明 |
|----------|------|
| 外国法条文 | 原文+权威译本 |
| 外国学理文献 | 该领域的外国权威学者观点 |
| 国际组织文件 | OECD、世界银行等合规指南 |
| 外国案例 | 如有英文/中文译本 |
| 比较法专著 | 专门比较研究的学术著作 |

**检索策略**：

```
步骤1：法域选择
  - 选择与核心命题最相关的法域
  - 应用法学论文一般选择3-5个法域即可
  - 注意法域的可比性论证
  ↓
步骤2：OpenAlex/Crossref自动化检索（主力英文源）
  - 用英文标准法律术语构建查询短语
  - OpenAlex查询：按被引量排序，优先高被引文献
  - Crossref补充查询：与OpenAlex结果去重
  - 重点关注OA可下载全文的文献
  ↓
步骤3：可比性论证
  - 论证选择的法域与我国制度的可比性
  - 标注不可比的因素
  - 避免简单的"外国怎么做+中国该怎么做"模式
  ↓
步骤4：经验提炼
  - 从比较法材料中提炼可借鉴的制度经验
  - 注意制度移植的可行性分析
  - 标注文化、制度背景差异
```

## 执行流程

```
步骤1：接收提纲审查结果和环节1文献综述报告
  - 读取环节3的提纲审查报告
  - 读取环节1的选题文献综述报告（作为检索起点）
  - 如为实务轨，读取"实务问题线索卡"
  - 确认提纲已通过
  - 提取提纲中的论证框架和依据类型标注
  - 提取文献综述报告中的核心文献清单和待补充检索方向
  - 【实务轨】提取线索卡中的受困主体、实务场景、规范缺口类型，纳入检索计划
  ↓
步骤2：制定检索计划
  - 在环节1文献综述报告基础上扩展检索计划
  - 优先覆盖文献综述报告中的"待补充检索方向"
  - 根据提纲的论证框架，确定四类文献的检索优先级
  - 【实务轨】针对线索卡的受困主体、实务场景、规范缺口类型制定定向检索计划
  - 分配检索时间（建议：学理40%、规范20%、案例25%、比较法15%）
  - 构建关键词矩阵（在环节1关键词基础上扩展）
  ↓
步骤3：执行检索（工具链+人工）
  - 学理文献：NCPSSD单词查询（主力）+ WebSearch补充
  - 比较法文献：OpenAlex短语查询（主力）+ Crossref补充
  - 规范文献：威科/北大法宝人工检索（NCPSSD不覆盖法规全文）
  - 案例文献：裁判文书网/威科人工检索 + WebSearch补充
  - 记录每个工具的检索来源、查询词、检索结果数量
  - 初步筛选：剔除明显不相关的文献
  ↓
步骤4：多源去重合并
  - 按标题（小写化）去重
  - 按DOI去重（如有DOI的文献）
  - 与环节1综述报告中的核心文献清单合并
  - 按四类文献分别归档
  ↓
步骤5：文献评估
  - 对每篇文献评估：相关性、权威性、时效性、贡献度
  - 标注文献在论证框架中的位置（支撑哪个前置论点）
  - 识别文献覆盖度缺口
  ↓
步骤5：精读笔记
  - 对核心文献（每类3-5篇）制作阅读笔记
  - 下载核心文献PDF到 [论文项目目录]/papers/（下载间隔≥3秒）
```

## 输出底线

- **文献必须真实存在**。不捏造任何文献。
- **文献幻觉三分类核验**——所有文献必须按以下三类逐一核验，不可笼统标注"已验证"：
  - **第一类（作品不存在）**：作者真实、期刊真实，但这篇论文没发表过。核验方法：用题名+作者分别检索独立来源（不要用AI给的全部字段限制检索——年份有错会排除正确记录），至少2个独立来源确认。
  - **第二类（字段有误）**：论文真实存在，但作者/年份/卷期/页码有错。核验方法：找到候选后逐字段比对（作者/年份/卷期/页码），任一字段不一致即标注字段错误。
  - **第三类（正文误用）**：书目全对，但引用时歪曲了原文观点（如把"介绍的观点"写成"作者的主张"，把"有条件的"写成"普遍的"）。核验方法：回到原文核对观点归属、适用条件和限定词。
- **DOI核验规范**——DOI链接能打开≠引用准确。有效DOI可能指向不相干论文。打开DOI后必须比对题名、作者与出版信息是否与文献清单一致。
- **[待验证]细分标注**——不再笼统标注"[待验证]"，改为：
  - `[暂未核实]`：尚未完成核验，可能因数据库覆盖、访问权限、题名变体等原因暂未找到——不等于虚构
  - `[确认虚构]`：经至少2个独立来源检索确认该文献不存在
  - `[字段存疑]`：文献真实存在但某字段（年份/卷期/页码等）有误，标注具体存疑字段
- **NCPSSD检索必须单词查询**——多词组合会返回0结果，需拆分为多个单概念词分别查询后合并。
- **每篇文献标注检索来源**（NCPSSD/OpenAlex/Crossref/WebSearch/威科/裁判文书网等），确保可追溯。
- **多源检索结果必须去重合并**——同一文献被多个工具检索到时，保留首次发现的来源标注，不重复列入。
- **四类文献缺一不可**。即使某类文献数量较少，也必须说明检索结果。
- **正反案例必须平衡**。不得只检索支持论点的案例。
- **覆盖度评估必须如实**。覆盖不足的论点必须标注。
- **引用策略必须具体到章节和论点**。不能笼统说"可以引用"。
- **待补充清单必须如实列出**。不能掩盖文献缺口。
- **文献下载遵循反爬保护**——下载间隔≥3秒，环节4会话上限15篇，连续失败3次暂停。付费墙文献不下载但必须记录论文名/作者/期刊/年份/DOI等核心信息供人工获取。下载前检查环节1是否已下载同一文献。
- **实务轨必须读取并消费线索卡**——针对线索卡的受困主体和实务场景定向检索实务文献，文献清单中至少3篇与线索卡直接相关，否则标注"实务文献覆盖不足"。

## 回溯协议

- 如某个前置论点的文献覆盖度=不足（✗）→ 需扩大检索范围后重新评估
- 如案例文献出现大量反面案例且无法回应 → 回退到环节2（思路梳理），核心命题可能需要调整
- 如比较法文献的可比性无法论证 → 放弃比较法论证路线，调整论文类型
- 如关键规范已废止且无替代 → 回退到环节2，论证框架需要调整

## 快速通道

- 如环节3（提纲审查）综合评分 ≥ 4.5 → 可启用简化模式：
  - 学理文献检索聚焦核心期刊（不扩展到普通期刊）
  - 案例文献检索聚焦指导性案例和公报案例
  - 比较法文献可选（如论文类型不是比较法研究型）
- 但规范文献检索不可简化——必须穷尽相关规范
