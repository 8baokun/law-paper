# 文献覆盖度自检清单

## 使用说明

在文献检索完成后，逐项核对以下清单。任何一项不通过，都需要补充检索或调整论证策略。

## 一、学理文献自检

### 1.1 谱系完整性

```
☐ 是否找到了该问题的最早研究文献？
☐ 是否梳理了研究发展的主要阶段？
☐ 是否识别了代表性学者及其核心观点？
☐ 是否标注了当前研究的前沿方向？
☐ 是否识别了研究空白区域？
```

### 1.2 观点平衡性

```
☐ 是否检索了与自身观点不同的文献？
☐ 是否检索了与自身观点对立的文献？
☐ 主流观点和少数观点是否都得到体现？
☐ 是否避免了对单一学者的过度引用（同一学者引用不超过3次）？
```

### 1.3 时效性

```
☐ 是否包含近3年发表的文献？
☐ 是否包含最新修订法律的配套研究文献？
☐ 如引用了5年前的文献，是否说明了为何引用旧文献？
☐ 是否关注了最新学术会议/研讨会的观点动态？
```

## 二、规范文献自检

### 2.1 层级完整性

```
☐ 宪法层面：是否检查了相关宪法条款？
☐ 法律层面：是否穷尽了相关法律？
☐ 行政法规：是否检索了相关行政法规？
☐ 部门规章：是否检索了相关部委规章？
☐ 规范性文件：是否检索了配套通知、指导意见？
☐ 司法解释：是否检索了相关司法解释？
☐ 地方性规范：是否检索了地方实施细则？
```

### 2.2 效力核查

```
☐ 每条引用的规范是否标注了施行日期？
☐ 每条引用的规范是否确认现行有效？
☐ 如引用已废止规范，是否说明了理由？
☐ 是否标注了最近修订情况？
☐ 是否检查了正在修订中的法律（草案）？
```

### 2.3 规范冲突

```
☐ 是否检查了不同层级规范之间的冲突？
☐ 是否检查了同层级规范之间的不一致？
☐ 如有冲突，是否标注了解决规则（上位法优先/新法优先/特别法优先）？
☐ 是否检查了法律保留事项？
```

## 三、案例文献自检

### 3.1 案例质量

```
☐ 是否优先检索了指导性案例？
☐ 是否优先检索了公报案例？
☐ 案例的裁判文书号是否完整标注？
☐ 案例的裁判法院和日期是否标注？
☐ 案例的裁判要旨是否准确提取？
```

### 3.2 正反平衡

```
☐ 是否检索了支持论点的案例？
☐ 是否检索了不支持论点的案例？
☐ 正反案例的比例是否反映了真实的裁判倾向？
☐ 如反面案例较多，是否调整了论证策略？
☐ 是否存在选择性引用的嫌疑？
```

### 3.3 代表性

```
☐ 案例是否具有典型性？
☐ 案例的法院层级是否足够（一般以中级以上为重点）？
☐ 案例的时间范围是否合理（一般取近5年）？
☐ 是否关注了裁判趋势的变化？
```

## 四、比较法文献自检

### 4.1 法域选择

```
☐ 选择的法域是否与核心命题最相关？
☐ 法域数量是否合理（一般3-5个）？
☐ 是否论证了法域选择的理由？
☐ 是否考虑了法系代表性（大陆法系/英美法系/混合法系）？
```

### 4.2 可比性

```
☐ 是否论证了所选法域与我国制度的可比性？
☐ 是否标注了不可比的因素？
☐ 是否避免了简单的制度罗列？
☐ 是否分析了制度移植的可行性？
☐ 是否标注了文化、制度背景差异？
```

### 4.3 来源可靠性

```
☐ 外国法条文是否有权威译本？
☐ 引用的外国学理文献是否是该领域的权威文献？
☐ 是否标注了国际组织文件的准确出处？
☐ 是否避免了对二手译介的过度依赖？
```

## 五、引用策略自检

```
☐ 每个前置论点是否有至少2个文献支撑？
☐ 引用是否覆盖了四类文献（学理/规范/案例/比较法）？
☐ 是否避免了对单一来源的过度引用？
☐ 引用格式是否统一规范？
☐ 必引文献和建议引用文献是否区分清楚？
☐ 引用目的是否明确（支撑/对话/反驳）？
```

## 六、学术诚信自检

```
☐ 所有文献是否真实存在（非捏造）？
☐ 文献信息是否准确（作者、标题、出处、年份）？
☐ 原文引用是否逐字核对？
☐ 是否避免断章取义？
☐ 是否标注了转引（如引用的是二手文献）？
☐ 如有不确定的信息，是否标注了"[待验证]"？
```

## 自检结果汇总

| 检查类别 | 通过项数 | 总项数 | 是否通过 |
|----------|----------|--------|----------|
| 学理文献 | X | 15 | ✓/✗ |
| 规范文献 | X | 14 | ✓/✗ |
| 案例文献 | X | 12 | ✓/✗ |
| 比较法文献 | X | 12 | ✓/✗ |
| 引用策略 | X | 6 | ✓/✗ |
| 学术诚信 | X | 6 | ✓/✗ |

> 任一类别不通过 → 需补充检索或调整策略后重新自检
> 全部通过 → 可进入环节5（论文写作）
