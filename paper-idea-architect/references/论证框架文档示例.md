# 标准化论证框架文档示例

## 示例：合规管理办法第26条的规范构造

### 1. 核心命题

《合规管理办法》第26条规定的业法财融合机制在规范层面具有可操作性，但其效力层级和约束范围需要在制度实现层面进一步完善。

### 2. 论证线索

#### 2.1 核心主张

第26条并非宣示性条款，而是创设了具体的规范义务——要求国企在合规管理中实现业务、法务、财务的协同治理。但该义务的效力来源是部门规章，缺乏上位法支撑，在制度实现上需要通过公司章程和内部制度予以落地。

#### 2.2 前置论点

| 编号 | 前置论点 | 是否需独立论证 | 依据类型 | 依据来源 |
|------|----------|----------------|----------|----------|
| P1 | 第26条的文义包含"协同治理"的规范要求 | 需论证 | L+S | 《合规管理办法》第26条+文义解释 |
| P2 | 业法财融合不是已有制度的重命名，而是新的规范要求 | 需论证 | S+L | 学说+与既有制度的规范比较 |
| P3 | 部门规章的效力层级限制了第26条的直接约束力 | 已成立（行政法基本原理） | L | 《立法法》+行政法理论 |
| P4 | 公司章程是第26条落地的主要载体 | 需论证 | L+F | 《公司法》+国企章程实践 |
| P5 | 京投公司的实践提供了制度实现的样本 | 需论证 | F | 京投合规管理实践 |

#### 2.3 论证结构图

```
[核心主张：第26条创设规范义务但需制度实现]
  ├── [P1：文义包含协同治理要求] ← [L] ← 《合规管理办法》第26条
  │     └── [S] ← 文义解释方法
  ├── [P2：非重命名而是新要求] ← [S] ← 学说
  │     └── [L] ← 与《公司法》《企业内控基本规范》的规范比较
  ├── [P3：效力层级限制] ← [L] ← 《立法法》+行政法理论
  │     └── [已成立前提，不需独立论证]
  ├── [P4：公司章程是落地载体] ← [L] ← 《公司法》关于章程的规定
  │     └── [F] ← 国企章程实践案例
  ├── [P5：京投实践提供样本] ← [F] ← 京投合规管理实践
  │     └── [P] ← 京投内部制度文件
  └── [反驳回应R1] ← 第26条并非宣示性条款的论证
```

#### 2.4 反驳预判

| 编号 | 可能的反对意见 | 回应方向 | 依据类型 |
|------|----------------|----------|----------|
| R1 | 第26条是宣示性条款，不创设具体义务 | 从文义、体系、目的三个角度论证其规范性 | L+S |
| R2 | 业法财融合只是已有合规/内控/风险管理概念的重命名 | 通过规范比较揭示其独特要素（法务合规合署、总法律顾问兼任等） | S+L |
| R3 | 京投案例是个案，不具备推广价值 | 提炼可推广的制度要素，区分"京投特色"和"通用要素" | F+S |
